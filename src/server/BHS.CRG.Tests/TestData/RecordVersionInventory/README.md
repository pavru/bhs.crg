# Образцы нарушений переписи истории версий

Читает `Configuration/RecordVersionInventoryTests.Каждый_запрет_красный_на_своём_образце`. Файлы —
`.cs.txt`, чтобы не компилироваться и не попадать в переписи исходников решения. Образец нарушения
нарушает ровно один запрет; ожидаемый ответ записан в тесте точным списком. Образцы, помеченные
«не нарушение», ловят ложный отказ: сторож, который краснеет на законном коде, обходят, а не слушают.
