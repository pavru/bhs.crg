# Design: предпросмотр документа без прыжка

Общая архитектура — `../viewer-00-epic/design.md` (D7, D9). Компонент — `../viewer-01-component/design.md`.
Здесь только решения этого change.

## Context

- **Панель.** `DocumentPreviewPanel` (`features/document-sets/editor/DocumentPreviewPanel.tsx`)
  стоит в `RequisitesTab.tsx:807`:
  - открыта только на `xl` (`hidden xl:flex`), ширина `w-[44%] min-w-[380px]` (уже в уровне храповика);
  - перегенерация с дебаунсом 1,5 с, single-flight через `reqId`;
  - на обновлении держит старый PDF (`setState(s => s.kind === 'pdf' ? s : …)`), но `<iframe src>` с
    новым адресом всё равно перезагружается и прыгает на первую страницу (`:93`).
- **Кнопки шапки** «Обновить» и «Скрыть» — голые `button p-1.5` (`:81`, `:86`), «Повторить» в отказе —
  голая `button` (`:113`).
- **Загрузчик.** `previewDocument` (`shared/api/documentSets.ts:348`) возвращает `{ kind: 'pdf', url }`
  либо маркер «нет шаблона» или ошибку (различает по `content-type`).
- **Сверка: `previewGeneratedFile` (`documentSets.ts:416`) панель не зовёт.** Её зовут кнопки открытия
  готового PDF — `GenerationTab.tsx:266` и `SetDetail.tsx:283`. Окно она открывает синхронно (это
  верно), а ссылку не отзывает никогда (`:431`, «intentionally not revoking»).
- **e2e.** Живого прогона предпросмотра документа нет (сверено grep по `e2e/`).

## Goals / Non-Goals

**Goals:** тот же лист после перегенерации; ни одного пустого кадра; без роста памяти; закрыть утечку
`previewGeneratedFile`.

**Non-Goals:**
- Предпросмотр на узком экране и на телефоне: панель по-прежнему только на `xl`.
- Проверка «байты те же — ничего не делать» по хешу. Typst, вероятно, пишет дату в метаданные, и тогда
  байты разные всегда. Проверить при реализации; если пишет — не делать.
- Ширина панели и её `localStorage` (`doc-preview-open`).

## Decisions

### Подмена в движке
Реализует [UI-25] внутри `shared/ui/viewer`:
1. Тот же `documentKey`, новые байты — прежний документ остаётся на экране, новый грузится в фоне
   (`loadingTask`). Предыдущая фоновая загрузка гасится `loadingTask.destroy()`.
2. Новый готов — снимается якорь (страница + доля, масштаб, поворот). Видимые страницы нового рисуются
   в холсты вне экрана, затем лента подменяется одним кадром.
3. Прежний документ — `destroy()` после подмены, ровно один раз.
4. Листов стало меньше — якорь прижимается к последнему.

Альтернатива — два стопкой лежащих просмотрщика с переключением видимости. Отвергнута: два документа и
два набора холстов на 200 листах — та самая память, которую экономим.

### Панель
- `previewDocument` → `{ kind: 'pdf', blob }`. Состояние `pdf` держит `Blob`, `urlRef` и отзыв уходят.
- `reqId` остаётся: устаревший ответ сервера отбрасывается до просмотрщика. Гонку внутри движка гасит
  шаг 1.
- `PdfViewer` с `documentKey = instanceId`, `rememberZoomAs="document-preview"`.
- Спиннер первой загрузки остаётся у места; на обновлении — только иконка «Обновить» крутится.
- «Повторить» — `Button variant="text"`. Кнопки шапки на `IconButton size="sm"` переводит открытый
  `sharedui-icon-button-screens` (1.2, `[UI-46]`, сверено 22.10.2026). Двух переводов одного места не
  планируем: кто начнёт первым, тот и переводит, а пункт у другого вычёркивается. Перевод по готовому
  правилу UI.md, макеты не нужны (D10 зонтика).

### `previewGeneratedFile`
Становится тонкой обёрткой: `openInNewTab(() => загрузка Blob)` — окно сразу, байты потом, отзыв с
отсрочкой. Плейсхолдер «Загрузка PDF…» и текст отказа во вкладке переезжают в общую функцию:
`openAttachmentInNewTab` получит их же в `viewer-05`.

### Живой прогон
Новая проверка в `fields-smoke.mjs` (он уже открывает редактор документа `PDF_DOC`) либо отдельный файл
`e2e/document-preview-checks.mjs` с записью в `run-suites.mjs`. Предпросмотру нужен шаблон по умолчанию
у типа. Если у посевного типа его нет, посев (`e2e/seed.mjs`) получает многостраничный шаблон.
- Ширина окна ≥ `xl`, панель открыта.
- Прокрутка на страницу 2, правка реквизита.
- `MutationObserver` на ленте: число `canvas` ни разу не 0.
- После перегенерации поле номера говорит «2».

## Risks / Trade-offs

- [Якорь, снятый до загрузки] → снимается в момент готовности; тест компонента с подменённым движком
  крутит позицию между началом и концом загрузки.
- [Утечка документов в worker без `destroy`] → тест «`destroy` старого ровно раз» и замер DevTools →
  Memory (10 перегенераций) в описании PR.
- [Многостраничный шаблон в посеве удлиняет живые прогоны] → одна проверка, документ на 3–5 листов;
  200 листов — только ручной замер памяти.
