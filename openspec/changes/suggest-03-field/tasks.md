- [ ] 2.3 Клавиатура и принятие: нет активного пункта до стрелки, листание без `onChange`, Enter/щелчок
  — один `onChange`, Tab закрывает без принятия, Esc закрывает только список, щелчок по пункту не
  закрывает окно [UI-2]. Проверка — тесты: «Каб» → Tab оставляет «Каб» и уводит фокус; в `Modal` первый
  Esc закрывает список, второй — окно
- [ ] 2.4 Пустой ответ и отказы: пусто — списка нет; 503/403 — список не открыт, ввод цел [UI-3].
  Проверка — тесты на подменённые ответы
- [ ] 2.5 Вид: жирное совпадение, разделитель «С других строек» только при обеих группах, пункт в 1–2
  строки, 32/44 px, токены вместо цвета [UI-4]. Проверка — тесты на разделитель; `npm run ui:ratchet`
  без роста
- [ ] 2.6 Доступность: `aria-autocomplete="list"`, честный `aria-expanded`, `aria-controls` через
  `useId`, `aria-activedescendant`, `autoComplete="off"`, `listbox`/`option`, объявление числа только при
  открытии [UI-6]. Проверка — тест: два поля на форме — разные `aria-controls`; закрытый список —
  `aria-expanded="false"`
- [ ] 2.7 Телефон: список — часть поля, не слой истории [UI-7]. Проверка — тест: открытый список не
