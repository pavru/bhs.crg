# Design: компонент `SuggestField`, стрелки `EditGrid`, правило в `docs/UI.md`

Общая архитектура — `../suggest-00-epic/design.md` (D10, D12). Здесь только решения этого change.

## Context

- `TextField` (`shared/ui/TextField.tsx`) — outlined MD3 через `OutlinedField`, id от `useId` (`:28`).
- `EditGrid.tsx:146-161`: обработчик клавиш выходит по `e.defaultPrevented` и модификаторам, затем при
  ↑↓ уступает любому `role="combobox"` (`:157`). Фокусируемое в клетке — селектор `FOCUSABLE` (`:69`)
  уже включает `[role="combobox"]`.
- `Select` (`shared/ui/Select.tsx:145-153`) — Radix с порталом, слой `bg-surface border-stroke
  shadow16 rounded-md`; правила слоёв — `docs/UI.md`, «Слои над окном» (#1521).
- Слои истории на телефоне — `historyLayers` (`Modal`, `ConfirmDialog`, `CommandPalette`, меню); `Select`
  в них не входит.
- Образцы combobox в коде: `NomenclaturePicker.tsx:315` (честный `aria-expanded`, `aria-controls`
  по id) и `BaseCandidatePicker.tsx:74` (`aria-controls="bcp-listbox"` литералом, `aria-expanded` без
  значения) — как не делать.
- **Что выяснилось сверкой.** Тест `EditGrid.test.tsx:93-103` («стрелки выпадающего списка сетка не
  трогает») моделирует закрытый combobox простой кнопкой без `preventDefault` и ждёт, что ↓ фокус не
  сдвинет. После правки это поведение меняется по замыслу: тест переписывается на кнопку, которая сама
  зовёт `preventDefault` (так ведёт себя триггер Radix `Select`), плюс новый тест на текстовую ячейку.
- Макета нет: issue описывает поведение, разбор Дизайнера и Архитектора дан при согласовании эпика
  19.10.2026, но варианты вида в Claude Design не готовились, а правило «три макета» (#1545) действует
  с того же 19.10.2026.

## Goals / Non-Goals

**Goals:** один компонент на все три места подключения; сетка не теряет навигацию; поведение
клавиатуры и доступность — по APG; правило в `docs/UI.md`.

**Non-Goals:** подключение к формам, ячейкам и шагу «Новая позиция» и контекст типа-владельца
(`suggest-05`); серверный адрес (`suggest-02`) — компонент строится и тестируется на подменённом ответе.

## Decisions

- **Порядок PR.** Первый коммит — `EditGrid` (условие `aria-expanded === 'true'` вместо роли) с
  тестами; затем компонент. Без первого шага подключение в ячейки сломало бы навигацию.
- **Состав.** `SuggestField` принимает пропсы `TextField` и источник подсказок
  `{ type, field, scope?, scopeId? }`; без источника — обычный `TextField` (для мест, где правило
  `Suggestable` сказало «нет», компонент не зовёт адрес вовсе). Вариант для ячейки — `compact`, без
  подписи в вырезе, с `aria-label` (ячейки рисуют свою рамку).
- **Слой.** Radix Popover с `Popover.Anchor` на рамке поля, портал в body без `container`, фокус
  остаётся в поле (`onOpenAutoFocus` гасится), `collisionPadding` и `hideWhenDetached` — по правилам
  «Слои над окном». Щелчок по пункту — `onPointerDown` с `preventDefault`, чтобы поле не потеряло фокус и
  окно не сочло щелчок «мимо».
- **Клавиатура.** Состояние «активный пункт» живёт в компоненте и начинается с «никакого»; ↓/↑ двигают
  его, текст не трогают. Enter при активном пункте — `onChange(value)` и `preventDefault` (форма не
  отправляется); без активного — Enter не перехватывается. Tab — закрыть и не мешать. Esc при открытом
  списке — закрыть и `stopPropagation`, чтобы окно не закрылось; при закрытом — не перехватывается.
- **Данные.** Хук `useFieldSuggestions` в `shared/api/fieldSuggestions.ts`: React Query, ключ
  `['field-suggestions', type, field, scope, scopeId, q]`, `staleTime` 60 с, `signal` для отмены;
  задержка 200 мс — в компоненте до смены `q` в ключе. Ошибка любого вида — список закрыт, без тоста.
- **Вид.** Совпадение — `font-semibold` на префиксе слова, найденном той же нормализацией, что сервер
  (регистр, ё→е); разделитель — `text-caption text-fg3` строкой «С других строек»; пункт —
  `line-clamp-2`, высота `min-h-8` / `pointer-coarse:min-h-11`. Цвет — только токенами.
- **Объявление числа.** Скрытая `aria-live="polite"` область обновляется при открытии списка («N
  подсказок»), при листании — нет.
- **Макеты.** Варианты различаются решением, а не цветом: например, список под полем во всю ширину
  против узкого по тексту; разделитель групп строкой против подписи группы; место списка в ячейке сетки.
  Выбранный вариант и ссылка — в этом `design.md` и в описании PR.
- **Чем ломается.** Уступка стрелок по роли — красный тест «↓ в текстовой ячейке при закрытом списке
  переходит на строку ниже». Принятие пункта листанием — красный тест «листание не зовёт `onChange`».
  Свой выпадающий список без портала — правило «Слои над окном».

## Risks / Trade-offs

- [Radix Popover и поле спорят за фокус] → фокус не уходит в слой вовсе; пункты — `option` с
  `aria-activedescendant`, а не фокусируемые кнопки.
- [Подсказка закрывает следующее поле формы] → список открывается только набором, Tab закрывает без
  принятия.
