# Spec Delta: plan

## ADDED Requirements

### Requirement: [PLAN-16] [WORK-43] Выработка у работы графика
Ответ графика SHALL нести у каждой работы выработку её вида работ из контракта «Выработка» модуля
`work` — объём на час и размер выборки, с состоянием. Экран графика показывает её рядом с объёмом
работы. При выключенном учёте работ MUST приходить состояние «учёт работ не подключён», без права
`work.facts.read` — «скрыто правами» с кодом права, при малой выборке — «данных мало»; нулевая выработка
вместо состояния MUST NOT отдаваться.

#### Scenario: Выработка есть
- **WHEN** по виду работы «Прокладка кабеля» принятых отчётов с одним видом работ достаточно
- **THEN** у работы графика рядом с объёмом стоит «м/ч» и «по 14 отчётам, 3 стройки», без часов и имён

#### Scenario: Учёт работ выключен
- **WHEN** график читают на экземпляре без модуля `work`
- **THEN** у работ состояние выработки «не подключено», числа нет

#### Scenario: Без права на факты
- **WHEN** график открывает пользователь без `work.facts.read`
- **THEN** у работ состояние выработки «скрыто правами» с кодом `work.facts.read`, а график показан, как прежде

#### Scenario: Данных мало
- **WHEN** по виду работы отчётов меньше порога выборки
- **THEN** у работы стоит «данных мало» с размером выборки, а не число
