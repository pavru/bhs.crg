# Spec Delta: sharedui

## ADDED Requirements

### Requirement: [UI-81] Сообщение экрана — баннер, а не плашка
Сообщение экрана о его состоянии (данные устарели, повторное чтение не удалось, исправление открыто,
уровень схемы) SHALL быть `Banner` вверху содержимого. Короткое сообщение о поле — supporting text этого
поля. Плашку из заливки, обводки и радиуса экраны MUST NOT рисовать: правило `notice-plaque` стоит на нуле
во всём `src/`.

#### Scenario: Устаревший счёт
- **WHEN** открыт счёт, данные которого изменили в другом месте
- **THEN** сообщение об этом — баннер во всю ширину вверху содержимого с действием «Обновить», а не
  плашка в теле формы

#### Scenario: Новая плашка
- **WHEN** в файл экрана добавлен `div` с заливкой роли `*-container`, обводкой и радиусом
- **THEN** `npm run ui:ratchet` красный, правило `notice-plaque` называет файл и `Banner`

### Requirement: [UI-81] Карточка экрана — `Card`
Каждая карточка экрана SHALL быть `Card`. Правило `hand-card` MUST стоять на нуле во всём `src/`: новая
карточка руками краснит храповик сразу, без уровня.

#### Scenario: Карточка шага документа
- **WHEN** открыт редактор документа с карточками разделов
- **THEN** каждая карточка — `Card` вида outlined, у всех один радиус 12 и одна обводка

#### Scenario: Уровень пуст
- **WHEN** открыт `src/client/ui-baseline.json` после последнего PR
- **THEN** у правил `hand-card` и `notice-plaque` нет ни одного файла

### Requirement: [UI-81] Боковая панель экрана — `SideSheet`
Боковая панель экрана (карточка номенклатуры, предпросмотр документа, строка таблицы) SHALL быть
`SideSheet` — standard или modal по смыслу. Своих панелей с собственной шапкой, шириной и закрытием экраны
MUST NOT заводить.

#### Scenario: Карточка номенклатуры
- **WHEN** у позиции счёта открыта карточка номенклатуры
- **THEN** это side sheet с заголовком `title-large` и крестиком; Esc и «Назад» ведут себя так же, как у
  остальных листов

### Requirement: [UI-81] Только шкалы MD3
Экраны и `shared/` SHALL брать радиус, тень и размер текста только ступенью шкал MD3 (`rounded-xs…xl`,
`shadow-elevation-1…5`, роли текста). Правила `legacy-radius`, `legacy-shadow`, `legacy-type` MUST стоять
на нуле во всём `src/`.

#### Scenario: Старый радиус
- **WHEN** в файл добавлен `rounded-lg` прежней шкалы (10 px)
- **THEN** `npm run ui:ratchet` красный, правило `legacy-radius` называет файл и ступени шкалы MD3

#### Scenario: Свой размер текста
- **WHEN** в файл добавлен `text-xs` вместо роли текста
- **THEN** `npm run ui:ratchet` красный, правило `legacy-type` называет файл и роли MD3

### Requirement: [UI-81] Перевод экрана не меняет его состав
Перевод экрана на готовые компоненты SHALL сохранять состав, раскладку и шаги экрана. Если замена плашки
баннером или панели листом меняет место сообщения или раскладку, правка MUST идти по макетам и выбору
владельца (`docs/UI.md`, «Новый экран: порядок»).

#### Scenario: Баннер меняет место сообщения
- **WHEN** плашка стоит в середине формы, а баннер встаёт вверху содержимого
- **THEN** в описании PR названы макет, выбранный вариант и ссылка
