# Proposal: экраны без самоделок — плашки, карточки, поля и остатки шкал

Дочерний change зонтика `sharedui-md3-00-epic`, общая архитектура — `../sharedui-md3-00-epic/design.md`
(D2, D8, D9, D10, D11).

## Why

Дети 10–16 перекрашивают `shared/ui`. Но до того, что экраны рисуют сами, рестайл не доходит (D9). После
них в `features/` остаются четыре вида самоделок (уровни `ui-baseline.json` на 03.11.2026):
- **плашки-сообщения** — заливка `*-container` с обводкой и радиусом: 32 места в 25 файлах;
- **карточки руками** — `bg-surface border rounded-*`: 67 мест в 49 файлах; половина из них не карточки, а
  заметки, поля только для чтения, плитки значений и миниатюры;
- **сырые поля со своей рамкой** — 77 мест в 43 файлах (`raw-field`, ноль — здесь по решению владельца в 11);
- **остатки старых шкал** — радиусы (6), тень (1) и текст (39 мест в 31 файле), которые кодмоды 06 и 07
  оставили как неоднозначные (D3).

Правила `notice-plaque` (12), `hand-card` (13), `raw-field` (11), `legacy-radius`, `legacy-shadow` (06) и
`legacy-type` (07) держат уровень по файлам, и ноль у них — здесь. Пока они не на нуле, финал
`sharedui-md3-20-legacy-removal` удалил бы псевдонимы под живыми классами.

## What Changes

Раздел 0 закрыт 03–04.11.2026: разбор Дизайнера и Архитектора, три макета в Claude Design (проект
«Экраны без самоделок (md3-17)», 4f525fa0), выбор владельца — **А «MD3 буквально» по всем девяти
развилкам**:
- **Сообщение области → `Banner` в начале своей области** (окна, панели деталей, страницы); сообщение об
  одном поле — ошибка или подсказка этого поля. «Такая запись есть в архиве» — banner вверху формы с
  действиями «Вернуть из архива» и «Создать новую». Нейтральная заметка — `Banner tone="info"`;
  переключатель взглядов затрат — строкой под ним.
- **Карточки → `Card`** (outlined, filled или elevated по смыслу); у `Card` появляются состояния
  перетаскиваемой карточки, цели перетаскивания и ошибки. Шаг конструктора XPath и группа фильтра — `Card
  outlined` на уровень вложенности. Карточка стройки — кликабельный `Card` целиком; «избранное»,
  «переименовать» и «удалить» уходят в шапку страницы стройки.
- **Поле только для чтения → `TextField readOnly`**: одна строка, полностью — в подсказке.
- **Плитка значения (ссылка, файл, сводка составного) → чип**: input chip со знаком вида (щелчок — заменить,
  крестик — снять), сводка составного — assist chip, открывающий окно.
- **Миниатюры** — медиа без обводки на `surface-container-highest`, форма 12; выбранная — галка в круге и
  обводка 2 px `primary`.
- **Панель выделения → контекстная шапка**: при выборе шапка области сменяется полосой «✕ Выбрано: N» с
  действиями — новый общий компонент.
- **Боковые колонки → `SideSheet standard` 400**: предпросмотр документа открывается переключателем в
  шапке документа (полоса 44 px уходит), карточка номенклатуры в окне выбора — по выбору строки, с
  заголовком и крестиком; фокус остаётся в поиске, Esc закрывает сначала лист.
- **Сырые поля → `TextField` / `TextAreaField`** или плотное поле (`density="dense"`).
- **Остатки шкал** — радиусы, тени и роли текста — по месту, ступенью MD3. Флажок 2 px (форма checkbox
  MD3) — названное исключение правила `legacy-radius`, а не уровень.
- **Сначала компоненты, потом экраны** — шесть PR:
  0. `shared/ui`: контекстная шапка выбора, состояния `Card`, `SideSheet` в окне; `/design-sync`;
  1. `settings` с `account`, `auth`, `activity`, `jobs`, `notifications` и экраном входа;
  2. `datasets`, `templates`, `tables`;
  3. `document-sets` с `quality-docs`, `catalog`, `common-data`;
  4. `costs` с `planning`, `periods`, `reconciliations` — без файлов экрана счёта;
  5. остатки в `shared/`, файлы экрана счёта и правила в ноль.
- **Шесть правил** — уровень убывает с каждым PR и становится нулём в последнем; дальше новое нарушение
  краснит сразу.

## Capabilities

### New Capabilities
- Нет.

### Modified Capabilities
- `sharedui`: экраны без самоделок — сообщения баннером, карточки `Card` с состояниями, значения чипами,
  выбор контекстной шапкой, боковые панели `SideSheet`, поля `TextField`, только шкалы MD3; шесть правил
  храповика на нуле [UI-81].

## Impact

- **Клиент:** `shared/ui` — новый компонент контекстной шапки выбора, свойства `Card` и `SideSheet`
  (PR 0); `features/**` по разделам; остатки `shared/` — 7 мест (`Checkbox`, `ListDetailShell`, `Markdown`,
  `SectionRail`, `SuggestBox`, `siteFilter/SitesFilter`) и одно `raw-field`.
- **Страница стройки** получает «избранное», «переименовать» и «удалить» в шапку (карточка стройки
  становится кликабельной целиком).
- **Сторожа:** `ui-baseline.json` — уровни шести правил вниз до нуля; `skip` флажка у `legacy-radius`;
  тест пустого уровня — новым файлом (`ui-ratchet.test.mjs` и `ui-ratchet-lib.mjs` — у порога 500 строк).
- **Экран счёта** — у него свои change `costs-invoice-screen-10…13`. Его файлы (16 мест) этот change не
  трогает до их архива и доводит в PR 5б (`shared/` — раньше, в PR 5а).
- **`sharedui-md3-18-lists`** правит те же файлы `settings`, `datasets`, `catalog`, `templates`: кто
  сливается вторым, тот обновляет ветку.
- **Параллельные ветки** (`plan-17`, `plan-20`, `work-12`, `work-21`, `work-22`, `work-23`, строки
  счёта) пишут на готовых компонентах. Правила с уровнем не дадут им добавить самоделку.
- **Живые прогоны:** весь список в каждом PR (экраны тех разделов, что правились).
- **Claude Design:** макеты раздела 0 — проект 4f525fa0; после PR 0 — `/design-sync` (новые компоненты и
  свойства).
- **Сервер:** не меняется.
- **PR:** шесть. Каждый с меткой `version:minor`.
