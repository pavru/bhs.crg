# Spec Delta: costs

## ADDED Requirements

### Requirement: [COST-16] [CORE-36] Исправление накладной закрытого периода
Содержимое проведённой накладной, запертой закрытым периодом, SHALL менять только
`POST /api/costs/waybills/{id}/correction`: обязательная причина и всё содержимое (шапка и строки с
позициями номенклатуры) одним телом, `If-Match`, право `costs.waybill.correct`. Исправление MUST писать
версию с прежним содержимым, причиной, автором и временем; накладная остаётся проведённой.

#### Scenario: Исправление с причиной
- **WHEN** пользователь с правом исправления исправляет строки запертой накладной и называет причину
- **THEN** накладная меняется, прежнее содержимое лежит версией с этой причиной, журнал называет исправление

#### Scenario: Без причины
- **WHEN** исправление прислано с пустой причиной
- **THEN** ответ 400, накладная не меняется

#### Scenario: Без права исправления
- **WHEN** исправление вызывает пользователь с `costs.waybill.edit`, но без `costs.waybill.correct`
- **THEN** ответ 403

#### Scenario: Без версии и по устаревшей версии
- **WHEN** исправление вызвано без `If-Match` или с устаревшей версией накладной
- **THEN** ответ 400 или 409 соответственно

#### Scenario: Модуль выключен
- **WHEN** модуль `costs` выключен
- **THEN** адрес исправления отвечает отказом выключенного модуля, как все адреса модуля

#### Scenario: Отмена закрытия периода
- **WHEN** закрытие периода исправленной накладной отменили
- **THEN** накладная правится обычной правкой с журналом, как любая проведённая открытого периода; версии
  и пометка «исправлена после закрытия» остаются

#### Scenario: Исправление не нужно
- **WHEN** исправляют черновик или проведённую накладную открытого периода
- **THEN** ответ 409 «исправление не нужно» с выходом — обычная правка

### Requirement: [COST-16] Запертая накладная мимо исправления не меняется
Каждый пишущий адрес накладной, кроме исправления, SHALL отвечать запертой накладной 409 «заперта» — с
выходом через исправление, а не только через отмену закрытия периода.

#### Scenario: Правка строк запертой накладной
- **WHEN** пользователь сохраняет строки, сопоставляет строку или возвращает в черновик запертую накладную
- **THEN** ответ 409 «заперта», в отказе назван выход «исправить с причиной»

### Requirement: [CORE-36] Версии накладной и пометка исправления
История накладной SHALL читаться `GET /api/costs/waybills/{id}/versions` под `costs.waybill.read` —
версии с номером, причиной, автором и временем. Список накладных MUST помечать исправленную после
закрытия; «Материалы на объекте» MUST читать только действующее содержимое.

#### Scenario: Прежняя версия видна
- **WHEN** накладную исправили дважды
- **THEN** карточка показывает две версии с причинами, а действующее содержимое — исправленное

#### Scenario: Материалы на объекте после исправления
- **WHEN** исправление сменило количество в строке накладной
- **THEN** перечень отпущенного по стройке показывает новое количество и не складывает его с версией

### Requirement: [COST-28] [COST-29] Право `costs.waybill.correct`
Модуль SHALL объявлять право `costs.waybill.correct` «исправлять накладные закрытого периода» с
зависимостью `costs.waybill.edit`; в «Читать всё» оно не входит. Право MUST NOT открывать счета: право на
накладные не даёт права на счета (`COST-29`).

#### Scenario: Кладовщик с правом исправления
- **WHEN** у роли есть `costs.waybill.edit` и `costs.waybill.correct`, но нет прав на счета
- **THEN** накладные закрытого периода исправляются, а адреса счетов отвечают 403

#### Scenario: Зависимость права
- **WHEN** роли выдают `costs.waybill.correct` без `costs.waybill.edit`
- **THEN** редактор ролей добавляет зависимость, как у прочих прав модуля
