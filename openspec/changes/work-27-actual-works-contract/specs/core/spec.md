# Spec Delta: core

## ADDED Requirements

### Requirement: [CORE-34] [WORK-57] Расширение формы «Фактических работ» поставщиком `work`
Форма контракта «Фактические работы» SHALL нести к счётчикам не вошедшего (ждут приёмки, бригадные
группы не сверены) третий — принятые строки без позиции перечня. Кроме часов и сотрудников, в форме
ответа MUST NOT быть полей автора, учётной записи и отчёта: по ним часы восстанавливаются соединением с
табелем. Имеющиеся поля формы расширение не меняет.

#### Scenario: Строки без позиции перечня
- **WHEN** на стройке две принятые строки без позиции перечня, и потребитель читает факты стройки
- **THEN** ответ несёт счётчик «без позиции перечня: 2», а объёмов этих строк в фактах нет

#### Scenario: Поле отчёта или автора в форме
- **WHEN** в запись ответа контракта добавлено поле отчёта, автора или учётной записи
- **THEN** тест формы падает с названием поля

#### Scenario: Потребитель формы до расширения
- **WHEN** «Ход работ» читает факты после расширения формы
- **THEN** колонка факта и счётчики «ждут приёмки» и «не сверены» приходят, как прежде
