# Подключение Android к экземпляру заказчика

## ADDED Requirements

### Requirement: [MOB-4] [MOB-5] [MOB-6] [MOB-7] [MOB-8] Первое подключение

Один APK SHALL подключаться по публичной ссылке `/m/join` после установки или по приглашению в уже установленном приложении. Для внутреннего сертификата и ручного ввода MUST сохраняться проверка ключа. Пользователь подтверждает полученное от сервера название организации.

#### Scenario: Первое подключение в работе

- **WHEN** камера запрещена, приложение передано мессенджером
- **THEN** ручной путь завершает то же подключение с проверкой ключа и подтверждением организации; отказ пользователя не сохраняет привязку.

### Requirement: [MOB-9] [MOB-10] [MOB-11] [MOB-12] Транспорт экземпляра

Приложение MUST поддерживать https-system, https-pinned и явно выбранный http только для адреса приглашения. Режим http постоянно виден. Подтверждённый переход http → https при запросе сведений SHALL обновить сохранённый адрес. Понижение защиты и несовпадение ключа запрещают отправку.

#### Scenario: Транспорт экземпляра в работе

- **WHEN** первичный адрес перенаправляет на HTTPS, а позже POST получает перенаправление вниз
- **THEN** отчёт отправляется прямо по сохранённому HTTPS; при понижении очередь сохранена и видна причина.
