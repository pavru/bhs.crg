# Spec Delta

## ADDED Requirements

### Requirement: [UI-89] Площадка выбора и броска файла
Окно или форма, куда кладут файл, SHALL принимать его общей площадкой `FileDropZone` из `shared/ui`, а не
своей разметкой. Площадка принимает файл броском и кнопкой выбора; путь MUST NOT менять того, что получит
экран. Пока над окном тащат файл, площадка SHALL показывать, что она наготове, и отдельно — что файл над
ней. Цель на всё окно ([COST-6.7]) и скрытый выбор из меню — другие входы, не площадка.

#### Scenario: Бросок
- **WHEN** на площадку окна «Загрузка сметы» брошен файл `смета.gsfx`
- **THEN** окно получает этот файл, а площадка показывает его имя и размер и кнопку «Другой файл»

#### Scenario: Выбор
- **WHEN** на площадке нажата кнопка выбора, и в окне выбора файлов указан `смета.gsfx`
- **THEN** окно получает тот же файл, что и при броске, и площадка выглядит так же

#### Scenario: Тот же файл ещё раз
- **WHEN** через кнопку выбора второй раз подряд указан тот же файл
- **THEN** окно получает его снова: повтор после неудачи не выглядит как «кнопка не работает»

#### Scenario: Наготове
- **WHEN** над окном тащат файл, а курсор ещё не дошёл до площадки
- **THEN** площадка показывает, что принимает бросок; когда курсор над ней — показывает «отпустите»

#### Scenario: Тащат не файл
- **WHEN** над площадкой тащат выделенный текст или строку списка
- **THEN** площадка не меняется и бросок не принимает

#### Scenario: Выбранный файл заменяется броском
- **WHEN** файл уже выбран, и на площадку брошен другой годный файл
- **THEN** окно получает новый файл, а площадка показывает его имя вместо прежнего

#### Scenario: Касание без мыши
- **WHEN** окно открыто на телефоне, где основной указатель — касание
- **THEN** площадка не предлагает перетащить файл, а кнопка выбора называет, какой файл выбрать

#### Scenario: Промах мимо площадки
- **WHEN** файл отпущен в окне рядом с площадкой, но не на ней
- **THEN** браузер файл не открывает, окно не теряет введённого, площадка ничего не получает

### Requirement: [UI-89] Отказ площадки — словами и на месте
Файл, который площадка не примет, SHALL получать отказ с причиной под площадкой, пока не придёт следующий
файл. Отказ MUST NOT уходить в снэкбар и MUST NOT быть молчаливым. Отказанный файл экрану не отдаётся.

Площадка SHALL называть сама:
- папку — по имени;
- несколько файлов, когда ждут один;
- пустой файл;
- файл не того вида — по перечню видов, который назвал экран;
- файл больше предела — с пределом.

Свою проверку экран SHALL добавлять тем же отказом, а не вторым местом для слов.

#### Scenario: Не тот вид
- **WHEN** на площадку «Файл сметы» брошен `счёт.pdf`, а площадка принимает `.gsfx` и `.xml`
- **THEN** под площадкой — отказ «счёт.pdf — не файл сметы: нужен .gsfx или .xml», окно файла не получает

#### Scenario: Больше предела
- **WHEN** на площадку с пределом 50 МБ брошен файл в 60 МБ
- **THEN** отказ называет файл и предел 50 МБ, окно файла не получает

#### Scenario: Несколько файлов там, где ждут один
- **WHEN** на площадку одного файла брошены три файла
- **THEN** отказ просит класть их по одному, окно не получает ни одного

#### Scenario: Папка
- **WHEN** на площадку брошена папка «Сканы»
- **THEN** отказ называет папку «Сканы» по имени: внутрь площадка не заходит

#### Scenario: Следующий файл снимает отказ
- **WHEN** после отказа брошен или выбран годный файл
- **THEN** отказ исчезает, окно получает файл

#### Scenario: Окно выбора тоже проверяется
- **WHEN** в окне выбора файлов указан «Все файлы» и выбран файл не того вида
- **THEN** отказ тот же, что при броске: фильтр окна выбора — подсказка, а не проверка

### Requirement: [UI-89] Площадка во время загрузки
Пока экран отправляет файл, площадка SHALL показывать ход и MUST NOT принимать новый файл ни броском, ни
выбором. Бросок в это время получает курсор «нельзя» и не отменяет начатую загрузку.

#### Scenario: Бросок во время загрузки
- **WHEN** окно «Заменить файл…» отправляет файл, и на площадку бросают второй
- **THEN** курсор показывает «нельзя», второй файл окну не отдаётся, первая загрузка идёт дальше

#### Scenario: Кнопка во время загрузки
- **WHEN** идёт загрузка
- **THEN** кнопка выбора выключена, а площадка называет, что идёт загрузка

### Requirement: [UI-89] Площадка с клавиатуры и для диктора
Площадка SHALL работать без мыши: кнопка выбора достижима клавишей Tab и открывает окно выбора файлов
клавишами Enter и пробел. Скрытое поле файла SHALL иметь имя, которое назвал экран (например, «Файл
сметы»). Отказ и смена выбранного файла SHALL доходить до диктора без перевода фокуса.

#### Scenario: Только клавиатура
- **WHEN** человек доходит до площадки клавишей Tab и нажимает Enter
- **THEN** открывается окно выбора файлов

#### Scenario: Диктор слышит отказ
- **WHEN** брошен файл не того вида
- **THEN** диктор читает отказ, а фокус остаётся, где был
