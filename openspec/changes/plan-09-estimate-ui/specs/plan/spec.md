# Spec Delta: plan

## ADDED Requirements

### Requirement: [PLAN-20] Экран смет: пункт стройки и раздел модуля
Сметы стройки SHALL открываться пунктом «Сметы» в карточке стройки и глобальным разделом модуля. Пункт
MUST быть виден только пользователю с правом на сметы; у модуля на странице стройки не больше двух
пунктов.

#### Scenario: Сметчик на странице стройки
- **WHEN** сметчик открывает стройку
- **THEN** в карточке есть пункт «Сметы» со сметами этой стройки

#### Scenario: Без прав на сметы
- **WHEN** стройку открывает пользователь без `plan.estimate.read`
- **THEN** пункта «Сметы» в карточке нет

### Requirement: [PLAN-5.2] [PLAN-2] Карточка сметы: редакции, строки и деньги по праву
Карточка сметы SHALL показывать редакции с признаками «действующая» и «зафиксирована» (чем) и строки
редакции с пометками сервера. Без `plan.estimate.cost` колонок стоимости MUST NOT быть, а над таблицей
MUST стоять строка «стоимость скрыта» с названием права.

#### Scenario: Сметчик без права на стоимость
- **WHEN** карточку открывает пользователь с `plan.estimate.read` без `plan.estimate.cost`
- **THEN** колонок стоимости нет, над таблицей — «стоимость скрыта: нужно право „…“»

#### Scenario: Зафиксированная редакция
- **WHEN** из редакции сделано КП
- **THEN** у редакции видно «зафиксирована: КП № …», действия правки строк скрыты

#### Scenario: Сделать действующей
- **WHEN** сметчик делает действующей новую редакцию
- **THEN** окно показывает расхождения плана по видам работ, посчитанные сервером, и просит подтверждения
  (решение В-5)

### Requirement: [PLAN-7] Экран импорта: отчёт разбора и решение человека
Экран импорта SHALL показывать ход разбора и отчёт «импортировано N строк из M, K не разобраны» с
раскрытием не разобранных строк и причин. Редакция MUST создаваться только действием человека, в том
числе при неполном разборе.

#### Scenario: Неполный разбор
- **WHEN** разобрано 280 строк из 300
- **THEN** экран показывает «280 из 300, 20 не разобраны ▸», и редакция не создана, пока сметчик не выбрал
  «создать»

#### Scenario: Куда импортировать
- **WHEN** сметчик загружает файл в стройку, где уже есть сметы
- **THEN** он выбирает «новая редакция сметы X» или «новая смета» (решение В-12)

### Requirement: [PLAN-6.1] [PLAN-9.1] Экран сопоставления
Окно сопоставления SHALL сопоставлять строки по разделу ЛСР целиком и построчно, показывать коэффициент
пересчёта с обеими единицами и пометку «запомнено» с отменой. Действие «новый вид работы» MUST быть
видно только при `core.worktypes.edit`. Материалы ресурсов сопоставляются с показом похожих позиций.

#### Scenario: Раздел целиком
- **WHEN** сметчик выбирает вид работы для раздела ЛСР
- **THEN** все подходящие строки сопоставлены, пропущенные названы с причиной

#### Scenario: Без права на виды работ
- **WHEN** окно открывает пользователь без `core.worktypes.edit`
- **THEN** действия «новый вид работы» в окне нет

#### Scenario: Конфликт версии
- **WHEN** сохранение сопоставления получает 409
- **THEN** экран говорит «редакцию тем временем изменили — перечитайте», набранное не теряется
