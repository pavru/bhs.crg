# Proposal: экраны смет — список, карточка с редакциями, импорт, сопоставление

Дочерний change зонтика `plan-00-epic`, общая архитектура — `../plan-00-epic/design.md` (D3, D4, D6, D8,
D17, D18).

## Why

Сервер смет (`plan-06`), импорта (`plan-07`) и сопоставления (`plan-08`) без экрана никому не виден.
Сметчик работает так: открывает стройку, видит её сметы, загружает файл ЛСР, видит «импортировано 280
строк из 300, 20 не разобраны ▸» и решает, создавать ли редакцию (`PLAN-7`), сопоставляет строки с
видами работ и материалы с номенклатурой (`PLAN-6.1`, `PLAN-9.1`), отмечает действующую редакцию
(`PLAN-5.2`). На странице стройки модуль занимает не больше двух пунктов, и сметы — первый из них
(`PLAN-20`). Пользователь без `plan.estimate.cost` видит смету без денег — и говорит ему об этом экран, а
не пустые ячейки (D4).

## What Changes

- **Макеты П1** — три варианта в Claude Design, выбор владельца; код — после выбора.
- **PR 1 — список и карточка.**
  - Панель «Сметы» в карточке стройки (механизм панелей `plan-02`) и глобальный раздел «Сметы» модуля
    со стройкой в строке.
  - Карточка сметы: редакции (номер, дата, файл, «зафиксирована: КП № … / график …», «действующая»),
    строки редакции на `DataGrid` (раздел ЛСР, шифр, наименование, объём, единица, вид работы,
    пометки; стоимость — только с `plan.estimate.cost`, иначе строка «скрыто правами»).
  - «Сделать действующей» с предпросмотром расхождений с прежней действующей (ждёт решения В-5).
- **PR 2 — импорт.** Загрузка файла в смету («новая редакция сметы X» или «новая смета», ждёт решения
  В-12), ход разбора, отчёт «N из M, K не разобраны ▸» с причинами, «создать редакцию» / «отказаться».
  ВОР и КА загружаются приложениями к смете (ждёт решения В-7; КА — `plan-11`).
- **PR 3 — сопоставление.** Окно сопоставления строк: по разделам ЛСР, массово и построчно, коэффициент
  пересчёта с обеими единицами, «запомнено» с отменой, новый вид работы из окна (при
  `core.worktypes.edit`). Сопоставление материалов ресурсов: похожие позиции, «запомнено», новая
  позиция явным действием. Списки запомненного с «забыть».
- Живой прогон смет и посев сметы в `e2e/seed.mjs`.
