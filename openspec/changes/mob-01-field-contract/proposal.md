# Постоянные адреса полевого API и контракт v1

## Why

Заказчику нужен один публикуемый вход для телефона. Установленный APK должен узнать сервер и свою совместимость после обновления экземпляра.

## What Changes

- Зафиксировать четыре постоянных операции, границу v1, модель причины отказа и примеры запросов и ответов старого клиента.
- Зафиксировать формы подключения и refresh для MOB-02. Опубликовать сведения и проверку связи. Добавить проверку перечня маршрутов при включённом и выключенном Work и пример двух префиксов прокси.
- Закрепить совместимость снимком контракта, в том числе коды, типы, обязательность и сохранение семантики старых ответов.

Требования [MOB-13] [MOB-14] [MOB-22] [CORE-25.2].

## Capabilities

### New Capabilities

- `field` — Постоянные адреса полевого API и контракт v1.

### Modified Capabilities

Действующие области сохраняют договор.

## Impact

Хост API, WorkModule.RoutePrefixes, публикующий прокси и контрактные тесты сервера.
