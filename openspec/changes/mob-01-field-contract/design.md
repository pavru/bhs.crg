# Постоянные адреса полевого API и контракт v1

## Context

Хост API, WorkModule.RoutePrefixes, публикующий прокси и контрактные тесты сервера. Опоры и границы описаны в [эпике](../mob-00-epic/design.md). Условие старта — подтверждённый канал установки, пункт 0.1 зонтика.

## Goals / Non-Goals

Заказчику нужен один публикуемый вход для телефона. Установленный APK должен узнать сервер и свою совместимость после обновления экземпляра. Объём и наблюдаемый результат закреплены в [дельте field](specs/field/spec.md).

## Decisions

Владельцем предметных операций остаётся Work. Выделить для устройства отдельную схему аутентификации. В сведениях о сервере вернуть название и логотип организации, поддерживаемый протокол и минимальную версию отправителя. Офисное управление остаётся под обычными воротами. Не связывать внешний адрес с исходящим прокси экземпляра.

Поставка MOB-01 включает исполняемые сведения и проверку связи и контрактные примеры остальных постоянных адресов. Подключение и refresh становятся исполняемыми в MOB-02. Проверка полного пути подключения относится к MOB-02, отчётов — к MOB-03. Минимальная версия отправки объявляется сведениями, отказ записи по ней реализует MOB-03.

Хост регистрирует публичные операции только при включённом Work. Группа офисного модуля сохраняет свою политику авторизации. Work объявляет оба префикса. При выключении модуля штатный AppModuleExtensions.Refuse отдаёт прежние HTTP 501, `module` и `error` с дополнительным полем `reason: "module-disabled"`. Это согласованное дополнение общего отказа распространяется также на офисные маршруты. Снимок клиента хранится в [docs/field](../../../docs/field/README.md).

Решение владельца от 28.11.2026 по MOB-7: поле `organizationName` получает действующее `BrandingInfo.ProductName` через `IBrandingService`. Без своей настройки возвращается штатное имя оформления. Логотип берётся из того же источника, его адрес доступен под полевым префиксом.

## Risks / Trade-offs

Старый APK зависит и от кодов, и от обязательности полей. Запускать сохранённые запросы старой версии на новом сервере, включая экземпляр только с Work.
