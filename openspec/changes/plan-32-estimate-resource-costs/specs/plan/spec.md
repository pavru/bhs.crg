## ADDED Requirements

### Requirement: [PLAN-7] [PLAN-8] [PLAN-9.1] Цена и сумма материала в текущих ценах ЛСР

Импорт ЛСР SHALL сохранять отдельно текущую цену единицы и стоимость всего учтённого ресурса после применённых сметой поправок. Сохранённая расшифровка ресурса имеет приоритет. Досчёт MUST опираться на подтверждённый профиль метода и исходные значения. Каждое недоказанное значение остаётся пустым независимо от другого. Явный ноль сохраняется числом.

#### Scenario: Самостоятельная строка по КА в БИМ
- **WHEN** импортирована позиция 85 из `lsr-16.2.2-sks.gsfx` с единственным собственным материалом, 76 шт. по 5,01 и применённым множителем 1,02
- **THEN** в редакции цена материала равна 5,01, сумма равна 388,38, налоговая основа подтверждена без НДС
- **AND** базисные 37,09 и сумма 473,65 из формы выполнения в эти поля не попадают

#### Scenario: Записанные суммы двух ресурсов работы
- **WHEN** импортирована позиция 1 из `lsr-16.2.3-rim1.gsfx`
- **THEN** у воды цена 38,42 и сумма 12,64, у сверла цена 1514,46 и сумма 214,14
- **AND** труд, машины, накладные расходы и прибыль не входят в эти суммы

#### Scenario: Парный файл РИМ без дерева итогов
- **WHEN** импортирована та же позиция из `lsr-16.3.0-rim1-no-itog.gsfx` в поддержанном профиле РИМ
- **THEN** получены те же две суммы с округлением каждого материала до копеек

#### Scenario: Одна материальная статья работы БИМ
- **WHEN** позиция 1 файла СКС содержит несколько материалов, а в итоге статьи М указаны только 95,49 на все материалы
- **THEN** у каждого материала без индивидуального подтверждения сумма неизвестна, итог работы остаётся доступен

#### Scenario: Самостоятельная строка сборника
- **WHEN** в позиции 107 файла СКС шифр ФСБЦ, единственная статья базисной цены — материалы, итог строки в текущих ценах по эталону 1076,11
- **THEN** единственный собственный материал получает 1076,11, наличие справочной текущей цены в файле само по себе не доказывает цену активного расчёта

#### Scenario: Недостаточные данные
- **WHEN** у ресурса есть текущая цена, но неоднозначна привязка расшифровки и нет подтверждённого способа досчёта
- **THEN** доступная цена сохраняется, сумма пуста, строка и её доступные количества сохраняются
- **AND** если известна только базисная цена и нужен неподдержанный индекс, текущая цена и сумма остаются пустыми при отсутствии прямой текущей расшифровки

#### Scenario: Прямое нулевое значение
- **WHEN** у учтённого материала в соответствующей ему текущей расшифровке явно записана нулевая сумма
- **THEN** материал получает 0,00, в том числе когда цена единицы неизвестна

### Requirement: [PLAN-9.1] [PLAN-23] Основа сметной суммы в денежных ответах

Денежный ответ по материалу SHALL различать подтверждённую основу без НДС и неподтверждённую основу. Известная текущая сумма с неизвестной основой MUST сохранять число с явным признаком неопределённости для потребителя. Группа имеет подтверждённую основу только при подтверждении всех вкладов. При отсутствии суммы хотя бы одного вошедшего ресурса сумма группы MUST быть пустой.

#### Scenario: Номинальная сумма и неизвестная основа
- **WHEN** у двух вошедших ресурсов одной номенклатуры суммы 100 и 20, у второго основа неизвестна
- **THEN** с правом на стоимость потребитель получает 120 с признаком неподтверждённой основы, точное сравнение без НДС по такому числу невозможно
- **AND** если у второго неизвестна сама сумма, результат пуст, если его сумма явно 0 без НДС и первая основа тоже подтверждена, результат равен 100 без НДС

### Requirement: [PLAN-5.1] [PLAN-9.1] Стоимость импортированного ресурса после сопоставления

«Плановые работы» SHALL учитывать суммы материалов действующих редакций по номенклатуре и доле строки в выбранном разделе. Последующее сопоставление MUST открывать уже сохранённую сумму без повторного импорта. Чтение материалов без права на себестоимость MUST сохранять действующую форму скрытия во всех ответах, включая результаты команд.

#### Scenario: Материал без номенклатуры и работа без позиции перечня
- **WHEN** в действующей редакции ресурс ещё без номенклатуры
- **THEN** его деньги сохранены в редакции, в сумме по номенклатуре их нет
- **AND** после сопоставления они входят для сопоставленной работы либо отдельной строки-материала без позиции перечня. Работа без позиции перечня учитывается счётчиком несопоставленных работ до сопоставления самой работы

#### Scenario: Доля по разделу
- **WHEN** на раздел отнесена половина работы с водой на 12,64 и сверлом на 214,14
- **THEN** ответ по разделу содержит 6,32 и 107,07 по соответствующей номенклатуре, ответ по всей стройке содержит 12,64 и 214,14

#### Scenario: Чтение без себестоимости
- **WHEN** читатель без `plan.estimate.cost` получает отчёт импорта, строки, группы материалов, ответ сопоставления или часть «Плановых работ»
- **THEN** в доступных данных нет сметных цен, сумм и признаков их основы, скрытая часть обозначена по правилам соответствующего ответа

### Requirement: [PLAN-5] [PLAN-5.2] Сохранность редакций при обновлении импорта ресурсов

Обновление SHALL сохранять старые редакции, имеющиеся числа, сопоставления, распределения и производные. Прежняя сумма без доказательства её налоговой основы MUST оставаться неподтверждённой. При повторном импорте исходной ЛСР штатный процесс SHALL создавать отдельную редакцию. Существующая действующая редакция меняется только обычным явным действием пользователя.

#### Scenario: Источник или индивидуальная стоимость недоступны
- **WHEN** у старой редакции нет читаемого исходника либо в нём нет достаточных данных о ресурсе
- **THEN** обновление не вычисляет стоимость из итога позиции и не меняет исторические строки, указатель действующей редакции и связанные КП или графики

#### Scenario: Импорт начат предыдущей версией
- **WHEN** сохранённый до обновления отчёт разбора ещё ожидает решения и в нём отсутствуют новые поля
- **THEN** его можно принять по обычным правилам с неизвестными значениями, повтор того же принятия возвращает ранее созданную редакцию

#### Scenario: Повторная загрузка доступного исходника
- **WHEN** у сметы есть действующая редакция и сметчик загружает оригинал новым импортом
- **THEN** действующей остаётся прежняя, её сопоставления, части распределения и производные сохранены, новая редакция доступна для сверки и выбора
