# Офлайн-справочники назначенных строек

## Why

Офлайн-форма должна предлагать реальные работы, материалы и участников смены при ограниченном объёме данных на личном телефоне.

## What Changes

- Описать ограниченные выборки, курсоры, границы страниц, удаление и потерю доступа по каждому набору с учётом даты назначения.
- Использовать порты и правила ReportEntryCatalog. Разделить недоступность costs/plan и пустую страницу, закрепить договор строки с CORE-12.
- Проверить пагинацию при конкурирующих изменениях, сокращение назначений, изоляцию сотрудников и состав Work без необязательных поставщиков.

Требования [MOB-2] [MOB-16] [MOB-37] [WORK-5.1] [WORK-24] [CORE-12].

## Capabilities

### New Capabilities

Новые области не вводятся.

### Modified Capabilities

- `field` — Офлайн-справочники назначенных строек.

## Impact

Полевой API v1, ReportEntryCatalog, AssignmentGate, порты номенклатуры, перечня и поставщиков подсказок.
