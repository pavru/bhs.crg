# Spec Delta: plan

## ADDED Requirements

### Requirement: [PLAN-15] [PLAN-Q7] Построение графика из редакции сметы
График SHALL строиться из редакции сметы одним действием: работы берутся из сопоставленных строк и
ссылаются на позицию перечня. Если строка распределена по разделам стройки, работы MUST создаваться по
частям распределения, а нераспределённый остаток — работой «по стройке в целом». Несопоставленные строки
в график не входят и называются числом. Построение фиксирует редакцию; повтор построения не создаёт
второго графика. Работы и связи графика SHALL храниться записями модуля.

#### Scenario: Распределённая строка
- **WHEN** строка редакции на 1400 м распределена «корпус 1: 700, корпус 2: 500», а 200 м не распределены
- **THEN** график получает три работы: корпус 1 — 700 м, корпус 2 — 500 м, «по стройке в целом» — 200 м

#### Scenario: Несопоставленная строка
- **WHEN** в редакции 17 строк без вида работы
- **THEN** они не входят в график, а ответ называет «не вошло: 17 несопоставленных строк»

#### Scenario: Редакция фиксируется
- **WHEN** из редакции построен график
- **THEN** правка этой редакции отвергается с названием графика

### Requirement: [PLAN-15] Перестроение работ по изменённому распределению
Если распределение строк изменилось после построения, график SHALL нести пометку «распределение изменено
после построения». Перестроить работы по распределению можно только действием после предпросмотра;
действие MUST нести версию графика `If-Match` и отпечаток предпросмотра. Сроки и исполнители совпавших
частей сохраняются.

#### Scenario: Распределение изменили
- **WHEN** после построения сметчик перенёс 100 м из корпуса 1 в корпус 2
- **THEN** график помечен «распределение изменено после построения»

#### Scenario: Перестроение с устаревшим предпросмотром
- **WHEN** перестроение приходит с отпечатком, не совпадающим с текущим распределением
- **THEN** ответ 409 с новым предпросмотром, работы не меняются

### Requirement: [PLAN-15] [PLAN-16] Работы графика, ручные работы и исполнители
У работы SHALL быть сроки начала и окончания (могут быть не назначены), объём в единице классификатора и
исполнители — сотрудники. Работа, добавленная вручную, MUST ссылаться на вид работы классификатора;
позиция перечня для неё заводится сервером. Правка работы требует `plan.schedule.edit` и версию работы
заголовком `If-Match`.

#### Scenario: Ручная работа
- **WHEN** менеджер добавляет работу «пусконаладка» по виду работы классификатора
- **THEN** работа получает позицию перечня по ключу «вид работы, стройка, раздел, единица»

#### Scenario: Правка без версии
- **WHEN** правка работы приходит без `If-Match`
- **THEN** ответ 400

#### Scenario: Устаревшая версия
- **WHEN** работу тем временем изменили, а правка пришла с прежней версией
- **THEN** ответ 409, работа не меняется

#### Scenario: Только чтение графиков
- **WHEN** пользователь с `plan.schedule.read` без `plan.schedule.edit` правит работу
- **THEN** ответ 403

#### Scenario: Модуль выключен
- **WHEN** экземпляр работает без модуля `plan`, а клиент вызывает адрес графика
- **THEN** ответ — отказ выключенного модуля

#### Scenario: Архивный сотрудник
- **WHEN** исполнителем новой работы указан сотрудник из архива
- **THEN** ответ — отказ с причиной «запись в архиве»

### Requirement: [PLAN-16.1] Зависимости между работами графика
Работа SHALL ссылаться на предшественников связью «окончание → начало» с задержкой в рабочих днях
календаря стройки — нулевой или отрицательной. Вид связи хранится; другие виды в первой версии MUST
отвергаться. Связь на работу другого графика той же стройки допустима, другой стройки — отказ.
Циклическая зависимость MUST отвергаться при сохранении с перечнем работ цикла — в том числе цикл через
графики одной стройки и цикл, который замкнули бы два одновременных сохранения.

#### Scenario: Отрицательная задержка
- **WHEN** монтаж связан с общестроем задержкой −2 рабочих дня
- **THEN** связь сохраняется: «начать за два рабочих дня до окончания»

#### Scenario: Цикл через два графика
- **WHEN** новая связь замыкает цикл из работ графиков «Электромонтаж» и «Общестрой» одной стройки
- **THEN** ответ — отказ с перечнем работ цикла, связь не сохраняется

#### Scenario: Вид «начало → начало»
- **WHEN** клиент присылает связь вида «начало → начало»
- **THEN** ответ — отказ «пока поддерживается только „окончание → начало“»

#### Scenario: Связь на другую стройку
- **WHEN** предшественник — работа графика другой стройки
- **THEN** ответ — отказ

### Requirement: [PLAN-19] [PLAN-16.1] Предупреждения графика без пересчёта сроков
Нарушение зависимости («начинается раньше, чем закончится предшественник с задержкой») и окончание на
нерабочем дне календаря стройки SHALL показываться предупреждением с сервера у обеих работ и в списке
графика. Сроки MUST NOT пересчитываться автоматически.

#### Scenario: Нарушение зависимости
- **WHEN** последователь начинается раньше, чем окончание предшественника плюс задержка в рабочих днях
- **THEN** обе работы несут предупреждение, сроки не меняются

#### Scenario: Окончание на празднике
- **WHEN** окончание работы приходится на нерабочий день календаря стройки
- **THEN** работа несёт предупреждение «окончание на выходном»
