# Proposal: график производства работ — работы, построение из редакции, зависимости

Дочерний change зонтика `plan-00-epic`, общая архитектура — `../plan-00-epic/design.md` (D3, D7, D9, D14, D15, D17).

## Why

График строится из редакции сметы и сохраняет ссылку на позицию перечня (`PLAN-15`): только так «срок по
графику» встречается в «Ходе работ» с планом и фактом той же позиции (`PLAN-21`). Работы графика и связи
между ними — записи модуля, а не массив в документе (решение 18.09.2026, `PLAN-Q7`): на их поля опирается
код — зависимости между графиками стройки, отказ при цикле, срок по позиции перечня. Сроки по
зависимостям первая версия не пересчитывает (`PLAN-19`): зависимости хранятся и показываются, нарушение —
предупреждение, сдвиг делает человек.

## What Changes

- **PR 1 — работы и построение.**
  - График — запись модуля: стройка, название, исходная редакция, отпечаток распределения на момент
    построения. Шапка — тоже запись модуля, а не документ общего типа: предложено, ждёт решения В-14
    (`design.md`).
  - Работа — позиция перечня, вид работы, раздел (часть распределения или «по стройке в целом»), объём в
    единице классификатора, начало и окончание (могут быть не назначены), исполнители-сотрудники
    (`PLAN-16`; бригады как сущности нет, `WORK-Q7`), признак «добавлена вручную».
  - **Построение из редакции** одним действием: по сопоставленным строкам, по частям распределения
    (`PLAN-15`, D9); нераспределённый остаток — работа «по стройке в целом»; несопоставленные строки не
    входят и названы числом. Построение фиксирует редакцию (`PLAN-5`).
  - **Ручная работа** ссылается на вид работы классификатора; позиция перечня заводится портом «найди или
    создай» (`plan-04`).
  - **«Распределение изменено после построения»** — носитель у графика; действие «перестроить работы по
    распределению» с предпросмотром, назначенные сроки совпавших работ сохраняются.
- **PR 2 — зависимости и предупреждения.**
  - Связь — предшественник, последователь, вид (хранится; в первой версии разрешён только «окончание →
    начало»), задержка в рабочих днях календаря стройки, может быть нулевой и отрицательной (`PLAN-16.1`).
  - Связь на работу другого графика той же стройки допустима; другой стройки — отказ.
  - Цикл — отказ при сохранении с перечнем работ цикла.
  - Нарушение «начинается раньше, чем закончится предшественник (с задержкой)» и «окончание на выходном»
    — предупреждения с сервера у обеих работ и в списке графика; пересчёта сроков нет (`PLAN-19`).
- Права `plan.schedule.read` / `.edit` объявлены в `plan-18` (первый адрес — календарь стройки).
- Выработка рядом с объёмом работы (`PLAN-16`, вторая фраза) — этап 4, `work-28` (D2).

## Capabilities

### New Capabilities
- Нет.

### Modified Capabilities
- `plan`: график как запись модуля, построение из редакции по частям распределения, ручные работы,
  исполнители, зависимости с задержкой в рабочих днях, отказ при цикле, предупреждения без пересчёта.
