# Spec Delta: plan

## ADDED Requirements

### Requirement: [PLAN-13] Признак «смета изменилась» у коммерческого предложения
КП, сделанное из редакции сметы, SHALL нести признак расхождения с сметой, который считает сервер: в
смете появилась редакция новее исходной или действующей стала другая редакция — с номерами редакций.
У КП без сметы признака нет.

#### Scenario: Новая редакция
- **WHEN** после КП по редакции 2 сметчик импортировал редакцию 3 той же сметы
- **THEN** КП показывает «сделано по ред. 2, в смете есть ред. 3»

#### Scenario: Смета не менялась
- **WHEN** исходная редакция КП — самая новая и действующая
- **THEN** признак расхождения — «нет»

### Requirement: [PLAN-13] [PLAN-12] Обновление КП по смете — после показа разницы
Обновить КП на другую редакцию SHALL только действием человека после предпросмотра: добавленные,
снятые и изменённые строки, неоднозначные — списком. Действие MUST нести версию КП заголовком `If-Match`
и отпечаток предпросмотра; черновик обновляется на месте, отправленное КП — новой версией.

#### Scenario: Обновление без версии
- **WHEN** действие обновления приходит без `If-Match`
- **THEN** ответ 400

#### Scenario: Версия устарела
- **WHEN** КП тем временем изменили, а обновление пришло с прежней версией
- **THEN** ответ 409, КП не меняется

#### Scenario: Смета изменилась после предпросмотра
- **WHEN** после предпросмотра в смете появилась ещё одна редакция, и пришло обновление с прежним отпечатком
- **THEN** ответ 409 с новым предпросмотром, КП не меняется

#### Scenario: Отправленное КП
- **WHEN** обновляют КП в статусе «отправлено»
- **THEN** появляется новая версия-черновик, отправленная версия остаётся в истории без изменений

#### Scenario: Без права на правку КП
- **WHEN** пользователь только с `plan.offer.read` вызывает обновление
- **THEN** ответ 403

#### Scenario: Модуль выключен
- **WHEN** экземпляр работает без модуля `plan`, а клиент вызывает обновление КП
- **THEN** ответ — отказ выключенного модуля

### Requirement: [PLAN-22] Производные редакции под сметой
Под сметой SHALL показываться по каждой редакции сделанные из неё КП и графики: статус, покрытие
редакции и признак «устарело» (сделано не из действующей). Блок КП MUST быть виден только держателю
`plan.offer.read`, блок графиков — `plan.schedule.read`; без права блок отвечает «скрыто правами» без
чисел. Цен продажи в этом ответе нет.

#### Scenario: Сметчик без прав КП
- **WHEN** пользователь с `plan.estimate.read`, но без `plan.offer.read`, читает производные сметы
- **THEN** блок КП — «скрыто правами», ни числа КП, ни их статусов в ответе нет

#### Scenario: КП по прежней редакции
- **WHEN** действующей стала редакция 3, а КП сделано по редакции 2
- **THEN** под редакцией 2 КП помечено «устарело»

#### Scenario: Покрытие графиком
- **WHEN** из 40 сопоставленных строк редакции у 30 есть работы графика
- **THEN** покрытие графика — 75 %
