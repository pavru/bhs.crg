# Spec Delta: id

## ADDED Requirements

### Requirement: [ID-3] Шаблон документа выбирается одним правилом
Генерация, предпросмотр и отладочный пакет (`GET /api/generate/debug-bundle/{instanceId}`) SHALL
выбирать шаблон экземпляра одним правилом: выбранный набор шаблонов (активные, в порядке выбора) →
явный шаблон этого типа → шаблон по умолчанию → самый ранний активный шаблон типа. Выбор MUST NOT
зависеть от физического порядка строк в базе. Отладочный пакет берёт первый шаблон того набора, который
выпустила бы генерация.

#### Scenario: Экземпляр с выбранным набором шаблонов
- **WHEN** у типа два активных шаблона и в экземпляре выбран второй
- **THEN** генерация выпускает документ вторым шаблоном, и отладочный пакет и предпросмотр берут его же

#### Scenario: Несколько активных без выбора и без шаблона по умолчанию
- **WHEN** у типа несколько активных шаблонов, ни один не по умолчанию, а экземпляр шаблон не выбирал
- **THEN** генерация, предпросмотр и отладочный пакет берут самый ранний по созданию шаблон
- **AND** выбор не меняется после восстановления копии, изменившего порядок строк

#### Scenario: Все выбранные шаблоны неактивны
- **WHEN** все шаблоны выбранного набора экземпляра неактивны
- **THEN** генерация, предпросмотр и отладочный пакет отвечают одним и тем же отказом «ни один из выбранных шаблонов не активен»

#### Scenario: Список шаблонов типа
- **WHEN** клиент запрашивает шаблоны типа
- **THEN** они приходят в порядке запасного выбора, и форма генерации показывает тот же шаблон, что выпустит сервер
