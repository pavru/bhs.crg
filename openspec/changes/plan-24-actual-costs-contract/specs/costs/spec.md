# Spec Delta: costs

## ADDED Requirements

### Requirement: [CORE-34] [PLAN-21.1] [COST-21] Контракт «Фактические затраты»
Модуль `costs` SHALL реализовать контракт ядра «Фактические затраты»: по стройке, с отбором по разделу —
итог «разнесено» (доли разноски счетов в учёте, кроме черновиков и отклонённых) и итог «оплачено» (из
них — доли оплаченных счетов). Итог «оплачено» MUST совпадать с затратами отчёта «Затраты по стройке» за
то же время. Доля затрат, привязанных к работам, MUST приходить состоянием «не ведётся», пока разноска
на позицию перечня не построена, а не нулём.

#### Scenario: Оплачен один счёт из двух
- **WHEN** на стройку разнесены два счёта, оплачен один
- **THEN** «разнесено» — сумма обоих, «оплачено» — сумма оплаченного и равна затратам отчёта по стройке

#### Scenario: Черновик
- **WHEN** у стройки есть черновик счёта с разноской
- **THEN** он не входит ни в один итог

#### Scenario: Доля по работам
- **WHEN** потребитель читает итоги
- **THEN** доля «привязано к работам» приходит состоянием «не ведётся», числа в ней нет

#### Scenario: Модуль `costs` выключен
- **WHEN** «Ход работ» спрашивает контракт на экземпляре без модуля `costs`
- **THEN** ответ — «не подключено: модуль „Счета и накладные“»

### Requirement: [COST-28] [AUTH-8.1] Право контракта `costs.totals.read`
Модуль SHALL объявлять `costs.totals.read` правом контракта: итоги затрат по стройке для «Хода работ»,
без счетов и поставщиков; модуль «Счета и накладные» оно не открывает. Контракт «Фактические затраты»
MUST отвечать носителю `costs.totals.read` или `costs.report.read`, остальным — «скрыто правами» с кодом
права. «Менеджер проекта» получает `costs.totals.read`.

#### Scenario: Только право итогов
- **WHEN** у пользователя из прав `costs` только `costs.totals.read`
- **THEN** контракт отдаёт ему итоги, а модуль `costs` в `/api/account/access` недоступен и адреса `/api/costs` ему закрыты

#### Scenario: Без прав
- **WHEN** у спрашивающего нет ни `costs.totals.read`, ни `costs.report.read`
- **THEN** ответ «скрыто правами» с кодом `costs.totals.read`, сумм в нём нет
