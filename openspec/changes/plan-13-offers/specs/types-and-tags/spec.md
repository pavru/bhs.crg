# Spec Delta: types-and-tags

## ADDED Requirements

### Requirement: [TYPE-17] Тип `КоммерческоеПредложение` и тэг `offer.markup`
Модуль `plan` SHALL объявлять тип записи модуля `КоммерческоеПредложение` (открытый документ) с
системными полями «Наценка» и «Итого» под замком и тэг `offer.markup` на поле наценки. Поля заказчика
добавляет администратор; системные поля MUST NOT правиться ни схемой, ни запросом записи.

#### Scenario: Администратор добавляет поле
- **WHEN** администратор добавляет в тип `КоммерческоеПредложение` поле «Срок действия предложения»
- **THEN** поле появляется в КП, системные поля «Наценка» и «Итого» не меняются

#### Scenario: Установка без планирования
- **WHEN** экземпляр запущен без модуля `plan`
- **THEN** тэга `offer.markup` нет в выборе редактора схем
