# Spec Delta: plan

## ADDED Requirements

### Requirement: [PLAN-6.1] [PLAN-4] Сопоставление строки сметы с видом работы
Строка редакции SHALL сопоставляться с видом работы классификатора, единицей классификатора и
коэффициентом пересчёта из единицы расценки. Объём позиции перечня MUST считаться в единице
классификатора: объём строки × коэффициент. Строка без сопоставления MUST оставаться в редакции с
пометкой «не сопоставлена» и не попадать в «Ход работ» и график.

#### Scenario: Укрупнённая единица расценки
- **WHEN** строка с объёмом 12 в единице «100 м» сопоставлена с видом работы в «м» и коэффициентом 100
- **THEN** позиция перечня заведена в «м», а объём строки для плана — 1200

#### Scenario: Несопоставленная строка
- **WHEN** строка импортирована без сопоставления
- **THEN** она видна в смете с пометкой `unmatched`, а в «Ходе работ» и графике её нет

#### Scenario: Массово по разделу ЛСР
- **WHEN** сметчик сопоставляет раздел ЛСР одним действием
- **THEN** ответ называет число сопоставленных строк и пропущенные с причиной

### Requirement: [PLAN-6.1] Запомненное сопоставление шифра расценки
Выбор сметчика SHALL запоминаться по шифру расценки и при следующем импорте подставляться сам с
пометкой «запомнено». Запомненное MUST отменяться одним действием и не подставляться, если единица
расценки в новом файле отличается от записанной.

#### Scenario: Знакомый шифр
- **WHEN** в новой редакции встречается шифр, сопоставленный ранее
- **THEN** строка сопоставлена с пометкой «запомнено» и отменой одним действием

#### Scenario: Единица расценки изменилась
- **WHEN** у знакомого шифра в новом файле другая единица расценки
- **THEN** запомненное не подставлено, строка помечена `unit-changed`

#### Scenario: Забыть
- **WHEN** сметчик удаляет запомненное сопоставление из списка
- **THEN** следующий импорт строку не сопоставляет, уже сопоставленные строки не меняются

### Requirement: [PLAN-6.1] [CORE-8] Новый вид работы из окна сопоставления
Сметчик SHALL заводить вид работы прямо из окна сопоставления — дверью видов работ ядра под
`core.worktypes.edit`; без этого права действие MUST NOT предлагаться.

#### Scenario: Сметчик заводит вид работы
- **WHEN** сметчик с `core.worktypes.edit` заводит вид работы из окна сопоставления
- **THEN** вид появляется в классификаторе, строка сопоставлена с ним

### Requirement: [PLAN-5] Сопоставление в зафиксированной редакции
В зафиксированной редакции несопоставленную строку SHALL быть можно сопоставить; пересопоставить уже
сопоставленную строку MUST быть нельзя — только новой редакцией (ждёт решения В-6).

#### Scenario: Пересопоставление зафиксированной
- **WHEN** сметчик меняет вид работы строки редакции, из которой сделан график
- **THEN** ответ 409 называет производную и путь «новая редакция»

### Requirement: [PLAN-9.1] [CORE-9] Сопоставление материалов ресурсов с номенклатурой
Материал ресурса строки SHALL ссылаться на номенклатуру ядра. Выбор запоминается по коду ресурса, а без
кода — по наименованию, и подставляется с пометкой «запомнено». Новая позиция номенклатуры MUST
заводиться только явным действием после показа похожих. Ресурс без номенклатуры MUST NOT попадать в
материалы контракта «Плановые работы».

#### Scenario: Незнакомый материал
- **WHEN** у ресурса нет запомненного сопоставления
- **THEN** ресурс ждёт выбора, ответ несёт похожие позиции номенклатуры

#### Scenario: Знакомый материал
- **WHEN** в новой редакции встречается ресурс с запомненным кодом
- **THEN** номенклатура подставлена с пометкой «запомнено»

### Requirement: Правка сопоставлений называет версию и стоит за правом
Пишущие адреса сопоставления SHALL стоять под воротами модуля `plan` и правом `plan.estimate.edit` и
требовать версию заголовком `If-Match`.

#### Scenario: Без заголовка
- **WHEN** сопоставление строки отправлено без `If-Match`
- **THEN** ответ 400

#### Scenario: Устаревшая версия
- **WHEN** сопоставление отправлено с версией, которую тем временем изменили
- **THEN** ответ 409, сопоставление не записано

#### Scenario: Без права правки
- **WHEN** пользователь только с `plan.estimate.read` отправляет сопоставление
- **THEN** ответ 403

#### Scenario: Модуль выключен
- **WHEN** модуль `plan` выключен
- **THEN** адреса сопоставления отвечают отказом выключенного модуля
