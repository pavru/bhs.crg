# Design: «право контракта»

Общая архитектура — `../work-00-epic/design.md` (D3 — вид права, D2 — права объявляются с первым
адресом, D15 — носители). Здесь только решения этого change.

## Context

Сверено по коду master `f8a8b222`.

- Правило «модуль открыт» — одно место, `BHS.CRG.Modules/ModuleAccess.cs:13-17`, проверка по префиксу
  кода. Статический метод без справочника прав: признак права он узнать не может.
- Спрашивают его пять мест:
  - ворота `module:` — `ModuleAccessHandler` (`PermissionPolicies.cs:136`);
  - ответ доступа — `Api/Endpoints/Account/AccountEndpoints.cs:67`;
  - аудитория уведомлений — `Api/Notifications/PermissionAudience.cs:54`;
  - каталог журнала по модулям — `Api/Activity/ActivityActionCatalog.cs:87`;
  - наборы модулей в параметре доступа — `Api/Auth/DataAccessResolver.cs:95`.
- Тесты зовут его тоже: `McpGateInventoryTests.cs:164`, `ReadAllWritesNothingTests.cs:157`,
  `PermissionCatalogTests.cs:252-253`.
- `AppPermission` (`BHS.CRG.Modules/AppPermission.cs:28`) несёт код, объяснения и `ReadAllMark`; проверка —
  `Validate()`. Справочник `PermissionCatalog` собирает права ядра и включённых модулей.
- В составах ролей уже стоят `work.facts.read` и `costs.materials.read` (`Api/Auth/SystemRoles.cs:59,72,117`).
  Права не объявлены, поэтому синхронизатор их пока не выдаёт.

## Goals / Non-Goals

**Goals:** признак на праве; одно правило «модуль открыт», которое признак знает; носитель признака
для администратора.

**Non-Goals:**
- объявление самих прав контракта — `work-09` и `work-27` (D2);
- межмодульный контракт как механизм — `work-09` (D13);
- новые адреса. Пишущих адресов change не заводит, правило `If-Match` его не касается.

## Decisions

### Состав PR (один)

- `AppPermission` получает `bool Contract = false`.
- `PermissionCatalog`:
  - множество кодов прав контракта;
  - отказ сборки, если признак стоит у права ядра. Справочник знает, какое право чьё (`ReadAllFaults`).
- `ModuleAccess.IsOpen(code, granted, catalog)`. Статический метод без справочника удаляется, а не
  остаётся рядом: старая сигнатура молча считала бы право контракта открывающим. Компилятор
  находит все пять мест и тесты.
- `ModuleAccessHandler` получает `PermissionCatalog` из DI (провайдер политик его уже получает).
- `PermissionView` в `Api/Auth/RoleEditor.cs:447` — поле `Contract`. Его отдают `/api/roles/permissions`
  и `/api/account/permissions`.
- Подпись в `features/settings/RolesPage.tsx` и `features/account/MyPermissionsSection.tsx`.

### Почему признак, а не проверка внутри адресов модуля

Альтернатива названа и отклонена в D3: право внутри адресов не отменяет префиксного правила. Дверь
модуля открылась бы у «Инженера ИД», и пустое пространство «Учёт работ» появилось бы в переключателе.

### Композиция с «читать всё»

Пометка `ReadAllMark` у права контракта обязательна, как у любого права модуля. Раскрытие `*.read.all`
идёт до проверки доступа (`AUTH-5.2`). Право контракта, помеченное «входит», «Руководителю» модуль не
откроет — правило одно для всех путей.

### Сторож и «чем ломается»

- `ContractPermissionTests` — живой хост с тестовым модулем, объявившим одно обычное право и одно право
  контракта (образец тестового модуля — `Tests/Configuration/DisabledModuleTests.cs:231`):
  - роль только с правом контракта: `available: false`, адреса группы — 403, уведомление модуля не видно;
  - роль с правом контракта и обычным: модуль доступен.
- Ломается так: вернуть проверку по префиксу без справочника — первый сценарий краснеет. Объявить
  `work.facts.read` обычным правом — у «Инженера ИД» появляется пустой «Учёт работ». Этот сценарий
  проверяет тест состава доступа по ролям в `work-27` (D2).

### Зависимости

По перечню зонтика — после `work-10`. Код модуля `work` change не требует и может идти раньше.
Потребители — `work-03` (навигация не открывает модуль правом контракта), `work-09`, `work-27`.

## Risks / Trade-offs

- [Признак пропустят при объявлении нового права для чужой роли] → тест состава
  `/api/account/access` по ролям в каждом PR, объявляющем право (D2). Пустой модуль у чужой роли
  виден в нём сразу.
- [Модуль, у которого все права — контракта, не открыт никому] → это верный ответ: такой модуль своих
  экранов не имеет. Отдельного отказа не вводим.
