# Spec Delta: auth

## MODIFIED Requirements

### Requirement: [AUTH-8] [AUTH-8.1] Ворота модуля и права
Каждый адрес SHALL стоять под политикой модуля `module:<код>` или права `perm:<код>`. Модуль
открывается тому, у кого есть хотя бы одно право этого модуля, не считая прав контракта; отдельного
права «войти в модуль» нет. Изменяющий адрес MUST стоять под правом на правку, а не под одними
воротами модуля.

#### Scenario: Только чтение в модуле
- **WHEN** пользователь с одним правом чтения модуля вызывает пишущий адрес модуля
- **THEN** ответ — отказ

#### Scenario: Только право контракта
- **WHEN** у пользователя из прав модуля есть только право контракта
- **THEN** ворота `module:<код>` его не пропускают

## ADDED Requirements

### Requirement: [AUTH-8.1] [WORK-48] Право контракта не открывает модуль-владелец
Модуль SHALL объявлять право, которое он выдаёт другим модулям, с признаком «право контракта». Такое
право MUST NOT учитываться при решении «модуль доступен». От этого решения зависят ворота модуля,
`available` в `/api/account/access`, навигация, аудитория уведомлений модуля, журнал действий модуля и
опубликованные наборы модуля. Право ядра с этим признаком — отказ при старте.

#### Scenario: Роль только с правом контракта
- **WHEN** у роли из прав тестового модуля есть только право контракта
- **THEN** в `/api/account/access` модуль приходит с `available: false`, и ни один адрес группы модуля её носителю не открыт

#### Scenario: Право контракта вместе с обычным
- **WHEN** у роли есть право контракта модуля и одно его обычное право
- **THEN** модуль доступен — его открывает обычное право

#### Scenario: Уведомление модуля
- **WHEN** модуль публикует уведомление с аудиторией по модулю
- **THEN** его не видит пользователь, у которого из прав модуля только право контракта

#### Scenario: Признак у права ядра
- **WHEN** право `core.*` объявлено с признаком «право контракта»
- **THEN** приложение не стартует и называет право

#### Scenario: Ворота права на праве контракта
- **WHEN** адрес вне группы модуля-владельца закрыт `perm:` на праве контракта
- **THEN** носитель права проходит, а адреса группы модуля-владельца ему по-прежнему закрыты воротами модуля

### Requirement: [AUTH-5] [AUTH-16.7] Право контракта названо в редакторе ролей и в профиле
`GET /api/roles/permissions` и `GET /api/account/permissions` SHALL отдавать у каждого права признак
`contract`. Редактор ролей и «Мои права» MUST подписывать право контракта: «право контракта: не
открывает модуль „<название>“, данные отдаются другим модулям».

#### Scenario: Администратор выдаёт право контракта
- **WHEN** администратор открывает в редакторе ролей группу модуля с правом контракта
- **THEN** под объяснением права стоит подпись «право контракта: не открывает модуль „…“», а в ответе адреса у права `contract: true`

#### Scenario: Обычное право
- **WHEN** право объявлено без признака
- **THEN** в ответе у него `contract: false`, подписи нет
