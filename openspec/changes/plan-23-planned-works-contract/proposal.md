# Proposal: контракт «Плановые работы» и права контракта модуля `plan`

Дочерний change зонтика `plan-00-epic`, общая архитектура — `../plan-00-epic/design.md` (D10, D11, D12, D3).

## Why

Сметные объёмы, трудозатраты и материалы позиций нужны трём модулям, ни один из которых не вправе
читать схему `plan` (`CORE-2`, `CORE-34`):
- заявке на закупку `costs` — материалы позиций сметы с количествами, без цен (`COST-5.1`, `PLAN-9.1`);
- «плану против факта» `costs` — сметная стоимость материалов (`COST-21`);
- этапу 4 — нормы чел.-ч на единицу для «по смете — фактически» (`WORK-42`, `WORK-57`) и наименования
  материалов позиции для яруса «смета» подсказки монтажнику (`WORK-5.1`, `WORK-59`).

Каждому — своя часть и ничего сверх: снабженец не видит цен, менеджер — денег, монтажник — количеств.
Поэтому контракт отвечает по праву спрашивающего, а узкие права объявлены **правами контракта** — они
не открывают модуль `plan` и его навигацию (`plan-21`). Права `plan.labor.read` и `plan.estimate.hint`
вписаны в `PLAN-23` решением `WORK-59` ради этапа 4.

## What Changes

- Модуль `plan` реализует контракт «Плановые работы» (`BHS.CRG.Modules/Exchange/PlannedWorks.cs`): по
  стройке, с отбором по разделу и списку позиций перечня. Считает **только действующие редакции** всех
  смет стройки (`PLAN-5.2`) и **только сопоставленные строки** (`PLAN-4`); несопоставленные названы числом.
- Ответ — частями, каждая со своим правом; части без права приходят «скрыто правами» с кодом права:
  - объёмы по позиции перечня и распределение по разделам, «стройка в целом» — `plan.estimate.read`;
  - стоимость — `plan.estimate.cost`;
  - материалы позиций с количеством на объём, без цен — `plan.estimate.materials` (ждёт решения В-2);
  - нормы чел.-ч на единицу позиции, без денег — `plan.labor.read`;
  - наименования материалов позиции без количеств и цен — `plan.estimate.hint`.
- Объявляются три права **контракта** с объяснениями, что модуль `plan` они не открывают, и
  `ReadAllMark.Out`: `plan.estimate.materials`, `plan.labor.read`, `plan.estimate.hint`.
- Составы ролей (вписаны в `plan-01`) начинают действовать: «Снабженец» — `plan.estimate.materials`,
  «Менеджер проекта» — `plan.labor.read`, «Монтажник» — `plan.estimate.hint`.

## Capabilities

### New Capabilities
- Нет.

### Modified Capabilities
- `plan`: поставщик контракта «Плановые работы», его части по правам, три права контракта.

## Impact

- **Контракты:** `src/server/BHS.CRG.Modules/Exchange/PlannedWorks.cs` — интерфейс и форма ответа.
- **Сервер:** `src/server/BHS.CRG.Modules.Plan/Exchange/PlannedWorksProvider.cs`, регистрация в
  `PlanModule.RegisterServices`, объявление прав в `PlanModule`.
- **Тесты:** `src/server/BHS.CRG.Tests/Plan/PlannedWorks*`, тест состава `/api/account/access` по ролям,
  живой хост `costs` без `plan` — «не подключено».
- **Документы:** `docs/ADMIN_GUIDE.md` — права контракта `plan` и у кого они по умолчанию.
- **Зависит от:** `plan-21`, `plan-22`, `plan-06` (редакции и ресурсы), `plan-08` (сопоставление),
  `plan-10` (распределение). Потребители — `plan-26`, `plan-27`, `plan-25`; этап 4 — `work-26`, `work-28`.
