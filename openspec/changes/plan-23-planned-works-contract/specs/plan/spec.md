# Spec Delta: plan

## ADDED Requirements

### Requirement: [CORE-34] [PLAN-9.1] Контракт «Плановые работы» отдаёт план действующих редакций
Модуль `plan` SHALL реализовать контракт ядра «Плановые работы»: по стройке, с отбором по разделу и
списку позиций перечня — объём по позиции перечня в единице классификатора, распределение по разделам
стройки с остатком «стройка в целом», материалы позиции с количеством, нормы чел.-ч на единицу,
стоимость. Ответ MUST считаться только по действующим редакциям всех смет стройки и только по
сопоставленным строкам; число несопоставленных строк MUST приходить в ответе.

#### Scenario: Повторный импорт
- **WHEN** у сметы две редакции, действующая — вторая
- **THEN** контракт отдаёт объёмы второй редакции, а не сумму двух

#### Scenario: Несопоставленная строка
- **WHEN** в действующей редакции есть строка без вида работы
- **THEN** её объёма нет ни в одной позиции, а число несопоставленных строк в ответе — 1

#### Scenario: Укрупнённая единица расценки
- **WHEN** строка «100 м» сопоставлена с видом работы в «м» с коэффициентом 100 и несёт 12 чел.-ч на 2 единицы «100 м»
- **THEN** объём позиции — 200 м, норма — 0,06 чел.-ч на метр

#### Scenario: Модуль `plan` выключен
- **WHEN** потребитель спрашивает контракт на экземпляре без модуля `plan`
- **THEN** ответ — «не подключено: модуль „Планирование“»

### Requirement: [PLAN-23] [PLAN-11] Части «Плановых работ» отдаются по праву спрашивающего
Каждая часть ответа SHALL открываться своим правом: объёмы, распределение, материалы, нормы и
наименования — `plan.estimate.read`; стоимость — `plan.estimate.cost`; материалы без цен —
`plan.estimate.materials`; нормы без денег — `plan.labor.read`; наименования материалов без количеств —
`plan.estimate.hint`. Часть без права MUST приходить «скрыто правами» с кодом права, а не пустой и не
нулями.

#### Scenario: Снабженец
- **WHEN** контракт спрашивает пользователь только с `plan.estimate.materials`
- **THEN** приходят материалы позиций с количествами, а объёмы, стоимость, нормы — «скрыто правами»

#### Scenario: Монтажник
- **WHEN** контракт спрашивает пользователь только с `plan.estimate.hint`
- **THEN** приходят позиции номенклатуры без количеств, остальное — «скрыто правами»

#### Scenario: Менеджер без права на деньги сметы
- **WHEN** контракт спрашивает пользователь с `plan.estimate.read` без `plan.estimate.cost`
- **THEN** стоимость — «скрыто правами», ни одного денежного поля в ответе нет

### Requirement: [PLAN-23] [AUTH-8.1] Права контракта модуля `plan`
Модуль SHALL объявлять `plan.estimate.materials`, `plan.labor.read` и `plan.estimate.hint` правами
контракта с объяснением, что модуль «Планирование» они не открывают, и с пометкой «не входит в чтение
всего». «Снабженец» получает `plan.estimate.materials`, «Менеджер проекта» — `plan.labor.read`,
«Монтажник» — `plan.estimate.hint`.

#### Scenario: Монтажник и модуль
- **WHEN** у пользователя только права роли «Монтажник»
- **THEN** в `/api/account/access` модуль `plan` недоступен, и ни один адрес `/api/plan` ему не открыт

#### Scenario: Руководитель
- **WHEN** у пользователя право «читать всё»
- **THEN** права контракта `plan` в его действующие права не раскрываются
