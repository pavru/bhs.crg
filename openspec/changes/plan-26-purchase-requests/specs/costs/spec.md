# Spec Delta: costs

## ADDED Requirements

### Requirement: [COST-5.1] Заявка на закупку из материалов сметы
Заявка на закупку SHALL создаваться из материалов позиций сметы стройки, полученных контрактом «Плановые
работы» в правах спрашивающего: выбранные позиции перечня или раздел сметы дают предложенные строки по
номенклатуре с количеством «по смете минус отпущено на стройку». Предложение MUST ничего не записывать;
заявка сохраняется отдельным действием после правки человеком. Отпущенное сверх сметы MUST давать ноль с
пометкой, а не отрицательное количество.

#### Scenario: Часть уже отпущена
- **WHEN** по смете 100 м кабеля, на стройку отпущено 30 м
- **THEN** предложено 70 м

#### Scenario: Отпущено больше сметы
- **WHEN** по смете 100 м, отпущено 120 м
- **THEN** предложено 0 с пометкой «отпущено больше сметы»

#### Scenario: Нет права на материалы сметы
- **WHEN** предложение запрашивает пользователь без `plan.estimate.materials` и без `plan.estimate.read`
- **THEN** ответ «скрыто правами» с кодом права, а не пустой список

#### Scenario: Модуль `plan` выключен
- **WHEN** на экземпляре нет модуля `plan`
- **THEN** создание заявки — 409 «нужен модуль „Планирование“», ранее созданные заявки читаются

### Requirement: [COST-5.1] Статусы и правка заявки
Заявка SHALL проходить статусы черновик → подана → закрыта; подданную автор может вернуть в черновик с
причиной. Строки MUST меняться только в черновике. Удалить можно только черновик без связанных счетов.
Каждая правка, переход и удаление MUST идти под `costs.request.edit` за воротами модуля `costs` и
требовать заголовок `If-Match` с версией из ответа чтения.

#### Scenario: Правка без версии
- **WHEN** пишущий адрес заявки вызван без `If-Match`
- **THEN** ответ 400

#### Scenario: Правка по устаревшей версии
- **WHEN** правка отправлена с версией, которую сдвинула другая правка
- **THEN** ответ 409 «заявку тем временем изменили»

#### Scenario: Без права правки
- **WHEN** пишущий адрес заявки вызывает пользователь только с `costs.request.read`
- **THEN** ответ 403

#### Scenario: Модуль выключен
- **WHEN** адрес заявки вызывают на экземпляре без модуля `costs`
- **THEN** ответ — отказ выключенного модуля

#### Scenario: Правка подданной
- **WHEN** строки меняют у подданной заявки
- **THEN** ответ 409 с выходом «верните в черновик»

### Requirement: [COST-5.1] Счёт связывается с заявкой
Счёт SHALL нести необязательную ссылку на заявку той же стройки; одна заявка — несколько счетов. Ссылку
ставит правка шапки счёта под `costs.invoice.edit` с `If-Match` счёта. Заявка MUST показывать по каждой
номенклатуре «заказано» (строки заявки), «выставлено в счетах» (строки связанных счетов) и «отпущено» (на
стройку проведёнными накладными).

#### Scenario: Счёт к заявке другой стройки
- **WHEN** счёт связывают с заявкой, чья стройка не совпадает с разноской счёта
- **THEN** ответ 422 с причиной

#### Scenario: Два счёта по заявке
- **WHEN** с заявкой связаны два счёта с одной номенклатурой
- **THEN** «выставлено в счетах» — сумма количеств обоих

#### Scenario: Закрытая заявка
- **WHEN** счёт связывают с закрытой заявкой
- **THEN** ответ 422 «заявка закрыта»

### Requirement: [COST-28] [COST-5.1] Права заявок на закупку
Модуль SHALL объявлять `costs.request.read` и `costs.request.edit` с объяснениями и пометкой
«читать всё»: чтение входит, правка — нет. «Снабженец» и «Менеджер проекта» получают оба права.

#### Scenario: Роли после объявления
- **WHEN** экземпляр стартует с модулем `costs`
- **THEN** «Снабженец» и «Менеджер проекта» получают `costs.request.read` и `costs.request.edit`
