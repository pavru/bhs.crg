# Tasks: Этап 5 — полевой API и приложение Android

11 дочерних change, 12 плановых PR реализации. Архивные и планировочные PR учитываются отдельно. Число в скобках — PR реализации. Галочку строки ставят после слияния всех PR change и его архивации. Порядок групп помогает навигации; обязательные зависимости перечислены по каждой вехе в [карте](../../roadmap/milestones-5.json).

## 0. До начала реализации

- [x] 0.1 [STG-7] [MOB-25] Решение владельца от 28.11.2026: поставка для Android в РФ, основной канал — прямая установка APK, RuStore — запасной. За учётную запись разработчика, подпись и необходимую регистрацию отвечает владелец по подробным инструкциям координатора. Старт MOB-01 и MOB-06 разрешён. Фактическая настройка подписи, регистрация и проверка запасного канала выполняются до выпуска в MOB-11; их завершение этим решением не подтверждается. Если основной канал окажется недоступен, проверить RuStore; при недоступности обоих согласовать пересмотр этапа по STG-7.

## 3. Подключение и доставка с телефона

- [ ] 3.1 `mob-07-android-join` (1) — Подключение Android к экземпляру заказчика. Один APK подключается к двум экземплярам, отказ от камеры и внутренний сертификат проходят ручным путём. [MOB-4]
- [ ] 3.2 `mob-08-background-sync` (1) — Фоновый обмен и причины недоставки. Семь исходов различимы, обновление и прерывание отправки сохраняют очередь. [MOB-3]
- [ ] 3.3 `mob-09-photo-outbox` (1) — Доставка фото после текста отчёта. Офис принимает текст до файлов; повторная доставка фото не удваивает занятое место. [MOB-2]
