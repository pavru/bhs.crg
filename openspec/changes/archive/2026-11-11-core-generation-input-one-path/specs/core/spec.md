# Spec Delta: core

## MODIFIED Requirements

### Requirement: [CORE-21] [CORE-22] Пайплайн генерации PDF через Typst
Генерация документа SHALL идти конвейером `EntityResolver` → `DataSetResolver` / `QualityLinkResolver`
→ `TypstGenerator`, который пишет `data.json`, `typeblocks.typ`, `userlib.typ`, материализует картинки и
компилирует шаблон Typst CLI (`TYPST_PATH`). Единственный формат на выходе — `Pdf`; DOCX на выходе MUST
NOT поддерживаться. Блоки печати собираются из схем типов и от данных не зависят.

#### Scenario: Запрошен не PDF
- **WHEN** генерацию запрашивают в формате, отличном от `Pdf`
- **THEN** запрос отклоняется

#### Scenario: Отладочный комплект
- **WHEN** администратор скачивает `GET /api/generate/debug-bundle/{instanceId}`
- **THEN** ZIP содержит каталог компиляции генерации, и его компилирует внешний Typst (подробности — требования об отладочном комплекте ниже)

## ADDED Requirements

### Requirement: [CORE-21] [CORE-22] Отладочный комплект воспроизводит вход генерации
Отладочный комплект (`GET /api/generate/debug-bundle/{instanceId}`) SHALL содержать тот каталог, который
компилирует генерация того же экземпляра тем же шаблоном: те же файлы, `data.json` с тем же
содержанием, те же ассеты и вложения с теми же пределами размера. Внешний Typst, скомпилировавший
комплект с ключами из его `README.txt`, MUST получить тот же документ, что выпускает генерация.

#### Scenario: Комплект компилируется в тот же документ
- **WHEN** документ выпущен, и сразу после этого снят отладочный комплект того же экземпляра
- **THEN** набор файлов комплекта совпадает с каталогом компиляции генерации
- **AND** PDF, скомпилированный из комплекта, совпадает с выпущенным по тексту и числу листов

#### Scenario: Ассет больше предела
- **WHEN** ассет шаблона больше предела размера, который применяет генерация
- **THEN** его нет ни в каталоге генерации, ни в комплекте

#### Scenario: Шрифт объявлен, но не скачался
- **WHEN** у шаблона объявлен шрифтовой ассет, а хранилище его не отдало
- **THEN** генерация компилирует без `--font-path`, и `README.txt` комплекта этого ключа не предлагает

#### Scenario: Запрос комплекта отменён
- **WHEN** клиент отменил запрос, пока комплект скачивает ассеты шаблона
- **THEN** сборка комплекта прерывается и не продолжает загрузку остальных файлов

### Requirement: [CORE-21] [CORE-22] Отладочный комплект называет отказ генерации
Отладочный комплект SHALL отдаваться и тогда, когда генерация экземпляра отказала бы: отлаживают как раз
такие документы. В этом случае `README.txt` комплекта MUST перечислить причины отказа — ошибки проверок
документа с их кодами и полями, а также поля с картинками, которые хранилище не отдало (CORE-37.2).
Комплект документа, который генерация выпустит, такого перечня MUST NOT содержать.

#### Scenario: Не заполнено обязательное поле
- **WHEN** у экземпляра не заполнено обязательное поле, и генерация отвечает отказом `missing-required`
- **THEN** комплект отдаётся, и `README.txt` называет код `missing-required` и путь поля

#### Scenario: Картинка не читается из хранилища
- **WHEN** файл картинки в реквизитах хранилище не отдаёт
- **THEN** комплект отдаётся, и `README.txt` называет поле, на котором генерация откажет

#### Scenario: Документ выпускается
- **WHEN** генерация экземпляра проходит без ошибок
- **THEN** `README.txt` комплекта не содержит перечня причин отказа
