# Proposal: источник подсказок для вложенных полей и строк массивов

Дочерний change зонтика `suggest-00-epic`, общая архитектура — `../suggest-00-epic/design.md` (D1, D2,
D10, D12).

## Why

Issue #1532 (подсказки 4/5: источник вложенных полей и строк массивов по путям из схемы), часть эпика
#1527. После `suggest-02`; только сервер, контракт адреса не меняется.

⚠️ **Приоритет понижен по замеру #1528.** В копии базы заказчика строки массивов, набранные руками,
дают почти ничего: 25 пар «запись — значение», сбережено 1. Строки кабельного журнала приходят из файла
набора данных, а не набираются; набранный массив один — «Реестр работ → Работы». Встроенные составные
дают больше — 106 пар, сбережено 21, — но 16 из 21 — «Адрес» (страна, регион: одно значение на всю
копию; остальное — части ФИО), которому место в справочнике, а не в подсказке (#1540). `suggest-05` эту
задачу не ждёт. **Брать её, когда в документах появятся набираемые таблицы с повторами или владелец
попросит.**

Зачем она вообще: составные поля и строки массивов лежат внутри записи-владельца — записей типа
«Работа» в `domain_objects` может не быть вовсе. Источник «записи типа-владельца» из `suggest-02` для
ячеек массивов и встроенных составных даёт пусто.

## What Changes

- Источник «вхождения типа внутри чужих записей»: пути к полям типа-владельца выводятся **из схем**
  типов, где он встречается (составное поле, массив, вложенность), глубина ≤ 6. Не рекурсивный `$.**`:
  он смешал бы «Организация.Наименование» с «Работа.Наименование».
- Частота — по разным записям-владельцам, а не по вхождениям: один большой журнал не задавит остальные
  документы.
- Те же индекс, окно по объёму, таймаут, права, архив, порог и нормализация, что в `suggest-02`, плюс
  предел по строкам массива — около 10 000 строк на запрос: окно набирается, пока сумма
  `jsonb_array_length` не превысит предел.
- Ссылка на запись каталога (не встроенное значение) источником не считается: её значение лежит в самой
  записи и уже учтено верхним уровнем.

## Capabilities

### New Capabilities
- Нет.

### Modified Capabilities
- `core`: адрес подсказок получает источник вложенных полей и строк массивов.

## Impact

- **Сервер:** `Application/Objects/FieldSuggestions/SuggestionSources.cs` (пути из схем),
  `Infrastructure/Persistence/FieldSuggestionReader.cs` (чтение по путям, предел строк).
- **Тесты:** интеграционные адреса, тест плана, замер на синтетике.
- **API:** контракт `GET /api/field-suggestions` не меняется; ответ для типов строк массивов перестаёт
  быть пустым.
- **Версия:** не меняется; PR — с меткой `version:minor`.
