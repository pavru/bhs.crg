# Spec Delta: costs

## ADDED Requirements

### Requirement: [COST-6] [COST-23] Поставщик и плательщик — названием для показа
Модуль `costs` SHALL показывать поставщика и плательщика тем названием, которое даёт порт справочника
организаций (сокращённое, если есть): в карточке и строках реестра счетов, в выборе организации, в
накладных, соответствиях и условиях поставщиков, затратах по стройке и в сообщениях отказов. Отбор
реестра по названию организации MUST находить счёт и по названию, которое видно в колонке, и по
полному (решение владельца 22.10.2026).

#### Scenario: Карточка счёта
- **WHEN** пользователь открывает счёт поставщика, у которого заполнено сокращённое название
- **THEN** поле «Поставщик» показывает сокращённое название

#### Scenario: Реестр счетов
- **WHEN** пользователь смотрит реестр счетов и отбирает его по названию поставщика
- **THEN** колонка «Поставщик» показывает сокращённые названия, и отбор находит счёт по сокращённому и по
  полному

#### Scenario: Выбор поставщика
- **WHEN** пользователь выбирает поставщика в форме счёта
- **THEN** организации в списке названы сокращённо, а полное название — второй строкой пункта, чтобы
  различить похожие
