# Spec Delta: auth

## MODIFIED Requirements

### Requirement: [AUTH-16.1] [AUTH-15] Страница входа по доступу
После входа и по адресу `/` клиент SHALL открывать страницу, вычисленную по `/api/account/access` и
текущему пространству. Открывается видимый пункт, объявивший себя страницей входа, с наименьшим рангом.
Если такого нет — первый видимый пункт навигации. Главная работой не считается: если видимых пунктов,
кроме Главной, нет, клиент MUST показать страницу `AUTH-15`, а не Главную и не раздел, отвечающий отказом.

#### Scenario: Роль с правами модуля без «Строек»
- **WHEN** у пользователя права модуля `plan`, но нет `core.constructions.read` (самодельная роль)
- **THEN** после входа открывается не отказ на «Стройках», а Главная; до появления Главной — первый
  видимый пункт, то есть пункт раздела «Планы»

#### Scenario: Пункт объявил себя страницей входа
- **WHEN** пункт модуля объявил ранг страницы входа меньше ранга Главной и виден пользователю
- **THEN** после входа открывается он, а не Главная

#### Scenario: Пункт входа вне пространства
- **WHEN** пункт с наименьшим рангом не входит в текущее пространство
- **THEN** открывается страница входа этого пространства, само пространство не меняется

#### Scenario: Ни одного видимого пункта
- **WHEN** у пользователя нет прав ни на один раздел
- **THEN** он видит честную страницу «нет доступа» с объяснением

#### Scenario: Кроме Главной, ничего не видно
- **WHEN** входит пользователь, которому из пунктов навигации видна только Главная
- **THEN** открывается страница `AUTH-15`, а не Главная
