# Proposal: адрес `GET /api/field-suggestions`, источник верхнего уровня

Дочерний change зонтика `suggest-00-epic`, общая архитектура — `../suggest-00-epic/design.md` (D1, D2,
D5–D8, D10, D11). Контракт адреса — D10.

## Why

Issue #1530 (подсказки 2/5: адрес `GET /api/field-suggestions`, источник верхнего уровня), часть эпика
#1527, после #1529 (`suggest-01`).

Подсказке нужен один адрес, который по типу и ключу поля отдаёт уже введённые значения — в порядке
показа, без лишнего (id, имён, частот, дат) и с честным отказом. Главный потребитель по замеру #1528 —
«Номенклатура → Производитель», верхний уровень записей справочника; поэтому здесь — только верхний
уровень, вложенные поля и строки массивов — `suggest-04`.

Цена ошибки формы запроса велика и не видна по ответу: без частичного индекса и окна по объёму каждая
буква распаковывает все картинки типа (замер #1528: 50k записей, 1 000 картинок по 300 КБ вне окна —
p95 340 мс; с индексом — 5 мс; окно из 1000 записей с картинками — 320 мс, по объёму — 8 мс).

## What Changes

- Адрес `GET /api/field-suggestions?type=&field=&q=&scope=&scopeId=&limit=8` → `{ items: [{ value, here }] }`.
  Источник — верхний уровень записей типа-владельца и его семьи по наследованию (`IsSameOrDescendant`);
  потомок, перекрывший ключ своим полем, выпадает.
- Поле, которое правило `suggest-01` не подсказывает, — 200 и пустой список; неизвестный тип или поле —
  400; таймаут (`statement_timeout` ~300 мс) — **503**, а не пусто; тип строки массива — 200 и пустой
  список до `suggest-04`.
- Миграцией ядра — индекс `(CompositeTypeId, UpdatedAt DESC) WHERE ArchivedAt IS NULL` на
  `domain_objects`. Окно — последние записи семьи по `UpdatedAt`, пока сумма `pg_column_size("Data")`
  ≤ 8 МБ, и не больше 1000; окно отбирается подзапросом, поле читается только у попавших в него.
- Только свои значения записи (`_baseRef` не разрешается); архивные записи не участвуют
  (`RecordsFor.Choice`, строка в `ArchiveReadInventoryTests`).
- Права — в службе приёмом `DataAccess`: документы — `id.document.read` и включённый `id`; общие
  данные — `core.catalog.read`; без обоих — 403. Шаг «Новая позиция» — по решению В-1 зонтика.
- Нормализация (регистр, ё→е, пробелы), совпадение с начала слова, склейка близнецов, равное `q` не
  отдаётся, частота по разным записям, порог «своя стройка от 1, чужие от 2», своя стройка первой;
  записи уровня «вся система» — по решению В-3 зонтика.
- `CLAUDE.md` и `AGENTS.md` тем же коммитом: адрес — в «REST API» (200-пусто против 503), подсказки —
  в «Условие пересмотра» инварианта `CatalogScope`. Место отбора по правам — в перечень `STG-11`.
