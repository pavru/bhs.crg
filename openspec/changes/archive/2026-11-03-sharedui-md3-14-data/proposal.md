# Proposal: таблица данных и сетка правки по MD3

Дочерний change зонтика `sharedui-md3-00-epic`, общая архитектура — `../sharedui-md3-00-epic/design.md`
(D6, D7, D8, D10, D11, D12). Выбор владельца 02.11.2026 — вариант А «Data table буквально» (макеты
https://claude.ai/design/p/2d7f81d4-5708-4674-87a1-fac3ddc04e33).

## Why

Таблицы — главный рабочий вид приложения: реестры, строки счёта, матрица разноски, наборы данных. И
это самое плотное место, где старая плотность держится дольше всего:
- `DataGrid` — шапка 42 на заливке `surface-container` подписью `body-small` `on-surface-variant`,
  строка около 37;
- в `compact` — шапка 32 и строка около 25, ниже любой плотности MD3;
- открытая строка — `primary-container`, закреплённые клетки закрывают слой состояния: наведение на
  них не видно;
- `EditGrid` — поле в клетке рисует экран, и рамки у полей разные; у `sheet` строка 28 и текст 12.

В M3 таблицы данных нет. Data table — расширение из Material 2 на токенах MD3 (D8). Вариант Г задал её
вид: шапка 56 без заливки, строка 48, поле в клетке 40 без рамки. Таблица плотности D7 делает его
правилом: страница — 56 / 48, окно и боковой лист — 48 / 40.

## What Changes

- **`DataGrid`:**
  - страница: шапка 56, строка не ниже 48; `compact` (окно, боковой лист): шапка 48, строка не ниже 40;
  - шапка без своей заливки (фон контейнера), у прокрученного тела — `surface-container`; подпись
    `title-small` роли `on-surface`; черты — `outline-variant`;
  - открытая строка — `secondary-container`, и на закреплённых клетках; наведение — слоем состояния (D6),
    видимым и на закреплённых клетках;
  - обёртка-карточка — outlined card 12; итог — `surface-container` без черты.
- **`EditGrid`:** строка не ниже 48, поле в клетке 40 без рамки, заливки и черты в покое; у фокуса —
  подчёркивание `primary`, у ошибки — `error`. Вид даёт само поле — новый размер `density="cell"`; поле в
  шапке колонки (матрица разноски) остаётся плотным 40 с рамкой (В5). `sheet` (строки массива документа)
  — строка 40, текст 14, линии колонок остаются (В5).
- **Пометки строк** (`marked` — тон предупреждения) — `warning-container`; у открытой строки фон открытой
  важнее пометки.
- **Сторож** — правило храповика `cell-field`: поле в клетке `EditGrid` без `density="cell"`.
- **Живые прогоны** получают положительные проверки высот — их сегодня нет ни у одного; `site-costs-smoke`
  (строка выше сгиба на 1366×768) правится тем же PR.
- `docs/UI.md` «Таблицы» и «Плотность» — таблица D7 словами MD3, data table — в разделе отступлений.
- **Не входит:** строки списков list-detail — отдельный change с общим `ListItem` (вид — по варианту А);
  `panelLink` и `PageList` — `sharedui-md3-15-shell`; переключатель плотности в представлении таблицы.

## Capabilities

### New Capabilities
- Нет.

### Modified Capabilities
- `sharedui`: таблица данных и сетка правки по шкале плотности MD3 [UI-78].

## Impact

- **Клиент:** `shared/ui/dataTable.ts` (классы `dt*` — один источник), `DataGrid.tsx`, `EditGrid.tsx`,
  `dataGridStates.ts`, `fieldBox.ts` / `OutlinedField` и поля `NumberInput`, `Select`, `DateInput`,
  `SuggestField` (размер `cell`). Экраны с `DataGrid` (33 файла в `features/`) получают вид сами. Клетки правки — пять
  экранов с `EditGrid` и `InvoiceLineCells`, `WaybillForm`, `NomenclaturePicker`, `ComplexCells` /
  `CELL_INPUT`, `LineAllocation`. Колонка удаления `EditGrid` — шире (`w-12` / `w-14`).
- **Сторожа:** новое правило `cell-field` (своим модулем — `ui-ratchet-lib.mjs` у порога размера).
  Тесты `DataGrid.test.tsx`, `EditGrid.test.tsx`, `dataGridColumns.test.ts` — ожидания классов
  переписываются вручную, вместе с отрицательными (D11).
- **Живые прогоны:** весь список зелёный; новые проверки высот — `table-view-smoke` (шапка, строка, фон
  закреплённой клетки открытой строки), таблица в окне, `EditGrid`, `sheet` (`invoice-lines-smoke`,
  `fields-smoke`); правка `site-costs-smoke`.
- **Claude Design:** `/design-sync` после слияния.
- **Сервер:** не меняется.
- **PR:** два — `DataGrid`; сетка правки и поле `cell`. Оба с меткой `version:minor`.
