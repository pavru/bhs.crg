## ADDED Requirements

### Requirement: [COST-6.3] Значок «Файл» называет, что сделает нажатие
Значок кнопки «Файл» в сводке счёта SHALL меняться с местом файла: файл закрыт — знак «открыть панель
справа», файл открыт рядом — знак «закрыть панель справа», файл откроется поверх формы — знак
«развернуть». Подпись «Файл», подсказки и `aria-pressed` MUST NOT меняться от смены значка.

#### Scenario: Файл закрыт
- **WHEN** открыт счёт, файл закрыт, слева виден список
- **THEN** у «Файл» знак «открыть панель справа», `aria-pressed="false"`

#### Scenario: Файл открыт рядом
- **WHEN** файл открыт панелью справа, списка нет
- **THEN** у «Файл» знак «закрыть панель справа», `aria-pressed="true"`, подсказка «Скрыть файл»

#### Scenario: Файл поверх формы
- **WHEN** рядом с панелью файла форме остаётся меньше 720 px
- **THEN** у «Файл» знак «развернуть», а подсказка называет причину «поверх»

#### Scenario: Имя для диктора
- **WHEN** файл открыт или закрыт
- **THEN** имя кнопки — «Файл» в обоих состояниях
