# Spec Delta: plan

## ADDED Requirements

### Requirement: [PLAN-9.1] Материалы без единицы в «Плановых работах»
Часть `materials` контракта «Плановые работы» MUST передавать материалы без единицы отдельными
строками. Сложение количеств допустимо только внутри совпадающей непустой единицы.

#### Scenario: Две строки без единицы в одной позиции
- **WHEN** два материала одной номенклатуры и позиции перечня несут количества 60 и 40 без единицы
- **THEN** потребитель получает две строки с исходными количествами
