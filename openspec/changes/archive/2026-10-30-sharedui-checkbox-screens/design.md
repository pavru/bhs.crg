# Design: флажки экранов — на `Checkbox`

## Context

- `shared/ui/Checkbox.tsx` — нативный `input` с `accent-brand`, 18 px (`sm` — 16 px), пропы `label`,
  `description`, `indeterminate`, `forwardRef`. С подписью он оборачивается в `<label className="inline-flex …">`.
- Правило `native-checkbox` (`src/client/scripts/ui-ratchet-lib.mjs`) считает `<input type="checkbox">`
  по синтаксическому дереву, только в `features/`. Уровень — `src/client/ui-baseline.json`.
- `docs/UI.md`: таблица контролов («Флажок»), «Кто сторожит» — «накопленные (31 файл) стоят в уровне».

### Что выяснилось сверкой (22.10.2026)

- **Уровень — 35 мест в 30 файлах**, а не 36 в 31, как в issue: `features/settings/BackupSection.tsx`
  из перечня выпал. Его флажок ушёл в `BackupScheduleForm.tsx` уже на `Checkbox` (#1559, #1561).
  Уровень `BackupSection` в `file-size-baseline.json` больше не стоит — опускать нечего.
- **`Checkbox` с подписью по-прежнему `inline-flex`.** Правка «подпись — блок» была в пробном переводе
  (коммит `3bd018ac`) и откатана вместе с ним (`d94b782e`). Её надо сделать заново, первой.
- **Пробный перевод 17.10.2026 лежит в истории:** `git show c417d69c -- src/client/src/features`. Он —
  образец решений по каждому файлу, а не заплатка: файлы с тех пор менялись, переносится смысл, не дифф.
- Остальное из issue подтверждено: `FieldBuilder` (654) и `PrimitiveTypesPage` (627) стоят в
  `file-size-baseline.json`; `shared/` переведён (#1420); живые прогоны, перечисленные в issue,
  ищут флажки через `input[type=checkbox]` или по подписи.

## Goals / Non-Goals

**Goals:** уровень `native-checkbox` — ноль; вид и доступные имена флажков — одни на всех экранах.

**Non-Goals:**
- `Switch` вместо флажка там, где по смыслу переключатель: это решение экрана, не перевод;
- флажки в `shared/` — уже переведены (#1420), правило их не смотрит (расширение области — #1469,
  change `sharedui-ratchet-shared-scope`).

## Decisions

- **D1. Сначала `Checkbox`, потом экраны.** Подпись — `flex w-fit items-start gap-2`: блок по ширине
  содержимого. `w-fit`, а не `w-full`: щелчок мимо текста в пустоте строки не должен переключать
  флажок. Альтернатива — оставить `inline-flex` и оборачивать флажки экранов в `div` — отклонена:
  обёртки разошлись бы по тридцати файлам, а забытая ставила бы флажки в строку молча.
- **D2. Имя сохраняется одним из трёх способов** (из пробного перевода):
  - строка — своя разметка (иконка, несколько колонок: `WorkspacesDialog`, `PickRow`, `ColumnsPanel`) —
    `Checkbox` без `label` внутри её `<label>`;
  - иначе подпись и пояснение — пропами `label` / `description`;
  - имени нет вовсе — `aria-label`: параметр шаблона (`DocumentTemplateParams`), булева клетка таблицы
    (`ComplexCells`), значение по умолчанию (`TemplateParamsPanel`).
- **D3. Законных исключений нет** — и потому уровень ноль, а не «почти ноль». `Checkbox` — тот же
  нативный `input`: в клетку таблицы — `size="sm"` (`ComplexCells`, `ComplexFields`); под `Tooltip`
  (`TemplateParamsPanel`) — он передаёт ref; только для чтения (`PrimitiveInput`, #958) —
  `aria-readonly` и `onClick` проходят во флажок через `...rest`.
- **D4. Порядок — порциями по разделу,** уровень опускается тем же PR (`npm run ui:ratchet:update`).
  Одна порция — один набор живых прогонов: настройки (`routing`, `settings`, `types`, `fields`),
  документы (`dialogs`, `fields`), таблицы (`table-view`, `table-saved-views`). Можно и одним PR — тогда
  гоняются все семь.
- **D5. Макетов нет.** Правка — перевод на готовый компонент (`docs/UI.md`, «Новый экран: порядок»,
  «Макеты не нужны»): что человек видит и делает, не меняется. Блочная подпись `Checkbox` возвращает
  раскладку, которая на экранах уже есть.
- **Сторож.** Храповик `native-checkbox` с уровнем ноль; `ui-ratchet.test.mjs` уже проверяет счёт
  правила. Вид подписи — тест `Checkbox` (две подписи подряд — два блока).
- **Чем ломается.** Подпись осталась `inline-flex` — флажки встают в строку (виден на стенде в
  настройках почты). Потерянное имя — живой прогон не находит флажок по подписи. Похудевший файл без
  опущенного уровня размера — `FileSizeRatchet` красный в CI.

## Risks / Trade-offs

- [Флажок внутри чужого `<label>` с `label`-пропом даёт `<label>` в `<label>`] → в строках со своей
  разметкой `Checkbox` ставится без `label` (D2); ревью сверяет по перечню.
- [`PasteMappingModal` и `ComplexFields` — крупные файлы, правка задевает соседние строки] → перевод
  точечный, без попутной уборки; `ComplexFields` (779) только худеет.
- [`ui:ratchet` в CI падает, если уровень не опущен] → `npm run ui:ratchet:update` и коммит
  `ui-baseline.json` в той же порции.
