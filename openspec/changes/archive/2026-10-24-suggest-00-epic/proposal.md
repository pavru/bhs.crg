# Proposal: подсказки по ранее введённому в текстовых полях, зонтик

## Why

Issue #1527 (эпик «Подсказки по ранее введённому в текстовых полях»); дочерние — #1529, #1530, #1531,
#1532, #1533; замер #1528 закрыт, его итоги — в тексте эпика и в `design.md`. Связанный #1540
(постоянные поля документов) — отдельная задача, не в эпике.

Подсказок по ранее введённому в системе нет нигде: есть только выбор записи справочника (организации,
люди, номенклатура — #1511). Одни и те же строки человек набирает заново в каждой записи. Подсказки
браузера не годятся: у полей нет `name`, `id` создаётся заново при каждом показе (`useId` в
`shared/ui/TextField.tsx:28`), браузер помнит ввод одного человека на одном устройстве и не знает, к
какому полю типа относится значение.

Где повторы на деле (замер #1528 по копии базы заказчика, агрегаты): почти весь выигрыш — справочник
номенклатуры, поле «Производитель» (110 пар «запись — значение», 17 различных, сбережено бы 93 набора),
а заводят его в шаге «Новая позиция» из строки счёта. В документах вручную набрано мало: большинство
полей — ссылки, строки кабельного журнала приходят из файла, а повторяющиеся «Публикатор», «Раздел»,
«Шифр» по смыслу постоянны для стройки — их закрывает #1540, а не подсказка.

Решения согласованы Архитектором и Дизайнером 19.10.2026. Зонтик фиксирует их, контракт адреса,
перечень дочерних change и порядок.

## What Changes

- Поле строки, нарисованное по схеме типа, по мере набора предлагает значения, уже вводившиеся в этом
  поле в других записях: сначала со своей стройки, ниже, под разделителем «С других строек», — с
  остальных. Выбор пункта подставляет значение; обычный ввод и навигация по таблице не меняются.
- Одно правило «подсказывается ли поле» (`Suggestable`) на сервере с зеркалом на клиенте и общим файлом
  случаев; ручное выключение — функциональный тэг `input.noSuggest` (`suggest-01`).
- Адрес `GET /api/field-suggestions`: чтение на лету из JSONB записей типа и его семьи по наследованию,
  частичный индекс, окно по объёму, таймаут 503, права читателя (`suggest-02`).
- Общий компонент `SuggestField` в `shared/ui`, правило в `docs/UI.md`, стрелки `EditGrid` уступают
  только открытому списку (`suggest-03`).
- Подключение: шаг «Новая позиция» выбора номенклатуры, поля форм (`PrimitiveInput`), ячейки массивов
  (`TableCell`); флажок «Подсказывать введённое ранее» в карточке поля редактора типа; e2e (`suggest-05`).
- Источник вложенных полей и строк массивов (`suggest-04`) — **приоритет понижен**, потом и
  необязательно.
- Вне эпика: производная таблица значений, `text`, строковые `primitive`, дописанные поля счёта,
  экран «не предлагать это значение», постоянные поля документов (#1540) — `design.md`, «Не входит».

## Capabilities

### New Capabilities
- Нет в самом зонтике. Домен `sharedui` (общие компоненты интерфейса) получает требования от
  `suggest-03`.

### Modified Capabilities
- Нет в самом зонтике (`skip_specs: true`). Дельты несут дочерние change: `types-and-tags`
  (`suggest-01`, `suggest-05`), `core` (`suggest-02`, `suggest-04`, `suggest-05`), `sharedui`
  (`suggest-03`).

## Impact

- **Сервер:** `Application/Objects/FieldSuggestions/*` (запрос, план источников, правило
  `Suggestable`), порт `IFieldSuggestionReader` с реализацией в `Infrastructure`, адрес в
  `Api/Endpoints/Core`, тэг в `Domain/Schema/FunctionalTag.cs` и `Application/Schema/TagRegistry.cs`,
  миграция `AppDbContext` (индекс `domain_objects`), описание двери `/api/nomenclature/intake`

- **Клиент:** `shared/ui/SuggestField.tsx`, `shared/ui/EditGrid.tsx`, `shared/api` (правило, адрес),
  `features/costs/NewNomenclatureStep.tsx`, `features/document-sets/fields/PrimitiveInput.tsx`,
  `ComplexCells.tsx`, `features/settings/FieldBuilder.tsx` (в храповике размера — новое в свои файлы).
- **Переписи:** `ArchiveReadInventoryTests` (новое место чтения — «выбор»), `EndpointGateInventoryTests`
  (адрес с воротами внутри), круг схемы `schemaRoundTrip.test.ts`.
- **Документы:** `CLAUDE.md` и `AGENTS.md` тем же коммитом (адрес — в «REST API», подсказки — в
  «Условие пересмотра» инварианта `CatalogScope`), `docs/UI.md`, `docs/USER_GUIDE.md`,
  `docs/ADMIN_GUIDE.md` (`npm run toc`), `docs/DEV_NOTES.md` (листинг адресов), перечень `STG-11` в

- **Версия** не меняется ни одним PR: её поднимает CI; функциональные PR — с меткой `version:minor`.
