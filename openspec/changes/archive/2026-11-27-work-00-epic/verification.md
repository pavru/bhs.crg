Номера PR позволяют проследить реализацию и архив в истории `master`. Тесты указаны по проверяемому поведению. Для отложенных требований приведены решение, доступная опора и граница доказательства.

- **Старая подсказка в форме веб-ввода.** Сценарий с синтетическим ответом воспроизвёл на возвращённом отчёте текст «Добавьте материал для подачи отчёта» при пустых материалах и виде, который их уже не требует. Сервер применяет текущие правила WORK-6. Очередь и карточка приёмки используют отдельный текущий расчёт WORK-59. Дефект относится к объяснению в форме, выполнение подачи и обязательный сигнал в приёмке подтверждены. Рекомендуется сверять остаточный текст ошибки с текущим видом либо явно подписывать его как исторический. Обычный менеджер той же стройки без этого основания видит только присутствие черновика. Руководство пользователя отдельно описывает исключение для автора ввода в разделе о таблице. Действующий охват по WORK-31/39/54 соответствует спецификации и подтверждён проверками. Для документации рекомендуется указать обе категории и оговорить действующий охват.
