# Spec Delta: auth

## ADDED Requirements

### Requirement: [AUTH-16.1] [WORK-2] Раздел рейла модуля «Учёт работ»
Навигация SHALL иметь раздел рейла `work` для пунктов модуля «Учёт работ»; подпись и значок — по
макету раунда Р0. Раздел MUST NOT показываться, пока в нём нет ни одного видимого пункта. Модуль,
открытый одним правом контракта, раздела не даёт.

#### Scenario: Пользователь без прав модуля
- **WHEN** у пользователя нет прав модуля `work`
- **THEN** раздела `work` в рейле и в нижней навигации телефона нет

#### Scenario: Инженер ИД с правом контракта
- **WHEN** у «Инженера ИД» из прав модуля `work` есть только `work.facts.read`
- **THEN** раздела `work` нет, а `/api/account/access` отдаёт модуль с `available: false`

### Requirement: [AUTH-16.1] [WORK-2] Страница входа модуля «Учёт работ»
Пункты раздела `work` SHALL объявлять ранг страницы входа общим механизмом страницы входа по доступу,
а не картой «роль → страница». Пункт «Мои отчёты» (право `work.report.own`) MUST иметь ранг меньше
ранга Главной (`plan-02`, `shell-08-home`) и пунктов ядра: монтажник после входа попадает на свои отчёты
(`WORK-2`), а не на Главную. Ранги остальных пунктов `work` и
их порядок относительно «Моих отчётов» — по макету Р0. Право контракта `work.facts.read` страницу входа не меняет.

#### Scenario: Монтажник после входа
- **WHEN** входит пользователь с ролью «Монтажник»
- **THEN** открываются «Мои отчёты», а не Главная, не «Стройки» и не страница отказа

#### Scenario: Только право контракта
- **WHEN** входит «Инженер ИД», у которого из прав `work` только `work.facts.read`
- **THEN** страница входа та же, что на экземпляре без модуля `work`

#### Scenario: Модуль выключен
- **WHEN** модуль `work` выключен
- **THEN** пункты `work` в расчёт страницы входа не попадают, вход ведёт туда же, куда до модуля
