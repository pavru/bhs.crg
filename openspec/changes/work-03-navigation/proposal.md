# Proposal: навигация этапа 4 — раздел рейла `work` и страница входа модуля

Дочерний change зонтика `work-00-epic`, общая архитектура — `../work-00-epic/design.md` (D3, D15, D17,
D18).

> **Сужен решением нарезки этапа 3 (22.10.2026, D18 зонтика).** Механизмы «любое из прав», раздела
> рейла модуля, страницы входа по доступу и панелей карточки стройки строит `plan-02-navigation`. Здесь —
> раздел рейла `work` и ранги страницы входа пунктов модуля, прежде всего «Мои отчёты» монтажника.
> Требование «Страница входа по доступу» из дельты снято: его заводит `plan-02`, здесь — его применение
> к модулю `work`.

## Why

У монтажника стартовая страница своя — его отчёты (`WORK-2`), а не «Стройки»: права
`core.constructions.read` у него может и не быть. Механизм страницы входа по рангу пункта и раздел рейла
модуля приносит `plan-02`; модулю `work` остаётся объявить свой раздел и ранги своих пунктов. Без этого
монтажник после входа попадал бы на первый видимый пункт — какой окажется первым по порядку рейла, а не
на свои отчёты.

Раздел рейла нужен модулю потому, что его пункты открываются разным ролям по разным правам: монтажнику
(`work.report.own`), менеджеру (`work.report.review`), руководителю (`work.report.read.all`). Раздел без
видимых пунктов не показывается, а право контракта `work.facts.read` его не даёт (D3).

## What Changes

- Раздел рейла `work` (`RailId` += `'work'`, строка в `railSections`). Подпись и значок — по макету Р0:
  там же решается переименование «Учёт» → «Затраты» у раздела `costs`.
- Ранги страницы входа пунктов `work` — таблица констант рядом с разделом: «Мои отчёты» — меньше пунктов
  ядра; остальные и их порядок относительно «Моих отчётов» — по макету Р0. Пункты заводят change экранов (`work-21`,
  `work-22`, `work-23`) с рангом из этой таблицы; панель «Назначения» `work-12` — механизмом панелей
  карточки стройки `plan-02`.
- Правка оболочки, поэтому идёт весь список живых прогонов.

## Capabilities

### New Capabilities
- Нет.

### Modified Capabilities
- `auth`: раздел рейла модуля «Учёт работ»; страница входа модуля «Учёт работ» (ранг «Моих отчётов»).

## Impact

- **Клиент:** `shared/ui/navConfig.ts` (раздел `work`, таблица рангов входа), `shared/ui/railSections.ts`.
- **Живые прогоны:** весь список (`npm run test:e2e:ci`), `e2e/rail-checks.mjs`; вход монтажника на «Мои
  отчёты» живьём проверяет `work-22`, когда появляется пункт.
- **Документы:** `docs/USER_GUIDE.md` — раздел модуля в рейле, страница монтажника после входа.
- **Зависит от:** `plan-02-navigation` (механизмы), `plan-21-contract-permissions` (право контракта не
  даёт раздела), `work-10` (модуль).
