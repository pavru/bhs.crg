# Spec Delta: core

## ADDED Requirements

### Requirement: [PLAN-21] Экран «Ход работ» собирает ядро из вкладов модулей
Ядро SHALL отдавать «Ход работ» стройки адресом `GET /api/constructions/{id}/progress` с необязательным
отбором по разделу. Строка — вид работы и единица (через позиции перечня), колонки — вклады модулей
контрактом «Колонка Хода работ», факт — из контракта «Фактические работы», полоса затрат — из контракта
«Фактические затраты». Строка, у которой есть только план или только факт, MUST показываться.
Адрес открыт носителю любого из прав колонок и только читает.

#### Scenario: Факт без плана
- **WHEN** у позиции перечня есть принятый факт, а в действующих редакциях смет её нет
- **THEN** строка вида работы показана с пустым планом и с фактом

#### Scenario: План без факта
- **WHEN** у позиции есть план, а факта нет
- **THEN** строка показана с планом и пустым фактом

#### Scenario: Без прав колонок
- **WHEN** адрес вызывает пользователь без единого права колонок «Хода работ»
- **THEN** ответ 403

### Requirement: [PLAN-21] [CORE-34] Состояния колонок и полос «Хода работ»
Колонка или полоса, на которую у читающего нет права, SHALL приходить состоянием «скрыто правами» с
кодом права; у выключенного поставщика — «не подключено» с названием модуля из ответа контракта. Нули и
пустые колонки вместо состояний MUST NOT отдаваться. При выключенном учёте работ колонки факта нет, а
вместо неё — полоса «учёт работ не подключён».

#### Scenario: Учёт работ выключен
- **WHEN** на экземпляре нет модуля `work`
- **THEN** колонки факта в ответе нет, есть полоса «учёт работ не подключён»

#### Scenario: Нет права на сметы
- **WHEN** читает пользователь без `plan.estimate.read`
- **THEN** колонка «план по смете» приходит «скрыто правами» с кодом права, значений в ней нет

### Requirement: [CORE-34] [PLAN-21] Контракт «Колонка Хода работ»
Контракт «Колонка Хода работ» SHALL объявляться со многими поставщиками: каждый включённый модуль отдаёт
свои колонки по позициям перечня и свои полосы с состоянием, в правах читающего. Вклад выключенного
модуля MUST отсутствовать, не ломая экран.

#### Scenario: Два вклада
- **WHEN** колонки отдают два включённых модуля
- **THEN** экран показывает колонки обоих

### Requirement: [CORE-34] [WORK-57] [STG-6.1] Форма контракта «Фактические работы»
Контракт «Фактические работы» (поставщик — модуль `work`) SHALL отдавать принятые объёмы по позиции
перечня, дате, смене и разделу и называть числом не вошедшее: ждущее приёмки и несверенные бригадные
группы. Часов и сотрудников в форме ответа MUST NOT быть. До появления поставщика форма проверяется
синтетическим поставщиком в тестах.

#### Scenario: Синтетический факт
- **WHEN** тестовый поставщик «Фактических работ» засеял факт по позиции перечня
- **THEN** «Ход работ» показывает его в колонке факта этой позиции

#### Scenario: Попытка отдать часы
- **WHEN** поставщик пытается вернуть часы или сотрудников
- **THEN** форма ответа не позволяет их выразить — полей для них нет
