# Spec Delta: plan

## ADDED Requirements

### Requirement: [PLAN-21] Колонки модуля `plan` в «Ходе работ»
Модуль `plan` SHALL отдавать в «Ход работ» колонку «план по смете» — сумму действующих редакций всех смет
стройки по позиции перечня, при отборе по разделу — из распределения, — и колонку «срок по графику» —
самое раннее начало и самое позднее окончание работ графиков стройки по позиции.

#### Scenario: План по двум сметам
- **WHEN** у стройки основная и дополнительная сметы с одной позицией перечня
- **THEN** «план по смете» у позиции — сумма объёмов их действующих редакций

### Requirement: [PLAN-21] [PLAN-5.2] Полосы модуля `plan` в «Ходе работ»
Над таблицей модуль MUST отдавать полосы: по каким редакциям считается план («план по: смета „…“
ред. N»), сколько строк действующих редакций не сопоставлено с видами работ и, при отборе по разделу,
сколько плана не распределено по разделам.

#### Scenario: Смена действующей редакции
- **WHEN** действующей отмечена редакция 3
- **THEN** полоса говорит «план по: смета „…“ ред. 3», а колонка плана считается по ней

#### Scenario: Несопоставленные строки
- **WHEN** в действующей редакции 17 строк без вида работы
- **THEN** полоса говорит «строк сметы не сопоставлено: 17 — в таблице их нет» со ссылкой на сопоставление

#### Scenario: Отбор по разделу
- **WHEN** «Ход работ» открыт с отбором по корпусу 1, а 400 м плана не распределены по разделам
- **THEN** полоса говорит «не распределено по разделам: 400 м — план всей стройки», а план корпуса не включает нераспределённое

### Requirement: [PLAN-18] Факт в работах графика
Ответ графика SHALL нести у каждой работы факт по её позиции перечня и разделу из контракта «Фактические
работы» — объём без часов — с состоянием. При выключенном учёте работ MUST приходить состояние «учёт работ
не подключён», а не нулевой факт.

#### Scenario: Учёт работ выключен
- **WHEN** график читают на экземпляре без модуля `work`
- **THEN** у работ состояние факта «не подключено», числа факта нет

#### Scenario: Учёт работ включён
- **WHEN** по позиции работы есть принятый факт
- **THEN** у работы виден факт-объём этой позиции и раздела
