# Proposal

## Why

Клиент проверяется и собирается на Node 22 (CI — `node-version: '22'` в двух работах, образ `web` —
`node:22.23.3-alpine`), а разработчик работает на Node 26.13.0. Две версии — два набора правды:
`npm test` локально красный пятью файлами, которых в CI не видно (ловушка webstorage), и наоборот,
CI может не увидеть того, на что разработчик уже опирается. Владелец 04.11.2026 решил: одна версия
везде, последняя — как у разработчика, `26.13.0`.

Единственное, что держалось именно на Node 22, — сторож заплаток pdf.js ([UI-21]): он ловил пропуск
заплатки потому, что в Node 22 нет `Map.getOrInsertComputed`, `Math.sumPrecise`, `Uint8Array.toBase64`.
В Node 26 они есть, и тест стал бы зелёным всегда. Решение владельца (04.11.2026): **тест сам
воспроизводит границу браузеров** — убирает из среды функции, которых на границе нет, и только потом
грузит pdf.js.

## What Changes

- **Один источник версии** — `.nvmrc` в корне (`26.13.0`). CI берёт его (`node-version-file`), образ
  `web` — `node:26.13.0-alpine`, `engines.node` клиента — `>=26.13.0` (с `engine-strict` ниже порога
  `npm ci` падает — так и задумано). **BREAKING для разработчика**: на Node ниже 26.13.0 установка
  зависимостей клиента отказывает с EBADENGINE.
- **Сторож согласованности версий**: тест, что `.nvmrc`, `FROM` в `deploy/Dockerfile.web` и нижние
  границы `engines` (клиент и `docs/tools`) называют одну версию. Разошлись — красный с названием места.
- **vitest под Node 26**: встроенный в Node 26 `localStorage` перекрывает хранилище jsdom — воркеры
  тестов запускаются с выключенным webstorage Node, и `npm test` зелёный и локально, и в CI.
- **Сторож заплаток pdf.js не зависит от версии Node** ([UI-21]): тест движка перед загрузкой
  библиотеки убирает из встроенных объектов всё, чего нет в записанной поверхности границы
  (снята с Node 22, по набору функций не новее Chrome 126), и проверяет, что граница действительно
  наступила — функции на месте только заплаточные.
- Тексты, называвшие Node 22 (комментарии CI, dependabot, `.npmrc`, `package.json`, DEV_NOTES,
  CLAUDE.md и его копия AGENTS.md, требование [UI-21]), — согласованы.

### Modified Capabilities
- `sharedui`: [UI-21] — сценарий «Обновлённая библиотека вызывает новую функцию» больше не ссылается

## Impact

- `.nvmrc` (новый), `.github/workflows/ci.yml` (две работы), `.github/dependabot.yml` (комментарии),
  `deploy/Dockerfile.web`.
- `src/client`: `package.json` (`engines`, `//engines`), `.npmrc` (комментарий), `vite.config.ts`
  (аргументы воркеров vitest), `src/shared/ui/viewer/pdfEngine.test.ts` и `pdfPolyfills.ts`
  (комментарии), новый помощник границы с записанной поверхностью, новый тест согласованности версий.
- `docs/tools/package.json` (`engines`), `docs/DEV_NOTES.md`, `CLAUDE.md` + `AGENTS.md`,
  `openspec/specs/sharedui/spec.md` (через архив).
- Сервер не затрагивается; `<Version>` не меняется.
