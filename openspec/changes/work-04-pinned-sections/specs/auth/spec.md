# Spec Delta: auth

## ADDED Requirements

### Requirement: [AUTH-16.4] [CORE-25.3] Закреплённые разделы хранит сервер
Список закреплённых разделов SHALL храниться серверной настройкой пользователя `pinnedSections` —
JSON-списком адресов разделов, не больше 20, без повторов. Значение другой формы сервер MUST отвергать
вместе со всем набором правки. Браузер держит зеркало и не отправляет его наверх при загрузке.

#### Scenario: Другой компьютер
- **WHEN** пользователь закрепил «Счета» и вошёл с другой машины
- **THEN** «Счета» стоят в группе «Закреплённые»: список пришёл с сервера

#### Scenario: Двадцать первый раздел
- **WHEN** клиент отправляет в `PUT /api/account/settings` список из 21 адреса или адрес не по форме
- **THEN** ответ 400 «Недопустимое значение настройки pinnedSections», прежний список не меняется

#### Scenario: Ключа на сервере нет
- **WHEN** сервер ответил, а ключа `pinnedSections` нет
- **THEN** группы «Закреплённые» нет, зеркало прежнего хозяина машины не применяется

### Requirement: [AUTH-16.4] Закрепление в навигации
Пользователь SHALL закреплять и откреплять раздел значком булавки. Звезда остаётся за «Избранными
стройками». Закреплённые разделы стоят группой «Закреплённые» вверху навигации в порядке закрепления.
Недоступный раздел MUST NOT попадать в группу. Раздел вне текущего пространства в группе есть, с
пометкой «вне пространства».

#### Scenario: Закрепить раздел
- **WHEN** пользователь нажимает булавку у раздела «Накладные»
- **THEN** «Накладные» появляются в группе «Закреплённые», булавка у пункта становится закрашенной

#### Scenario: Раздел вне пространства
- **WHEN** закреплённый раздел не входит в текущее пространство
- **THEN** в группе он помечен «вне пространства» и открывается с плашкой «Открыто вне пространства „…“»; пространство не меняется

#### Scenario: Пропало право
- **WHEN** у пользователя сняли право на закреплённый раздел
- **THEN** раздела нет в группе «Закреплённые», меню строится без ошибок, остальные закрепления на месте

### Requirement: [AUTH-16.4] [AUTH-16.7] Закреплённые разделы в профиле
Профиль SHALL показывать раздел «Закреплённые разделы» со всеми адресами списка. Доступный раздел —
названием. Недоступный — названием и пометкой «нет доступа: нужно право X» или «нужен модуль X» по
ответу `/api/account/access`. Адрес, которого нет в навигации, — пометкой «раздела больше нет». Из
списка адрес MUST уходить только по «Открепить».

#### Scenario: Недоступный закреплённый раздел
- **WHEN** у пользователя сняли `costs.waybill.read`, а «Накладные» закреплены
- **THEN** в профиле «Накладные» стоят с пометкой «нет доступа: нужно право costs.waybill.read» и кнопкой «Открепить»

#### Scenario: Право вернули
- **WHEN** право на закреплённый раздел выдали снова
- **THEN** раздел возвращается в группу «Закреплённые» без повторного закрепления

#### Scenario: Раздел убран из навигации
- **WHEN** в списке есть адрес раздела, которого в навигации новой версии нет
- **THEN** профиль показывает адрес с пометкой «раздела больше нет» и кнопкой «Открепить», а в меню его нет
