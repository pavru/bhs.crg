# Design: подсказка о перетаскивании сканов

Общая архитектура — `../shell-00-epic/design.md` (D1 — макет, D6 — живые прогоны). Макет — пунктирная
строка под списком на артборде «B · Счета» канваса варианта B; положение задаёт issue (на макете строка
под таблицей — упрощение макета). Новых макетов не нужно: строка выбрана решением эпика.

## Context

Сверено по коду ветки от master `c9586405`.

- Цель перетаскивания — `InvoiceScanDrop` (`features/costs/InvoiceScanDrop.tsx:22`): `div` с
  `relative flex-1 min-h-0 flex flex-col`, внутри — поиск, чипы очередей, полоса пакета и прокручиваемый
  блок `flex-1 overflow-y-auto` (`InvoicesPage.tsx:380-447`). Рамки накрывают цель `absolute inset-1`.
  Значит, строка — последним ребёнком внутри цели, после прокручиваемого блока: она не прокручивается и
  рамкой накрывается.
- `enabled` цели — `costs.invoice.edit && !loading` (`InvoicesPage.tsx:380`).
- Форматы уже считаются: `readable = recognizedKinds(kinds.data)` из `useFileKinds()` (`GET /api/files/kinds`,
  `InvoicesPage.tsx:308-309`), словами — `wordsOf(readable)`; выбор файла — скрытый `input` `scanInput`
  с `accept={acceptOf(readable)}`, кнопка — `PrimaryActionButton` «Счёт из файла» (`:358-372`).
  Свой перечень форматов в строке завёл бы второй источник — `fileKinds.ts` прямо это запрещает.
- **Что выяснилось сверкой:** упоминание уже есть, но спрятано — во всплывающей подсказке кнопки:
  «Один или несколько файлов: … Файлы можно перетащить на список счетов.» (`InvoicesPage.tsx:363`). На
  телефоне подсказки нет вовсе, а основное действие там — плавающая кнопка (`PrimaryFab`, #1434).
- Пустое состояние без отбора — «Счетов пока нет.» (`invoiceQueues.ts`, `emptyText`, ветка `default`).
- Файл `InvoicesPage.tsx` — 550 строк вместе с комментариями; строку кладём в `InvoiceScanDrop.tsx`
  (162 строки), страница только передаёт данные.

## Goals / Non-Goals

**Goals:** умение видно без наведения и без перетаскивания; текст правдив о форматах и о фоне.

**Non-Goals:** перетаскивание на открытый счёт (правая часть — не цель, D4 #1093); подсказка на экране
накладных; новые виды файлов.

## Decisions

- **Компонент.** `InvoiceScanDrop` получает `hint?: { formats: string | null; onPick: () => void }`;
  строка рисуется внутри цели, после `children`, `shrink-0`, с верхней чертой `border-t border-stroke`,
  `text-xs text-fg3`, значок `Upload` 16 px. «Выбрать файл» — текстовая кнопка (`Button variant="text"
  size="sm"`), не вторая filled: основная на экране одна (`docs/UI.md`). `onPick` — тот же
  `scanInput.current?.click()`, что у кнопки и у намерения палитры (`usePaletteIntent`).
- **Текст** (рабочий, окончательный — по Дизайнеру на ревью): «Перетащите сюда файлы счетов
  ({formats}) — заведём черновики и распознаем их в фоне; поля заполнятся после распознавания, их
  останется проверить. **Выбрать файл**». Без форматов (реестр не пришёл) — та же фраза без скобок:
  «не пришло» не превращается в выдуманный перечень.
- **Когда видна:** `enabled` цели (право и не идёт загрузка) И рабочий стол (`useMedia(WIDE)`,
  `shared/hooks/useMedia.ts`). Пока идёт пакет, строки нет — над списком полоса пакета говорит о ходе. На
  телефоне строки нет: перетаскивать там нечем, а видимый вход — плавающая кнопка «Счёт из файла»; строка
  «перетащите» была бы неправдой (правило «подсказка — пояснение, а не единственный путь»).
- **Пустой список.** Список пуст, отбора и поиска нет — строка внизу не рисуется, а пустое состояние
  получает ту же фразу с «Выбрать файл». Под отбором или поиском пустота — про отбор, и строка внизу
  остаётся.
- **Подсказка кнопки** «Счёт из файла» сохраняет фразу о перетаскивании: на рабочем столе она дублирует
  строку, но описывает кнопку, а не экран, и снимать её незачем.

### Сторож и «чем ломается»
- Vitest для `InvoiceScanDrop`: строка есть при `enabled` и `hint`, нет без права; без форматов — без
  скобок; «Выбрать файл» зовёт `onPick`.
- Живой прогон `e2e/invoice-layout-checks.mjs`: при длинном списке строка у нижнего края колонки и не
  перекрывает последнюю строку (геометрия: низ последней строки ≤ верх строки-подсказки); при
  перетаскивании рамка накрывает строку. Плюс весь список живых прогонов (зонтик, D6).
- Ломается так: строка внутри прокрутки (уезжает при сотне счетов); строка поверх последней строки
  списка; перечень форматов, расходящийся с тем, что принимает выбор файла.

## Risks / Trade-offs

- [Тихая строка становится шумом у тех, кто умение знает] → одна строка `text-xs`, без цвета и рамки;
  убрать её «насовсем» — по запросу владельца, личной настройкой, как «Полезно знать» на Главной.
- [Высота колонки на невысоком экране] → строка в одну-две строки текста; список и так прокручивается.
