# Spec Delta: types-and-tags

## ADDED Requirements

### Requirement: [TYPE-1] [CORE-30.2] Умолчание поля из профиля уровня
Умолчание поля схемы SHALL быть значением или ссылкой на поле профиля уровня документа (стройка, раздел,
комплект); переопределение в потомке (`fieldOverrides`) — тоже. Форма документа MUST показывать такое
умолчание с источником, не копируя его в реквизиты; генерация подставляет его порядком «экземпляр >
привязка набора > умолчание».

#### Scenario: Публикатор из профиля стройки
- **WHEN** у поля «Публикатор» умолчание — поле «Публикатор» профиля стройки, а в документе поле пусто
- **THEN** форма показывает значение профиля с пометкой «из профиля стройки», PDF печатает его же

#### Scenario: Профиль поправили
- **WHEN** в профиле стройки сменили «Публикатора»
- **THEN** документы стройки с пустым полем показывают и печатают новое значение без правки каждого

#### Scenario: Своё значение в документе
- **WHEN** в документе поле заполнено руками
- **THEN** печатается значение документа, профиль его не перекрывает

#### Scenario: В профиле пусто
- **WHEN** в профиле стройки поле не заполнено или профиля нет
- **THEN** форма называет «в профиле стройки не задано», а не показывает пустое поле как заполненное

#### Scenario: Круг схемы
- **WHEN** администратор открывает и сохраняет тип с умолчанием из профиля, правя другое поле
- **THEN** ссылка умолчания сохраняется без изменений; у поля модуля её правка запрещена, как правка умолчания
