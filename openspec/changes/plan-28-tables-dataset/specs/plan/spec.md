# Spec Delta: plan

## ADDED Requirements

### Requirement: [CORE-33] [CORE-24] [STG-6.2] Таблицы и наборы модуля `plan`
Модуль SHALL объявлять таблицы «Строки смет» (строки действующих редакций, под `plan.estimate.read`),
«Коммерческие предложения» (действующие версии, под `plan.offer.read`) и «Работы графиков» (под
`plan.schedule.read`); системные наборы `system:table:plan.*` получаются из них. Таблица строк смет MUST
отдавать только строки действующих редакций.

#### Scenario: Наборы модуля
- **WHEN** включён модуль `plan`
- **THEN** доступны наборы `system:table:plan.estimate-rows`, `system:table:plan.offers`, `system:table:plan.schedule-works` под правами своих таблиц

#### Scenario: Повторный импорт
- **WHEN** у сметы две редакции, действующая — вторая
- **THEN** таблица строк смет отдаёт строки только второй редакции

#### Scenario: Без права на КП
- **WHEN** таблицу КП читает пользователь без `plan.offer.read`
- **THEN** ответ 403, набор КП ему не виден

### Requirement: [PLAN-11] [PLAN-23] Деньги сметы в таблицах — под правом на себестоимость
Колонки стоимости строки сметы и поля схемы `ПозицияСметы` в таблице, выгрузке XLSX и наборе SHALL
стоять под `plan.estimate.cost`. Читающему без права они MUST приходить помеченными «скрыто правами», без
значений. Себестоимости в таблице КП MUST NOT быть.

#### Scenario: Сметчик без права на себестоимость
- **WHEN** таблицу строк смет читает и выгружает пользователь с `plan.estimate.read` без `plan.estimate.cost`
- **THEN** ни в строках, ни в файле XLSX, ни в наборе нет ни одного денежного значения, колонки помечены «скрыто правами»

#### Scenario: Поле заказчика
- **WHEN** заказчик добавил в схему `ПозицияСметы` числовое поле без тэга
- **THEN** оно тоже под `plan.estimate.cost` и без права не отдаётся
