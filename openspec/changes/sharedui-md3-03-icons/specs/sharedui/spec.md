# Spec Delta: sharedui

## ADDED Requirements

### Requirement: [UI-60] Значок — один компонент на наборе Material Symbols
Значок в интерфейсе SHALL рисоваться общим компонентом значка из набора Material Symbols выбранного
стиля как встроенный SVG: цвет — цвет текста, для вспомогательных технологий скрыт по умолчанию. Имя
значка MUST NOT попадать в текст страницы. Выбранное состояние (пункт навигации, выбранный чип,
включённая кнопка-переключатель) SHALL показываться залитым вариантом того же значка.

#### Scenario: Кнопка из одной иконки
- **WHEN** читают `textContent` и доступное имя кнопки «Удалить» со значком корзины
- **THEN** в тексте нет слова `delete`, имя — «Удалить» из её подписи

#### Scenario: Выбранный раздел рейла
- **WHEN** раздел рейла выбран
- **THEN** его значок залит, у невыбранных — контур

#### Scenario: Тёмная тема
- **WHEN** значок стоит в тексте `text-on-surface-variant` и тему переключают на тёмную
- **THEN** значок меняет цвет вместе с текстом

#### Scenario: Ничего не загружается отдельно
- **WHEN** страница открыта без сети после загрузки бандла
- **THEN** все значки видны сразу, без подмены словами и без запроса шрифта

### Requirement: [UI-60] Набор значков — из манифеста, один смысл — один значок
В бандл SHALL попадать только значки, перечисленные в манифесте; сгенерированный набор MUST лежать в git и
совпадать с перегенерацией. Один смысл SHALL иметь один значок во всём клиенте: синонимы прежнего набора
(предупреждение, ошибка, успех, справка) сводятся к одному.

#### Scenario: Значок вне манифеста
- **WHEN** экран ссылается на значок, которого нет в манифесте
- **THEN** `npx tsc -b` красный: такого экспорта нет

#### Scenario: Манифест поправили без перегенерации
- **WHEN** в манифест добавлен значок, а генератор не запущен
- **THEN** `npm test` красный и называет команду перегенерации

#### Scenario: Предупреждение
- **WHEN** на экранах показывают знак предупреждения
- **THEN** везде один и тот же значок `warning`

### Requirement: [UI-60] Значки — только через общий компонент
Храповик `lucide-import` SHALL считать по всему `src/` импорт `lucide-react` и импорт пакета Material
Symbols в обход набора значков `shared/ui`, с базовым уровнем 0 после перевода; зависимости `lucide-react`
в клиенте MUST NOT быть.

#### Scenario: Возврат прежнего набора
- **WHEN** в файл экрана добавлен `import { Trash2 } from 'lucide-react'`
- **THEN** `npm run ui:ratchet` красный с правилом `lucide-import`, и `npx tsc -b` красный: пакета нет

#### Scenario: Пакет значков напрямую
- **WHEN** экран импортирует SVG из пакета Material Symbols, минуя набор `shared/ui`
- **THEN** `npm run ui:ratchet` красный с тем же правилом

### Requirement: [UI-60] Размер значка — ступень шкалы
Размер значка SHALL быть ступенью шкалы, выбранной владельцем и записанной в `docs/UI.md`; храповик
`icon-size` SHALL считать по всему `src/` размер общего компонента значка вне шкалы, с уровнем 0.

#### Scenario: Размер вне шкалы
- **WHEN** экран ставит значку `size={13}`
- **THEN** `npm run ui:ratchet` красный с правилом `icon-size` и перечнем ступеней

### Requirement: [UI-60] Значки не утяжеляют основной бандл сверх бюджета
Рост основного чанка клиента после перехода на набор Material Symbols SHALL NOT превышать бюджет,
названный в `design.md` до кода; замер до и после MUST стоять в описании PR перевода.

#### Scenario: Замер в PR
- **WHEN** собран клиент (`npm run build`) на master до перевода и на ветке после
- **THEN** разница основного чанка в gzip не больше бюджета, оба числа — в описании PR

### Requirement: [UI-61] Ход операции — индикатор, а не вращающийся значок
Ход операции без известной доли SHALL показываться общим круговым индикатором MD3, а не вращающимся
значком. Индикатор вне подписанного места MUST иметь роль `progressbar` и имя; внутри кнопки или строки с
текстом хода он скрыт для вспомогательных технологий. Храповик `spinner-icon` SHALL считать
`animate-spin` на значке, с уровнем 0.

#### Scenario: Кнопка во время сохранения
- **WHEN** кнопка «Сохранить» ждёт ответа
- **THEN** в ней круговой индикатор, а доступное имя кнопки остаётся «Сохранить»

#### Scenario: Загрузка панели
- **WHEN** панель ждёт данных и показывает только индикатор
- **THEN** у индикатора роль `progressbar` и имя «Загрузка…»

#### Scenario: Вращающийся значок
- **WHEN** в файл добавлен значок с `animate-spin`
- **THEN** `npm run ui:ratchet` красный с правилом `spinner-icon` и советом `CircularProgress`

#### Scenario: Уменьшение движения
- **WHEN** в системе включено `prefers-reduced-motion`
- **THEN** индикатор остаётся видимым и движется медленнее или пульсирует, а не пропадает
