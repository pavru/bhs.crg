# Ошибки обязательных полей в веб-форме отчёта

## Why

Возвращённый после автоподачи отчёт может показывать красную ошибку у пустого поля, обязательность которого уже сняли в справочнике видов работ. Монтажник видит требование заполнить поле, хотя повторная подача по действующим правилам [WORK-6] его допускает. [Issue #2133](https://github.com/pavru/bhs.crg/issues/2133)

## What Changes

- При открытии возвращённого отчёта обновлять сведения о видах работ. Пометка «Нужно для ИД» отражает текущее содержимое строки и признаки вида из справочника [WORK-6].
- Показывать красные ошибки, переходы к полям и автоматический фокус по ответу `422` на ручную подачу. Применить правило в общей веб-форме своих отчётов и ввода за сотрудника [WORK-6].
- Хранить перечень пропусков автоподачи в ответе чтения и в записи журнала согласно [WORK-10]. Очередь и карточка приёмки по-прежнему рассчитывают пометку по [WORK-59].

## Impact

- Веб-форма отчёта, запрос справочника видов работ, регрессии формы и пояснение в руководстве пользователя.
- Область изменения ограничена веб-вводом Work. Действующие ответы API, правила ручной и автоматической подачи, журнал и приёмка сохраняют свои контракты.
