# Spec Delta: core

## ADDED Requirements

### Requirement: [CORE-21] [CORE-14] Печать записи модуля шаблоном Typst
Модуль SHALL объявлять печатную форму своей записи: тип записи, право чтения и поставщик контекста.
Ядро MUST печатать запись общим механизмом Typst — шаблон привязан к типу записи, блоки типов,
библиотека и ассеты те же, что у документов. Контекст печати SHALL собираться в правах печатающего:
поле, закрытое правами, в контекст не попадает вовсе. Объявленная форма без поставщика контекста MUST
останавливать старт с названием формы.

#### Scenario: Печать записи
- **WHEN** пользователь с правом чтения формы печатает запись модуля
- **THEN** ответ — PDF по шаблону по умолчанию для типа записи

#### Scenario: Нет права чтения
- **WHEN** пользователь без права чтения, объявленного формой, печатает запись
- **THEN** ответ 403

#### Scenario: Модуль-владелец выключен
- **WHEN** экземпляр работает без модуля-владельца типа, а клиент вызывает печать записи этого типа
- **THEN** ответ — отказ выключенного модуля

#### Scenario: У типа нет шаблона
- **WHEN** печать вызвана для типа, у которого нет ни одного активного шаблона
- **THEN** ответ 409 с причиной «у типа нет шаблона печати», а не пустой PDF

#### Scenario: Форма без поставщика контекста
- **WHEN** модуль объявил печатную форму, а поставщика контекста не зарегистрировал
- **THEN** приложение не стартует и называет форму

#### Scenario: Поле закрыто правами
- **WHEN** печатает пользователь без права на часть полей записи
- **THEN** этих полей нет в контексте генерации — ни пустыми, ни нулями

### Requirement: [CORE-21] Шаблоны печатных форм записей модулей без модуля `id`
Шаблоны типов записей модулей и общая библиотека Typst SHALL правиться правом ядра `core.print.edit`,
а шаблоны типов модуля `id` — прежним `id.config.edit`. Установка без модуля `id` MUST позволять
открыть и настроить шаблон печатной формы записи модуля.

#### Scenario: Установка только с планированием
- **WHEN** экземпляр работает с `Modules__Enabled=plan`, и администратор открывает шаблоны
- **THEN** шаблон печатной формы КП открывается и сохраняется

#### Scenario: Право `id` и шаблон модуля
- **WHEN** пользователь только с `id.config.edit` правит шаблон типа записи модуля `plan`
- **THEN** ответ 403
