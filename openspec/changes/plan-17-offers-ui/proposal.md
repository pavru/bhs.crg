# Proposal: экраны коммерческих предложений и прайс-листа

Дочерний change зонтика `plan-00-epic`, общая архитектура — `../plan-00-epic/design.md` (D2, D4, D5, D17, D18).

## Why

Сервер КП (`plan-13`), прайс-листа (`plan-14`), печати (`plan-15`) и производных (`plan-16`) без экрана
недоступен менеджеру проекта. Коммерческие предложения живут внутри «Смет» как производные редакции, а
КП без сметы — только в глобальном разделе модуля: третьего пункта у стройки нет (`PLAN-20`, `PLAN-22`).
Экран обязан показывать то, что сервер знает и что человеку легко упустить: КП отправлено и больше не
правится (`PLAN-12`), смета изменилась после КП (`PLAN-13`), себестоимость видна только с правом на сметы
(`PLAN-11`).

## What Changes

- **Макеты П3** — три варианта в Claude Design, выбор владельца, код после выбора (`docs/UI.md`, #1545).
- **PR 1 — КП.**
  - Глобальный раздел «Коммерческие предложения» в разделе рейла «Планы» (заголовок «Планирование», механизм `plan-02`) — все КП, в
    том числе без сметы; на `DataGrid`, статус и дата отправки в строке (`PLAN-12`).
  - Карточка КП: строки, наценки на всё / раздел / строку, итог, режим НДС (решение В-9);
    себестоимость рядом с ценой — только когда сервер её отдал (держатель `plan.estimate.cost`), иначе
    колонки нет и строка над таблицей «себестоимость скрыта правами».
  - Действия статуса: «Отметить отправленным» с датой (право `plan.offer.send`), итог «принято /
    отклонено / без ответа»; отправленное — только чтение и «Новая версия»; история версий.
  - Полоса «смета изменилась» (`drift` с сервера) и окно обновления с предпросмотром разницы (`plan-16`);
    409 «смета изменилась после предпросмотра» — окно перечитывает разницу.
  - «Печать» — PDF по шаблону (`plan-15`).
  - «Сделать КП» из редакции — действие в карточке сметы (`plan-09`), окно выбора наценки и печатной формы.
- **PR 2 — прайс-лист, КП без сметы, производные.**
  - Экран прайс-листа: вид работы, единица, действующая цена, история дат; правка — держателю
    `plan.pricelist.edit`.
  - Окно «КП по прайс-листу»: стройка, дата, виды работ с объёмами; строки без цены — с пометкой сервера.
  - Блок «Производные» под сметой (`PLAN-22`): КП и графики по редакциям, покрытие, «устарело»,
    «скрыто правами» — из ответа сервера.

## Capabilities

  закрытых правами сведений.
