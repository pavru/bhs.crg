# Proposal: перевод классов на роли MD3 перезапускаемым кодмодом

Дочерний change зонтика `sharedui-md3-00-epic`, общая архитектура — `../sharedui-md3-00-epic/design.md`
(D2, D3, D11). После `sharedui-md3-01-tokens`.

## Why

После 01 роли MD3 существуют, а старые имена — псевдонимы, которые рисуют то же (D2). Код всё ещё пишет
на словаре Fluent: около 3,5 тыс. мест из 5,3 тыс. переводятся один к одному, без изменения вида. Руками
и серией `sed` это не сделать: классы живут в любых строках, а параллельные ветки обязаны обновляться
механически, а не в «тихую неделю» (D3).

## What Changes

- **Кодмод в git:** `src/client/scripts/md3-migrate.mjs` и карта `md3-class-map.json`, команда
  `npm run md3:migrate`. Переводит старые имена во всех строках файлов `src/client/src` — `className`,
  карты вариантов, `clsx`, шаблоны, константы, ожидания тестов, комментарии — с сохранением вариантов
  `hover:`, `dark:`, `/opacity`, `!`. Повторный запуск ничего не меняет.
- **Карта однопроходная** и общая для эпика: имя цвета (любая утилита), полный класс и переменная
  (`--f-*`, `var(--color-<старое>)`). Дети 03, 04, 05–07 дописывают в неё свои строки.
- **Неоднозначное не трогается**, а перечисляется отчётом: `text-fg3`, `text-fg4`, `text-stroke-strong`,
  `text-brand-hover` без наведения, `brand-hover`/`brand-pressed`, `fg-disabled`, `warning-border`,
  `stroke-subtle`, `text-base` (это размер) и отрицательные ожидания тестов — их переписывают руками.
- **Прогон по всему `src/` одним PR** (~330 файлов). Уровень `legacy-class` опускается до неоднозначного
  остатка; фикстуры `white-on-fill` — на именах ролей.
- **Доказательство «вид не изменился»** — тест карты: у каждой пары объявления CSS старого и нового класса
  с разрешёнными переменными совпадают в обеих темах.
- **Как обновить чужую ветку** — в `docs/UI.md` и в описании PR: слить master до перевода, затем коммит
  перевода (по номеру PR) с версией ВЕТКИ в конфликтах (`git merge -X ours`), `npm run md3:migrate` и
  `npm run ui:ratchet`, закоммитить.
  Версия master в конфликтах молча теряет правки ветки в тех же строках — проверено на живой ветке.

## Capabilities

### New Capabilities
- Нет.

### Modified Capabilities
- `sharedui`: перевод старых имён — перезапускаемой командой по карте, без изменения вида, с отчётом
  неоднозначного [UI-58].

## Impact

- **Клиент:** ~330 файлов `src/client/src` (только замена имён, число строк не меняется); новые
  `scripts/md3-migrate.mjs`, `scripts/md3-class-map.json`, `scripts/md3-migrate.test.mjs`;
  `ui-baseline.json`, `ui-ratchet.test.mjs`, `package.json` (команда). Новых зависимостей нет.
- **Параллельные ветки:** конфликты текстовые, снимаются перезапуском. PR сливается сразу после зелёного
  CI; следующий PR обновляется после коммита бота.
- **Документы:** `docs/UI.md` — раздел «Перевод: как обновить ветку», «Цвет» — роли без старых имён в
  примерах.
- **PR:** один, без метки `version:minor`: вид не меняется.
