# Spec Delta: core

## ADDED Requirements

### Requirement: [CORE-11] [CORE-34.2] [AUTH-19] Принудительное удаление позиций перечня
Позиции перечня работ, которые держат только данные выключенных или снятых модулей либо не держит
никто, SHALL удаляться принудительно — правом `core.catalog.purge`, вводом числа удаляемых позиций,
целиком или никак. Число теряемых ссылок MUST показываться до ввода и писаться в журнал действий.

#### Scenario: Вид работы, занятый перечнем выключенного модуля
- **WHEN** администратор удаляет вид работы, позиции перечня которого держат только данные выключенного модуля `plan`, и вводит число позиций
- **THEN** позиции удалены, журнал называет число позиций и потерянных ссылок, вид работы затем удаляется обычным путём

#### Scenario: Без права
- **WHEN** принудительное удаление позиций вызывает пользователь без `core.catalog.purge`
- **THEN** ответ 403, позиции на месте

#### Scenario: Неверное число
- **WHEN** введённое число не совпадает с числом позиций на момент удаления
- **THEN** ответ — отказ со свежим предложением (число позиций и ссылок), ничего не удалено

#### Scenario: Держит включённый модуль
- **WHEN** хоть одну из позиций держат данные включённого модуля
- **THEN** ответ — отказ и при праве `core.catalog.purge`, ни одна позиция не удалена

#### Scenario: Позиции, которые не держит никто
- **WHEN** позиции вида работы не держит ни один модуль
- **THEN** то же действие удаляет их с числом потерянных ссылок 0

#### Scenario: Проверить держателей не удалось
- **WHEN** скан держателей не смог прочитать колонку модуля
- **THEN** ответ — отказ, как при занятой записи: непрочитанное могло держать
