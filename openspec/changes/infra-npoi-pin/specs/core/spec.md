# Spec Delta

## ADDED Requirements

### Requirement: [CORE-33] Выгрузка XLSX не зависит от шрифтов машины
Выгрузка в XLSX (таблицы модулей, источник набора данных, отчёт сверки) SHALL NOT измерять текст шрифтами машины, на которой работает сервер. Ширина колонок MUST считаться по содержимому клеток. Набор установленных шрифтов, их порядок на диске и нечитаемый шрифтовой файл MUST NOT влиять ни на успех выгрузки, ни на её содержимое.

#### Scenario: Первый шрифт машины нечитаем
- **WHEN** на сервере первым установленным шрифтом стоит файл без таблиц очертаний (например, растровый цветной эмодзи без `loca`), а шрифта книги по умолчанию нет
- **THEN** выгрузка XLSX завершается успешно, без отказа шрифтовой библиотеки

#### Scenario: Длинная выгрузка
- **WHEN** в выгрузке строк больше, чем книга держит в памяти, и строки сбрасываются на диск по ходу записи
- **THEN** выгрузка завершается успешно, все строки на месте, ширина колонки — по самому длинному значению в ней

#### Scenario: Ширина не зависит от машины
- **WHEN** одна и та же выгрузка сделана на машинах с разными наборами шрифтов
- **THEN** ширина колонок в файлах одинакова
