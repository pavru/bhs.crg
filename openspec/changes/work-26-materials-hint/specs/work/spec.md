# Spec Delta: work

## ADDED Requirements

### Requirement: [WORK-5.1] [COST-18] [PLAN-9.1] Подсказка материалов ярусами
Адрес `GET /api/work/materials/hint` SHALL отдавать для стройки, вида работы и позиции перечня строки
три яруса по порядку: `issued` — отпущено на стройку, `estimate` — ресурсы позиции сметы, `catalog` —
справочник поиском по `q`. Позиция, уже стоящая в верхнем ярусе, MUST NOT повторяться в нижнем. У
позиции сметы, не отпущенной на стройку, сервер ставит `notIssued: true` с текстом «не отпущен»; выбрать
её можно.

#### Scenario: Отпущенное первым
- **WHEN** на стройку проведена накладная с кабелем ВВГнг 3×2,5, и он же есть в ресурсах позиции сметы
- **THEN** кабель стоит в `issued` и не повторяется в `estimate`

#### Scenario: Смета без отпуска
- **WHEN** в ресурсах позиции сметы есть коробка распаечная, а на стройку её не отпускали
- **THEN** коробка стоит в `estimate` с `notIssued: true` и текстом «не отпущен»

#### Scenario: Справочник поиском
- **WHEN** монтажник ищет «гофра» в подсказке
- **THEN** `catalog` отдаёт действующие позиции справочника, архивные не предлагаются, а их число названо полем `inArchive`
- **AND** если список отсечён, `catalog` несёт `more: true`

### Requirement: [WORK-48] Отпущенное — без количеств и без набора
Ярус `issued` SHALL отдавать только позиции номенклатуры и единицу, без количеств, дат и накладных.
Отпущенное MUST читаться контрактом «Материалы на объекте» в правах спрашивающего — правом контракта
`costs.materials.hint`, а не адресом `costs` по HTTP и не набором данных.

#### Scenario: Монтажник с узким правом
- **WHEN** монтажник с `costs.materials.hint` запрашивает подсказку по своей стройке
- **THEN** `issued` несёт позиции, а в ответе нет ни количества, ни номера накладной

#### Scenario: Без узкого права
- **WHEN** у спрашивающего нет ни `costs.materials.hint`, ни `costs.materials.read`
- **THEN** `issued` приходит с `state: hidden` и кодом недостающего права, а не пустым списком

### Requirement: [WORK-5.1] [CORE-34] Состояния ярусов
Каждый ярус SHALL нести `state`: `ok`, `not-connected` (модуль-поставщик выключен), `hidden` (нет права
в контракте, с кодом права). У `estimate` есть ещё `no-item`: у работы нет позиции сметы. Пустой
`items` при `state: ok` MUST означать «поставщик ответил: нет ничего», а не отсутствие ответа.

#### Scenario: Учёт затрат выключен
- **WHEN** модуль `costs` выключен
- **THEN** `issued` приходит с `state: not-connected`, а `catalog` предлагает справочник целиком

#### Scenario: Планирование выключено
- **WHEN** модуль `plan` выключен
- **THEN** `estimate` приходит с `state: not-connected`, а не пустым списком

#### Scenario: Работа без позиции сметы
- **WHEN** строка относится к позиции перечня, у которой нет позиции сметы
- **THEN** `estimate` приходит с `state: no-item`

### Requirement: [WORK-39] [AUTH-8] Подсказка — по стройкам спрашивающего
Подсказка SHALL отвечать только по стройке, доступной спрашивающему: монтажнику — по стройкам его
назначений, менеджеру — своим, с `work.sites.all` или `work.report.read.all` — любой. По чужой стройке
ответ MUST быть 404. Адрес стоит за воротами модуля и под правом `work.report.own` или
`work.report.review`.

#### Scenario: Чужая стройка
- **WHEN** монтажник запрашивает подсказку по стройке, на которую не назначен
- **THEN** ответ — 404, а не 403, и ни один ярус не отдан

#### Scenario: Без права модуля
- **WHEN** пользователь без `work.report.own` и `work.report.review` вызывает адрес подсказки
- **THEN** ответ — 403

#### Scenario: Модуль выключен
- **WHEN** модуль `work` выключен
- **THEN** адрес подсказки отвечает отказом выключенного модуля (501)
