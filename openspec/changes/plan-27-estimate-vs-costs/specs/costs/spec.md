# Spec Delta: costs

## ADDED Requirements

### Requirement: [COST-21] [COST-26] «План против факта» материалов по стройке
Отчёт `GET /api/costs/estimate-vs-costs` под правом `costs.report.read` SHALL сравнивать по позиции
номенклатуры стройки (с отбором по разделу) сметную стоимость материала по действующим редакциям смет с
фактом двумя числами — разнесено и оплачено. Расхождение MUST считаться по разнесённому. Строки, у
которых есть только смета или только факт, MUST показываться.

#### Scenario: Закуплено больше сметы
- **WHEN** по смете кабель на 100 000, разнесено 120 000, оплачено 90 000
- **THEN** строка показывает смету 100 000, разнесено 120 000, оплачено 90 000 и расхождение +20 000

#### Scenario: Материал вне сметы
- **WHEN** на стройку разнесён материал, которого нет в смете
- **THEN** строка показана с пустой сметой и фактом

#### Scenario: Без права отчёта
- **WHEN** адрес вызывает пользователь без `costs.report.read`
- **THEN** ответ 403

### Requirement: [COST-21] [PLAN-11] Сметная колонка «плана против факта» — по праву на деньги сметы
Сметная стоимость SHALL приходить только читающему с `plan.estimate.cost`; без права колонка MUST
приходить «скрыто правами» с кодом права и без итогов, при выключенном модуле `plan` — «не подключено».
Материал, чью стоимость смета не несёт, MUST помечаться «нет в смете», а не нулём.

#### Scenario: Бухгалтер
- **WHEN** отчёт читает пользователь с `costs.report.read` без `plan.estimate.cost`
- **THEN** разнесено и оплачено видны, сметная колонка — «скрыто правами», сумм сметы в ответе нет

#### Scenario: Смета без стоимости ресурса
- **WHEN** у материала позиции сметы нет стоимости ресурса
- **THEN** его сметная стоимость помечена «нет в смете», расхождения нет

#### Scenario: Модуль `plan` выключен
- **WHEN** отчёт читают на экземпляре без модуля `plan`
- **THEN** сметная колонка — «не подключено», факт виден
