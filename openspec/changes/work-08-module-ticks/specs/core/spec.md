# Spec Delta: core

## ADDED Requirements

### Requirement: [WORK-41] [WORK-10] Периодический такт модульных заданий
Модуль SHALL объявлять такт — код, название, операцию своей очереди задач и период. Ядро MUST ставить
задачу такта через общую очередь, когда срок прошёл и после него задачу не ставили, с постоянной целью
такта: пока задача такта стоит в очереди или идёт, вторая не ставится. У выключенного модуля такта нет.

#### Scenario: Срок прошёл
- **WHEN** у такта с периодом 5 минут последняя задача поставлена 6 минут назад и завершилась
- **THEN** ядро ставит одну новую задачу операции такта, видимую в индикаторе фоновых задач

#### Scenario: Задача такта ещё идёт
- **WHEN** срок такта прошёл, а его прежняя задача ещё в очереди или выполняется
- **THEN** вторая задача не ставится и отказ «уже выполняется» в журнал сервера ошибкой не пишется

#### Scenario: Простой сервера
- **WHEN** сервер был выключен неделю и поднялся
- **THEN** такт ставит одну задачу, а не задачу за каждый пропущенный срок

#### Scenario: Модуль выключен
- **WHEN** экземпляр стартует без модуля, объявившего такт
- **THEN** задач этого такта не ставится

### Requirement: [WORK-41] Объявление такта проверяется при старте
Приложение MUST NOT стартовать, если такт включённого модуля называет операцию без обработчика, если
код такта повторён в модуле или период короче минуты; причина называет модуль и такт.

#### Scenario: Такт без обработчика
- **WHEN** модуль объявляет такт с операцией, для которой не зарегистрирован обработчик
- **THEN** приложение не стартует и называет модуль, такт и операцию

#### Scenario: Два такта одного кода
- **WHEN** модуль объявляет два такта с одинаковым кодом
- **THEN** приложение не стартует и называет повторённый код

### Requirement: [WORK-41] [CORE-24.1] Задача такта — от имени системы с названием
Задача такта SHALL выполняться от имени системы: записи журнала действий, сделанные в ней, MUST нести
автора «Система» с названием такта. Опубликованных наборов и таблиц с отбором по правам задача такта
MUST NOT читать — отказ с причиной.

#### Scenario: Запись журнала из задачи такта
- **WHEN** задача такта «Автоподача отчётов» пишет действие в журнал
- **THEN** автор записи — «Система — Автоподача отчётов», учётной записи у неё нет

#### Scenario: Отказ задачи такта
- **WHEN** задача такта падает
- **THEN** отказ уходит общесистемным уведомлением, а не в личный колокольчик

#### Scenario: Такт читает опубликованный набор
- **WHEN** задача такта запрашивает строки опубликованного набора
- **THEN** ответ — отказ с названием такта в причине, а не пустая таблица
