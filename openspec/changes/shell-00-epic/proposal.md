# Proposal: оболочка приложения, вариант B «Разделы и подпанель» — зонтик

## Why

Issue #1428 (эпик, `ui`): оболочка — навигация, профиль, поиск, активность — пересматривается по
требованиям владельца продукта:
1. интерфейс не перегружен;
2. пользователь не пугается сложности, а испытывает иллюзию простоты и ясности;
3. мощность функционала доступна простыми действиями, интерфейс сам подсказывает.

Дети эпика: #1429, #1430, #1431, #1432, #1433, #1434, #1435, #1436; рядом — #1418. На 22.10.2026 сделаны
#1429, #1430, #1431, #1432, #1434, #1418 и первая часть #1433 (действия и разделы палитры). Открыты:
- вторая часть #1433 — поиск по данным в палитре;
- #1435 — подсказка о перетаскивании сканов на список счетов;
- #1436 — Главная «Продолжить работу».

Зонтик фиксирует решение B, решения владельца, правила оболочки, сделанное (issue → PR) и порядок
оставшихся дочерних change.

## What Changes

- Дочерние change оставшейся работы (номер — место ребёнка в эпике, не порядок старта):
  - `shell-05-palette-data-search` (#1433, часть 2) — серверный поиск записей в правах спрашивающего и
    группы данных в палитре;
  - `shell-07-scan-drop-hint` (#1435) — постоянная строка-подсказка внизу колонки списка счетов;
  - `shell-08-home` (#1436) — Главная `/`: «Ждут вас», «Недавние», «Выполняется», «Полезно знать».
- Правило оболочки, ещё не записанное в `docs/UI.md`, — «наведение скрывает только ускоритель действия с
  видимым входом» — записывается одним из оставшихся PR (`tasks.md`, 1.4).
- Сделанное в коде не переделывается: зонтик только сводит его в таблицу (`design.md`, D3).

## Capabilities

### New Capabilities
- Нет в самом зонтике. Требования к оболочке (`sharedui`) и экранам модулей приносят дочерние change.

### Modified Capabilities
- Нет в самом зонтике (`skip_specs: true`). Дельты `sharedui`, `core` и `costs` несут дочерние change.

## Impact

- **Клиент:** `shared/ui/*` (палитра, рейл, `AppShell`, `BottomNav`), `App.tsx` (маршрут `/`),
  `features/costs/*` (подсказка, очередь адресом), новая страница Главной.
- **Сервер:** адрес поиска записей (форма — вопрос Архитектору в `shell-05`), хранение «Недавних»
  (вопрос Архитектору в `shell-08`).
- **Документы:** `docs/UI.md` (раздел «Оболочка»), `docs/USER_GUIDE.md` (оглавление — `npm run toc`).
- **Проверка:** правка оболочки затрагивает каждый экран — в каждом PR весь список живых прогонов CI.
- **Версия** приложения не меняется ни одним PR: её поднимает CI; функциональным PR — метка
  `version:minor`.
