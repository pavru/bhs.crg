# Spec Delta: costs

## MODIFIED Requirements

### Requirement: [COST-8] Распознавание счёта
Скан или файл счёта SHALL можно распознать профилем модуля через службу распознавания ядра; офисные
файлы `.docx`, `.xlsx`, `.xls` показываются читаемым образом и распознаются по нему. Распознанное —
предложение, его подтверждает человек; строки MUST NOT появляться в учёте сами.

#### Scenario: Поставщика нет в справочнике
- **WHEN** распознанный поставщик не найден среди организаций
- **THEN** он предлагается к созданию из названия и ИНН (`costs.organization.create`), но сам не создаётся

#### Scenario: Несколько файлов сразу
- **WHEN** пользователь перетаскивает несколько файлов счетов
- **THEN** на каждый файл заводится черновик, распознавание идёт фоновыми задачами

#### Scenario: Файл, который не читается
- **WHEN** счёт заводят из PDF, который не открывается (повреждён, под паролем или внутри не PDF), или распознавание такого файла запускают кнопкой
- **THEN** черновик заведён, а распознавание отказывает причиной «сам файл не читается» (`BadFile`) — одинаково при настроенном и ненастроенном движке: проверка файла идёт раньше проверки готовности движков, и ни движок, ни его проба зрения не вызываются
