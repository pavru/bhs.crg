# Spec Delta: costs

## ADDED Requirements

### Requirement: [COST-8] [COST-4.1] Повторная загрузка выгрузки 1С не задваивает
Накладная из выгрузки 1С SHALL нести внешний идентификатор — систему-источник и код документа в ней.
Загрузка документа с уже известным внешним идентификатором MUST NOT заводить вторую накладную; такой
документ считается пропущенным.

#### Scenario: Тот же файл дважды
- **WHEN** один и тот же файл выгрузки загружают второй раз
- **THEN** новых накладных нет, все документы файла названы пропущенными

#### Scenario: Загрузка файлом и из папки
- **WHEN** документ уже пришёл файлом вручную, а потом тот же документ лежит в папке загрузки
- **THEN** загрузка из папки его пропускает — сверка по внешнему идентификатору, а не по пути загрузки

### Requirement: [COST-8] Итог загрузки называет пропущенное числами
Загрузка выгрузки 1С SHALL заканчиваться итогом тремя числами — «загружено», «пропущено», «без
номенклатуры» — с документами за каждым числом. Пропущенное MUST быть названо с причиной, а не опущено.

#### Scenario: Часть документов уже была
- **WHEN** в файле пять документов, два из них загружены раньше, у одного строки без номенклатуры
- **THEN** итог: загружено 3, пропущено 2 (уже загружены), без номенклатуры 1

### Requirement: [COST-8] [COST-17] Накладная из 1С приходит проведённой
Накладная из выгрузки 1С SHALL появляться сразу проведённой, с источником «выгрузка 1С» в журнале
действий. Строки без позиции номенклатуры MUST оставаться несопоставленными и считаться в «не
сопоставлено», а не попадать в «Материалы на объекте».

#### Scenario: Строка без номенклатуры
- **WHEN** строка документа 1С не сопоставлена с позицией номенклатуры
- **THEN** накладная проведена, строка видна в «не сопоставлено», сопоставляется без распроведения

### Requirement: [COST-8] Сбой загрузки по расписанию приходит уведомлением
Сбой загрузки из папки по расписанию SHALL приходить уведомлением тем, кто вправе загружать выгрузку, —
с причиной словами. Тихий сбой, видный только в журнале сервера, MUST NOT быть единственным следом.

#### Scenario: Файл не разобран
- **WHEN** файл в папке загрузки не разбирается
- **THEN** приходит уведомление с именем файла и причиной, файл не считается загруженным

### Requirement: [AUTH-8] [AUTH-9] Ворота загрузки выгрузки 1С
Загрузка выгрузки SHALL требовать право загрузки накладных и включённый модуль. Загрузка заводит новые
записи и `If-Match` не требует — повтор сторожит внешний идентификатор.

#### Scenario: Без права
- **WHEN** загрузку вызывает пользователь без права загрузки накладных
- **THEN** ответ 403, ничего не заведено

#### Scenario: Модуль выключен
- **WHEN** модуль, которому принадлежит загрузка, выключен
- **THEN** адрес загрузки отвечает отказом выключенного модуля, загрузка по расписанию не идёт
