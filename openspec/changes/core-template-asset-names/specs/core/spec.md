# Spec Delta: core

## ADDED Requirements

### Requirement: [CORE-21] [CORE-22] Файлы полей и ассеты шаблона не перезаписывают друг друга
Каталог компиляции генерации SHALL держать картинки и вложения полей в каталоге `fields/`
(`/fields/img_N.ext`, `/fields/att_N.ext`), а ассеты-картинки шаблона — в `assets/`
(`/assets/{Name}{ext}`). Ассет шаблона MUST NOT заменять файл поля ни при каком имени. Путь к файлу
поля шаблон получает из `data.json` (`.src`), а путь `image("/assets/{Name}{ext}")` к ассету остаётся
прежним.

#### Scenario: Ассет назван как картинка поля
- **WHEN** у шаблона есть ассет-картинка `img_0` с файлом `.png`, и в реквизитах есть поле-картинка
- **THEN** документ выходит с картинкой поля, а ассет доступен шаблону по `/assets/img_0.png`

#### Scenario: Ассет назван как вложение
- **WHEN** у шаблона есть ассет-картинка `att_0`, и в реквизитах есть поле-вложение
- **THEN** в документ попадает вложение поля, а не файл ассета

#### Scenario: Существующий шаблон с картинкой поля
- **WHEN** шаблон выводит картинку поля через `image(it.Подпись.src)`
- **THEN** документ собирается, как до переезда файлов полей в `fields/`

### Requirement: [CORE-21] Имя ассета-картинки — простое имя файла
Имя ассета-картинки шаблона SHALL быть простым именем файла: буквы, цифры, `-`, `_` и `.`. В имени MUST
NOT быть разделителей пути `/` и `\` и последовательности `..`. При создании ассета с другим именем
запрос MUST отклоняться с кодом 400, а текст отказа — называть допустимые знаки. Файл в хранилище при
таком отказе MUST NOT загружаться. Имя шрифтового ассета в путь не входит, и правило к нему не
применяется.

#### Scenario: Имя с разделителем пути
- **WHEN** администратор загружает картинку с именем `fields/img_0`
- **THEN** ответ — 400, текст называет допустимые знаки, ассет не создан

#### Scenario: Имя с пробелом
- **WHEN** администратор загружает картинку с именем `Логотип компании`
- **THEN** ответ — 400, ассет не создан

#### Scenario: Допустимое имя
- **WHEN** администратор загружает картинку с именем `логотип-2.v1`
- **THEN** ассет создан, и шаблон зовёт его `image("/assets/логотип-2.v1.png")`

#### Scenario: Шрифт с пробелом в имени
- **WHEN** администратор загружает шрифт с именем `GOST 2.304 тип А`
- **THEN** ассет создан

### Requirement: [CORE-21] [CORE-22] Ассет с негодным именем — отказ генерации с названной причиной
Ассет-картинка, чьё имя не проходит правило простого имени файла, но пришёл из прежних данных или из
резервной копии, MUST NOT записываться в каталог компиляции. Генерация такого документа SHALL отказывать
(400) до компиляции, называя имя ассета и способ исправления. Отладочный комплект SHALL отдаваться, и в
перечне причин отказа его `README.txt` MUST быть названо имя ассета.

#### Scenario: Генерация с ассетом из старой копии
- **WHEN** из резервной копии восстановлен ассет-картинка с именем `../img_0`, и документ его шаблона
  генерируют
- **THEN** генерация отвечает 400, текст называет ассет `../img_0` и просит загрузить его заново под
  допустимым именем
- **AND** файл этого ассета не записан ни в какой каталог

#### Scenario: Отладочный комплект с таким ассетом
- **WHEN** администратор снимает отладочный комплект того же документа
- **THEN** комплект отдаётся, файла ассета в нём нет, а `README.txt` называет ассет в перечне причин
  отказа
