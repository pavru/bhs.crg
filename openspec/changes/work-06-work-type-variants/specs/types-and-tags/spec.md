# Spec Delta: types-and-tags

## ADDED Requirements

### Requirement: [WORK-49] [TYPE-9] Тип ядра `ВариантРаботы`
Ядро SHALL объявлять тип `ВариантРаботы` — составной, уровень правки `Extendable`, без родителя — с
запертым обязательным полем `ВидРаботы` (ссылка на запись типа `ВидРаботы`) и полем `Наименование` с
тэгом `identity`. Объявление MUST подтверждаться каждым стартом, как у `Сотрудника` и `ВидаРаботы`.
Если типа `ВидРаботы` на экземпляре нет, `ВариантРаботы` не заводится, и старт не останавливается.

#### Scenario: Заказчик дописывает своё поле
- **WHEN** администратор добавляет к типу `ВариантРаботы` необязательное поле «Способ крепления»
- **THEN** сохранение схемы проходит

#### Scenario: Попытка снять ссылку на вид
- **WHEN** администратор удаляет или переименовывает поле `ВидРаботы` у типа `ВариантРаботы`
- **THEN** сохранение отклоняется с ключом поля и причиной «поле ядра»

#### Scenario: Чистая установка без единиц измерения
- **WHEN** экземпляр стартует без справочника единиц, и `ВидРаботы` поэтому не заведён
- **THEN** старт проходит, типа `ВариантРаботы` нет, адреса вариантов отвечают «справочник не заведён»

#### Scenario: Вложенный объект вместо ссылки
- **WHEN** запись варианта несёт в поле `ВидРаботы` вложенный объект вида работы, а не ссылку на запись
- **THEN** запись отвергается с именем поля: вариант держит запись вида, а не её копию

## MODIFIED Requirements

### Requirement: [CORE-30] [CORE-30.1] [CORE-30.2] Опора ядра — ядро
Всё, от чего наследуется тип ядра или что он вкладывает (`complex`, `array`), SHALL принадлежать ядру.
Документная ссылка (`doc-ref`, `doc-array`) опорой не является. Типы ядра: `Организация`,
`НаименованиеОрганизации`, `Адрес`, `ГеографическиеКоординаты`, `Угол`, `Персона`, `ФИО`,
`ДополнительнаяХарактеристикаПерсоны`, `ОбъектСтроительства`, `ЕдиницаИзмерения`, `ПрофильСтройки`,
`ПрофильРаздела`, а также `Сотрудник`, `ВидРаботы` и `ВариантРаботы`; остальные прежние типы
принадлежат `id`.

#### Scenario: Тип ядра на опоре модуля
- **WHEN** тип ядра получает родителя или вложение из типа модуля
- **THEN** сохранение отклоняется

#### Scenario: Вариант вида работ — тип ядра
- **WHEN** экземпляр стартует с любым набором модулей
- **THEN** `ВариантРаботы` принадлежит ядру и опирается только на `ВидРаботы` — тип ядра
