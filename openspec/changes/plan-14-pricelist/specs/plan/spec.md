# Spec Delta: plan

## ADDED Requirements

### Requirement: [PLAN-10.1] Прайс-лист — запись модуля с датами действия
Прайс-лист SHALL храниться в схеме модуля `plan`, а не в общей таблице объектов: цена за единицу
классификатора у вида работы с датой начала действия. Действующая на дату цена — последняя, начавшаяся
не позже этой даты. Читать прайс-лист SHALL тот, у кого есть `plan.offer.read`; править — `plan.pricelist.edit`.

#### Scenario: Две цены одного вида работы
- **WHEN** у вида работы есть цены «с 01.01» и «с 01.07», а прайс-лист читают на 15.08
- **THEN** действующая цена — «с 01.07», прежняя видна в истории

#### Scenario: Сметчик без прав КП
- **WHEN** пользователь только с правами роли «Сметчик» читает прайс-лист
- **THEN** ответ 403

#### Scenario: Прайс-лист не виден через общие данные
- **WHEN** пользователь с правами модуля `id` ищет цены через «Общие данные», MCP или резервную копию
- **THEN** ни одной строки прайс-листа он не находит

### Requirement: [PLAN-10.1] [PLAN-23] Правка прайс-листа с версией
Правка и снятие строки прайс-листа SHALL требовать право `plan.pricelist.edit` и версию строки
заголовком `If-Match`. Новая цена вида работы на новую дату версии не требует.

#### Scenario: Правка без версии
- **WHEN** правка существующей строки приходит без `If-Match`
- **THEN** ответ 400

#### Scenario: Устаревшая версия
- **WHEN** строку тем временем изменили, а правка пришла с прежней версией
- **THEN** ответ 409, строка не меняется

#### Scenario: Право на КП без права на прайс-лист
- **WHEN** пользователь с `plan.offer.edit`, но без `plan.pricelist.edit`, правит цену
- **THEN** ответ 403

#### Scenario: Модуль выключен
- **WHEN** экземпляр работает без модуля `plan`, а клиент вызывает адрес прайс-листа
- **THEN** ответ — отказ выключенного модуля

### Requirement: [PLAN-10.1] Коммерческое предложение без сметы
КП SHALL заводиться по прайс-листу на стройку: строки — виды работ с объёмом, цена — действующая на дату
КП. Такое КП MUST NOT ссылаться на редакцию сметы: признак «смета изменилась» у него отсутствует, а
построить из него график нельзя. Вид работы без цены на дату MUST давать строку без цены с пометкой, а не
нулевую цену.

#### Scenario: Вид работы без цены
- **WHEN** в КП по прайс-листу добавлен вид работы, у которого нет цены на дату КП
- **THEN** строка несёт пометку «нет цены в прайс-листе», итог КП помечен «неполный»

#### Scenario: Прайс-лист изменился после заведения КП
- **WHEN** после заведения КП цену вида работы изменили
- **THEN** цены строк КП не меняются, пока человек не выполнит «пересчитать по прайс-листу» с показом изменений

#### Scenario: График из КП без сметы
- **WHEN** клиент читает КП, заведённое по прайс-листу
- **THEN** ответ несёт `canBuildSchedule: false` с причиной «КП не из сметы», признака «смета изменилась» в нём нет
