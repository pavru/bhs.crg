# Права полей таблиц модулей и метаданные их источников

## Why

Plan-28 выводит в таблицу расширяемые поля позиции сметы и публикует табличные наборы. Для этого ядру нужен единый контракт доступа к полям действующей схемы и к метаданным опубликованного источника в правах того, кто его читает.

## What Changes

- [CORE-33] [AUTH-8.2] Модуль получает необязательную политику права и причины недоступности для полей `RecordType`. Ядро учитывает её при каждом открытии таблицы, включая выгрузку и чтение через системный набор.
- [CORE-24.1] [CORE-24.2] Источники `system:table:…` сохраняют нейтральные метаданные. Примеры и число строк при чтении определяются в правах читающего и не подменяются снимком издателя.
- [CORE-24.1] [CORE-32] Объявление системного набора учитывает права полей схемы при проверке пригодности для общей печати и определения сверки.
- Правило совпадения ключа поля схемы с явной колонкой вынесено на согласование в design.md. Общий инвариант уже сформулирован в дельте: объявление явной колонки не может ослабить политику поля.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `core` — права на поля таблиц, сохранение и чтение метаданных табличных источников, пригодность для общего использования.

## Impact

Затронуты контракт таблиц модулей, общий сервис чтения таблиц и потребители метаданных табличных источников в REST, MCP и обработке наборов. Существующие маршруты и форматы запросов используются без нового экрана. [Plan-28](../plan-28-tables-dataset/proposal.md) подключит своё объявление после слияния кода CORE, подтверждённого повышения версии и слияния архива.
