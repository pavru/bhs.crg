# Фоновый обмен и причины недоставки

## ADDED Requirements

### Requirement: [MOB-19] [MOB-26] [MOB-27] Планирование обмена

Приложение SHALL синхронизироваться при запуске, появлении сети и периодически, давать ручной запуск и локальное напоминание. Серверный push не требуется. До подтверждения сервером запись очереди MUST пережить остановку процесса, выход из профиля и обновление APK.

#### Scenario: Планирование обмена в работе

- **WHEN** процесс завершился после ответа сервера до локальной фиксации
- **THEN** при перезапуске отправляется прежний id, в офисе один отчёт, локальный курсор не пропускает изменение.

### Requirement: [MOB-21] [MOB-22] [MOB-23] Семь исходов доставки

Приложение MUST различать отсутствие сети, недоступность сервера, несовпадение сертификата, отзыв, устаревший клиент, закрытый период и запись менеджера. Для каждой причины SHALL показывать свою фразу из MOB-21 и сохранять отчёт. При устаревшей версии ввод работает.

#### Scenario: Семь исходов доставки в работе

- **WHEN** для семи причин выполнены семь независимых отправок
- **THEN** статус связи указывает соответствующее действие, N ожидающих у старой версии, дату закрытого периода или выбор открытия и правки; локальное содержимое сохранено.
