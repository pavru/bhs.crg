# Отчёт без стройки и привязка в офисе

## Why

Отсутствие стройки в списке не должно лишить монтажника отчёта. Офису нужно разобрать запись, сохранив строки и возможность проверить часы.

## What Changes

- Добавить приём непривязанной записи с клиентским id и заявленными фото, поддержать курсор, повтор и запрет приёмки до привязки.
- Проверить область очереди и детали на дату начала смены по решению владельца, целевую стройку ограничить правами менеджера. Предусмотреть административный доступ через разрешение, без проверки имени роли.
- Подготовить три макета диалога, записать выбор владельца. Реализовать предпросмотр, подтверждение, сверку обеих версий, обработку закрытого периода и расхождения часов.
- Проверить конкурирующую привязку, повтор, дневную и ночную смены, серверное сопоставление id после объединения, исключение из факта до привязки и возврат конечного id в API. Приёмку Android-очереди выполняет MOB-08, файлов — MOB-09.

Требования [WORK-22] [WORK-23] [WORK-39] [WORK-58] [MOB-21].

Полевой ввод, очередь менеджера, журнал, связывание с существующими отчётами и чтение результата телефоном.
