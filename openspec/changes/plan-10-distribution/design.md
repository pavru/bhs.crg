# Design: распределение сметы по разделам

Дочерний change зонтика `plan-00-epic`, общая архитектура — `../plan-00-epic/design.md` (D7, D9, D17,
D18). Здесь только решения этого change.

## Context

Сверено по коду master `6b81e51e`.

- Образец баланса — разноска `costs`: `Modules.Costs/Data/AllocationMath.cs:34-46`
  (`AllocationLineBalance`, `Balanced`), отказы — `InvalidRequestException` с названием строки
  (`Endpoints/AllocationEndpoints.cs:166-202`); экран — `features/costs/AllocationMatrix.tsx`.
- Разделы стройки модуль получает портом `IModuleConstructions` (`ModuleConstruction(Id, Name, Sections)`).
- Журнал действий модуля — `IModuleActivityLog` (`BHS.CRG.Modules/Ports/IModuleActivityLog.cs:79`),
  действия объявляются заранее (`IModuleActivityActions`).
- Позиции перечня плоские (`Domain/Documents/WorkPlanItem.cs`, комментарий о `CORE-Q2`).

## Goals / Non-Goals

**Goals:** раздел ЛСР распределяется одним действием; баланс как у разноски; правка после фиксации;
перенос при повторном импорте без потерь.

**Non-Goals:** позиции перечня по разделам при распределении — их заводит потребитель, которому они нужны
(график `plan-19`, контракт `plan-23`, D7); перестройка работ графика (`plan-19`).

## Decisions

- **Две таблицы.** `DistributionRule` — «редакция, раздел ЛСР → раздел стройки» (весь объём строк раздела
  уходит в раздел стройки). `DistributionPart` — «строка → раздел стройки → количество» — исключение,
  которое заменяет правило для своей строки целиком. Действующее распределение строки: части, если они
  есть, иначе правило раздела ЛСР, иначе «стройка в целом».
- **Единица количества** — единица строки сметы (как в файле). Для сопоставленной строки ответ несёт и
  количество в единице позиции (× коэффициент `plan-08`): «1200 м = 700 + 500» в обеих единицах.
- **Баланс** (`COST-13`): сумма частей ≤ объёма строки — иначе 400 с названием строки и суммы; остаток —
  «стройка в целом», а не ошибка. Отрицательных и нулевых частей нет. У редакции — `distributed`,
  `undistributed` (число строк и объём по видам работ) — носители «Распределено» и полосы «не распределено
  по разделам» в «Ходе работ» (D17).
- **Версия.** У редакции — запись заголовка распределения с `xmin`; каждая правка правила или частей
  требует его `If-Match` и сдвигает `distributionChangedAt`. Без заголовка — 400, устаревший — 409.
- **Зафиксированная редакция** правится: распределение — слой, а не содержание (`PLAN-5.1`). КП оно не
  трогает; у графика — пометка `distribution-changed` по сравнению `distributionChangedAt` с моментом
  построения (`plan-19`).
- **Журнал.** Действия `plan.distribution.rule`, `plan.distribution.lines` в журнал ядра через
  `IModuleActivityLog` с прежним и новым значением; цель — «Смета …, ред. N».
- **Перенос при повторном импорте** — шаг `plan-07` после создания редакции: ключ «раздел ЛСР + шифр +
  номер в разделе». Правило раздела переносится, если раздел ЛСР с тем же названием есть в новой редакции.
  Ответ — `carried`, `ambiguous` (ключ встретился дважды), `lost` (строки нет), каждая с прежней частью;
  неоднозначные не переносятся молча.
- **Адреса** (ворота модуля, запись — `plan.estimate.edit`, чтение — `plan.estimate.read`):
  `GET /api/plan/revisions/{id}/distribution`, `PUT /api/plan/revisions/{id}/distribution/rules`,
  `PUT /api/plan/revisions/{id}/distribution/lines/{lineId}`,
  `DELETE /api/plan/revisions/{id}/distribution/lines/{lineId}`.
- **Ссылки.** Объявления `CORE-34.1` на раздел стройки из правила и частей: удалить раздел, на который
  распределено, — отказ с числом строк.
- **Экран (PR 2).** Разбор с Дизайнером → три макета П2 → выбор владельца → код. Сетка — `DataGrid`;
  матрица исключений — по образцу `AllocationMatrix.tsx`, но с разделами стройки вместо мест.

## Risks / Trade-offs

- [Повторный импорт тихо теряет распределение] → перенос отвечает списками `ambiguous` и `lost`, экран их
  показывает.
- [Распределение по единице строки путает со «100 м»] → ответ несёт обе единицы.
- [Правка после построения графика расходится с ним] → пометка у графика и действие «перестроить» (`plan-19`).
