# Design: палитра из seed, свои роли и две роли текста

Общая архитектура — `../sharedui-md3-00-epic/design.md`: палитра (D4), макеты (D10), сторожа (D11).
Описание темы и генератор — `../sharedui-md3-01-tokens/design.md`; карта перевода —
`../sharedui-md3-02-class-codemod/design.md`.

## Context

- После 01 описание темы в режиме `values`: значения 2022 года (baseline с seed `#1d5fb0`), недостающие
  роли вписаны предварительно. Псевдонимы без роли — `fg3`, `warning-border`, `stroke-subtle` (снимает
  этот change), `fg-disabled`, `brand-hover`, `brand-pressed` (снимает 05). `fg4` указывает на `outline`.
- После 02 в коде на старых именах остались: `text-fg3` (~640), `text-fg4` (~890), `text-stroke-strong`
  (14), `border-warning-border` (39), `border-stroke-subtle` (1); текст `text-error`/`text-success`/
  `text-warning` на своих `*-container` — по месту.
- Контраст сегодня (светлая): `fg4` на `surface` 4,36, на фоне страницы 4,03, на `bg4` 3,65; `success` на
  `success-container` 3,61; `warning-border` на `surface` 2,67 (разбор Дизайнера, §1).
- `@material/material-color-utilities` 0.4.0 (на 27.10.2026): `DynamicScheme` с вариантами
  `TonalSpot`, `Fidelity`, `Content`…, уровень контраста, `customColor` и `Blend.harmonize` (сдвиг тона не
  больше 15°).
- Сервер повторяет два значения: `BrandIcons.BackgroundColor` (`light.surface-container-low`) и
  `BrandIconComposer.DarkTile` (`dark.surface`); сторож 01 сверяет их с описанием.

## Goals / Non-Goals

**Goals:** все роли — из генератора; контраст ролей доказан тестом; у текста две роли.

**Non-Goals:** раскладка поверхностей по местам (какой контейнер у меню, окна, карточки — дети 12–15);
состояния и отключённое (05); пользовательский выбор цвета и рантайм-генерация (зонтик, Non-Goals);
третья тема «высокий контраст» — после эпика, генератор её почти даёт.

## Decisions

### Описание темы в режиме `seed`
- `md3-theme.json`: `mode: "seed"`, `seed: "#1d5fb0"`, `variant` (по листу), `contrast: 0`,
  `pinPrimary` (В2), `ext: [{ name: "success", value: "#1b8a5b", harmonize }, { name: "warning", value:
  "#7a5900", harmonize }]` (В3), `static: { "tab-light": "light.surface-container-low", "tab-dark":
  "dark.surface-container-low" }`. Раздел `roles` уходит.
- `pinPrimary: true` — после генерации светлый `primary` подменяется seed; `on-primary`,
  `primary-container`, `on-primary-container` остаются из тональной палитры seed. Тёмный `primary` — тон
  80 той же палитры. Тест контраста проверяет пары после подмены.
- Гармонизация по В3: `false` — свои роли из своей палитры как есть; ограниченная (≤ 5°) — свой сдвиг
  тона в HCT в генераторе, потому что `Blend.harmonize` сдвигает до 15°. Рекомендация Дизайнера — без
  гармонизации: зелёный и янтарный — смысл, синий сдвиг сделал бы success бирюзовым.
- Уровни тени и шрифт остаются как в 01 (тени меняет 06); из `--legacy-*` этот change снимает `fg3`,
  `warning-border`, `stroke-subtle`, остальные — 05.
- **Отвергнуто — оставить ручные значения и проверять только контраст.** Ручная правка однажды уже
  вывела `--f-bg3` из палитры; генерация из одного seed держит тона согласованными по построению.

### Тест контраста
- Формула относительной яркости WCAG 2.x по hex из описания после генерации, обе темы:
  `on-X`/`X` для `primary`, `secondary`, `tertiary`, `error`, своих ролей и их контейнеров ≥ 4,5;
  `on-surface` и `on-surface-variant` на `surface`, `surface-dim`, `surface-bright`, каждом
  `surface-container-*` ≥ 4,5; `outline` на тех же ≥ 3; `inverse-on-surface` на `inverse-surface` ≥ 4,5.
- Граница теста — фикстура заведомо плохой палитры (свой цвет с тёмным тоном контейнера): тест обязан
  её поймать.

### Перевод текста (В1) и прочих осиротевших имён
- Псевдонимы в PR 1: `fg3 → on-surface-variant`, `fg4 → on-surface-variant` — вид меняется сразу во всём
  клиенте, включая чужие ветки; значение `--legacy-fg3` удаляется.
- Карта 02 получает строки этого change (`same: false`, вид меняется по решению владельца):
  `text-fg3`, `text-fg4`, `text-stroke-strong` → `text-on-surface-variant`; прочие утилиты с `fg3`/`fg4`
  (`placeholder:`, `border-`, `fill-`) — по отчёту, руками.
- Текст на контейнере: в одном списке классов `bg-<роль>-container` и `text-<роль>` → `text-on-<роль>-container`
  — правилом кодмода по строке; разнесённые по элементам места — отчётом, руками.
- `border-warning-border` и `border-stroke-subtle` — по листу: рекомендация Дизайнера — обводки по
  статусу нет, статус несут знак и контейнер (`border-outline-variant` или без рамки); `--legacy-*`
  удаляются.
- **Отвергнуто — `fg4 → outline` навсегда:** MD3 не даёт `outline` для текста, и 888 мест остались бы
  ниже AA.

### Значения сервера
- В PR 1 `BackgroundColor` и `DarkTile` переписываются значениями генератора; сторож 01 краснеет, если
  забыть. `theme-color` страницы — бирюза знака, вне палитры (решение владельца 13.10.2026).

## Risks / Trade-offs

- [Подписи и метаданные заметно темнеют во всём клиенте] → это решение В1; лист «до/после» обеих тем
  владельцу до кода, снимки 5–7 экранов в PR.
- [TonalSpot сдвигает primary, и кнопка меняет цвет, знакомый людям] → В2: закрепить; вариант схемы — на
  листе.
- [Закреплённый primary нарушит контраст пары] → тест контраста проверяет пары после подмены; при
  отказе — вариант схемы, а не ручная правка.
- [Чужая ветка принесёт `text-fg4` после PR 2] → псевдоним уже рисует `on-surface-variant`, храповик
  просит перевести, `npm run md3:migrate` переводит.

## Migration Plan

PR 1 — генератор `seed`, свои роли, тест контраста, псевдонимы `fg3`/`fg4`, значения сервера. PR 2 —
карта и перевод текста, контейнеры, обводки по статусу, уровень `legacy-class`, `docs/UI.md`. Откат PR 1 —
ревёрт: описание темы возвращается в режим `values`.
