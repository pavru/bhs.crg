# Дельта спецификации core

## ADDED Requirements

### Requirement: [CORE-25] Результат фонового распознавания соответствует редакции набора
Сервер SHALL применять результат фонового распознавания PDF-набора целиком только к редакции входных данных, принятой для выполнения. Если редакция изменилась или не определяется, задача MUST завершиться с объяснением и сохранить текущие данные и связанные результаты.

#### Scenario: Набор изменился
- **WHEN** входные данные набора изменились между принятием задачи и применением результата
- **THEN** результат не применяется, а итог задачи сообщает причину

#### Scenario: Редакция совпадает
- **WHEN** задача завершила обработку и редакция её входных данных актуальна
- **THEN** сервер сохраняет результат и связанные данные

#### Scenario: Редакция прежней задачи не определяется
- **WHEN** после обновления обрабатывается задача, для которой редакция входных данных не определяется
- **THEN** задача завершается с предложением запустить обработку повторно

### Requirement: [CORE-25] [AUTH-12.1] Входы распознавания объясняют условия продолжения
Входы распознавания SHALL применять действующие права и правила допуска. Если для продолжения требуется действие сотрудника, ответ SHALL объяснить причину и указать, где это действие можно выполнить.

#### Scenario: Требуется действие сотрудника
- **WHEN** правила операции требуют действия сотрудника в интерфейсе
- **THEN** ответ указывает на доступный путь продолжения, а состояние набора сохраняется до действия сотрудника
