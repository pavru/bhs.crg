# Актуальность результатов фоновой обработки

## Why

Фоновое распознавание может выполняться дольше, чем пользователь редактирует набор. Версия входных данных должна определять, к какому состоянию набора относится результат.

## What Changes

- Привязать результат фонового распознавания к редакции входных данных. При конфликте сохранять текущие данные и сообщать причину.
- Согласовать правила допуска и сообщения для существующих входов распознавания. Если операцию должен завершить сотрудник, указывать на действующее действие в интерфейсе.
- Предусмотреть понятный повторный запуск для заданий, у которых после обновления отсутствует проверяемая редакция входных данных.

### Modified Capabilities

## Impact

В объём входят запуск распознавания PDF-наборов, обработка результата, существующие сообщения и проверка совместимости очереди. Работы по другим модулям рассматриваются отдельно.
