# Подписанный APK, обновление и приёмка поставки

## ADDED Requirements

### Requirement: [MOB-24] [MOB-26] Два канала одного выпуска

Каждый выпуск SHALL собирать подписанный APK, доступный по `/m/` экземпляра и как ассет GitHub Release. Приложение MUST обновляться поверх предыдущего выпуска с сохранением Room, несданных отчётов и файлов.

#### Scenario: Два канала одного выпуска в работе

- **WHEN** скачаны APK одного выпуска из двух каналов, на телефоне предыдущая версия с несданной ночной сменой и фото
- **THEN** контрольные суммы равны, подпись позволяет обновить установленное приложение, смена и фото успешно доставляются после обновления.
