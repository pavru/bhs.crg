# Proposal: поля заказчика «нужно к приёмке»

Дочерний change зонтика `work-00-epic`, общая архитектура — `../work-00-epic/design.md` (D7, D11, D15).

## Why

Заказчик добавляет в `СтрокаРаботы.Сведения` свои поля (`CORE-19.1`), а телефон первой версии их не
рисует (`MOB-Q4`, вариант А): заполнить их можно только в вебе. Без пометки в очереди их не заполнит
никто (`WORK-44`). Но пометка по любому пустому полю превратилась бы в шум: необязательные поля пусты
почти всегда, и отбор «не заполнены поля» вернул бы всю очередь. Решение владельца Р-7 (`WORK-53`) —
признак поля «нужно к приёмке»: отбор и счётчик считают только помеченные поля, а принять отчёт можно и
с пустыми.

## What Changes

- **Тип.** У поля схемы появляется признак `forAcceptance` («нужно к приёмке»). Он ставится только на
  поле заказчика и только у типа, чей модуль объявил приёмку. Тип отдаёт носитель `acceptanceFields`.
  Признак не делает поле обязательным: правило «в расширяемый тип — только необязательные поля» цело.
- **Отчёт.** У строки поданного отчёта сервер отдаёт `missingFields` — помеченные поля, оставшиеся
  пустыми; у отчёта — их число. Считается по действующей схеме при чтении.
- **Очередь.** Код пометки `fields-missing` («не заполнены поля: N») в каталоге `work-16`, счётчик по
  коду и отбор по нему.
- **Приёмка не запирается.** Принять отчёт с пустыми помеченными полями можно; пометка остаётся в карточке.
- **Заполнение после подачи** — обычная «правка после подачи» с журналом (`WORK-11`), после закрытия
  периода — новая версия с причиной (`WORK-15`, `work-19`).
- **Клиент.** Колонка признака в редакторе полей (только у типа с `acceptanceFields`), пометка «нужно к
  приёмке» у пустого поля в форме строки, список незаполненных в карточке и чип в очереди.

## Capabilities

### New Capabilities
- Нет.

### Modified Capabilities
- `work`: счёт незаполненных помеченных полей, пометка очереди, приёмка с пустыми, заполнение после
  подачи и после закрытия.
- `types-and-tags`: признак поля «нужно к приёмке» в схеме типа и правила его установки.
