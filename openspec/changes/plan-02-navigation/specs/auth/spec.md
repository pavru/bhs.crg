# Spec Delta: auth

## ADDED Requirements

### Requirement: [AUTH-16] [AUTH-8] Пункт навигации и адрес «любое из прав»
Пункт навигации SHALL уметь называть список прав и показываться при любом из них. Адрес или группа
адресов SHALL уметь стоять под политикой «любое из прав» с тем же списком. Каждый код списка MUST быть
объявлен — иначе приложение не стартует (`AUTH-8.2`). Страница «нет доступа» называет весь список, кроме
кодов модулей, которых нет на экземпляре: такое право выдать нельзя.

#### Scenario: Пункт под списком прав
- **WHEN** пункт и его адреса закрыты «любым из» двух прав, а у пользователя только второе
- **THEN** он видит пункт, и адреса отвечают ему 200

#### Scenario: Ни одного права из списка
- **WHEN** пользователь без обоих прав открывает адрес такого раздела прямой ссылкой
- **THEN** он видит страницу «Раздел недоступен: нужно одно из прав: …» с обоими правами

#### Scenario: Право модуля, которого нет на экземпляре
- **WHEN** пункт называет «любое из» двух прав, второе принадлежит модулю, которого нет в ответе доступа, а
  у пользователя нет ни одного
- **THEN** страница «нет доступа» называет только первое право

#### Scenario: Необъявленное право в списке
- **WHEN** политика «любое из» называет код, которого нет в справочнике
- **THEN** `PermissionGateTests` падает с названием кода, а не дверь молча закрыта всем

#### Scenario: Пишущий адрес под «любым из»
- **WHEN** изменяющий адрес закрыт «любым из», и одно право списка входит в `*.read.all`
- **THEN** `ReadAllWritesNothingTests` называет адрес

#### Scenario: Палитра команд
- **WHEN** пользователь с одним правом из списка ищет раздел в палитре (Ctrl+K)
- **THEN** раздел находится, как и в меню

### Requirement: [AUTH-16.1] [PLAN-20] Раздел рейла модуля «Планирование»
Навигация SHALL иметь раздел рейла `plan` для пунктов модуля «Планирование» с подписью «Планы» и
заголовком подпанели «Планирование» (макет П0); раздел стоит последним из рабочих, после «Затрат» —
раздела `costs` с подписью «Затраты». Раздел MUST NOT показываться, пока в нём нет ни одного видимого
пункта. Модуль, открытый одним правом контракта, раздела не даёт.

#### Scenario: Порядок разделов
- **WHEN** пользователю видны пункты разделов «Стройки», «Данные», `costs`, `plan` и «Система»
- **THEN** рейл показывает их в порядке «Стройки», «Данные», «Затраты», «Планы», «Система»

#### Scenario: Пользователь без прав модуля
- **WHEN** у пользователя нет прав модуля `plan`
- **THEN** раздела `plan` в рейле и в нижней навигации телефона нет

#### Scenario: Только право контракта
- **WHEN** у пользователя из прав модуля `plan` есть только право контракта
- **THEN** раздела `plan` нет, а `/api/account/access` отдаёт модуль с `available: false`

### Requirement: [AUTH-16.1] [AUTH-15] Страница входа по доступу
После входа и по адресу `/` клиент SHALL открывать страницу, вычисленную по `/api/account/access` и
текущему пространству. Открывается видимый пункт, объявивший себя страницей входа, с наименьшим рангом.
Если такого нет — первый видимый пункт навигации. Если видимых пунктов нет, клиент MUST показать
страницу `AUTH-15`, а не перенаправлять на раздел, отвечающий отказом.

#### Scenario: Роль с правами модуля без «Строек»
- **WHEN** у пользователя права модуля `plan`, но нет `core.constructions.read` (самодельная роль)
- **THEN** после входа открывается не отказ на «Стройках», а Главная; до появления Главной — первый
  видимый пункт, то есть пункт раздела «Планы»

#### Scenario: Пункт объявил себя страницей входа
- **WHEN** пункт модуля объявил ранг страницы входа меньше ранга Главной и виден пользователю
- **THEN** после входа открывается он, а не Главная

#### Scenario: Пункт входа вне пространства
- **WHEN** пункт с наименьшим рангом не входит в текущее пространство
- **THEN** открывается страница входа этого пространства, само пространство не меняется

#### Scenario: Ни одного видимого пункта
- **WHEN** у пользователя нет прав ни на один раздел
- **THEN** он видит честную страницу «нет доступа» с объяснением

### Requirement: [AUTH-16.1] Главная в расчёте страницы входа
Главная («Продолжить работу», `shell-08-home`) SHALL входить в расчёт страницы входа пунктом ядра с
рангом по умолчанию `HOME_ENTRY_RANK`. Пункт модуля MUST открываться вместо Главной, только если его ранг
меньше и аккаунту доступен ровно один модуль — модуль этого пункта. Пункту ядра ранг меньше
`HOME_ENTRY_RANK` MUST NOT назначаться (решение владельца 22.10.2026, вариант Б, `shell-08-home` В-1).

#### Scenario: Главная по умолчанию
- **WHEN** Главная есть, а ни один видимый пункт не объявил ранг меньше её ранга
- **THEN** после входа и по `/` открывается Главная

#### Scenario: Ранг больше ранга Главной
- **WHEN** пункт модуля объявил ранг страницы входа больше ранга Главной
- **THEN** после входа открывается Главная; ранг этого пункта решает только среди пунктов модулей, когда
  Главной нет

#### Scenario: Два доступных модуля
- **WHEN** пункт модуля объявил ранг меньше ранга Главной, а аккаунту доступны два модуля
- **THEN** после входа открывается Главная

#### Scenario: Модули считаются по аккаунту
- **WHEN** аккаунту доступны два модуля, а текущее пространство сужает навигацию до одного
- **THEN** после входа открывается Главная: вход не зависит от выбранного пространства

#### Scenario: Главной ещё нет
- **WHEN** пункт Главной не объявлен (`shell-08` не слит)
- **THEN** открывается видимый пункт с наименьшим рангом, правило одного модуля не действует

#### Scenario: Все права
- **WHEN** входит пользователь со всеми правами («Администратор»)
- **THEN** после входа открывается Главная, а не пункт какого-либо модуля с малым рангом

#### Scenario: Пункты модуля «Планирование»
- **WHEN** входит пользователь с правами роли «Сметчик», «Менеджер проекта» или «Снабженец»
- **THEN** открывается Главная: у пунктов `plan` ранга меньше ранга Главной нет (макет П0)

### Requirement: [AUTH-16.1] [PLAN-20] Панели модулей в карточке стройки
Модуль SHALL добавлять панель в карточку стройки и на страницу раздела общим механизмом, называя право
(или «любое из»), раздел ядра или модуль, блок и уровни. Видны только панели, доступные пользователю и
входящие в пространство. У модуля MUST быть не больше двух панелей. Адрес панели MUST NOT зависеть от
способа показа. Панель вне пространства по ссылке MUST открываться с плашкой; пространство в запросы
панели не передаётся.

#### Scenario: Страница раздела
- **WHEN** панель объявлена на уровнях стройки и раздела
- **THEN** она есть и в карточке стройки, и на странице раздела, а `PLAN-20` считает её одной панелью

#### Scenario: Панель недоступного модуля
- **WHEN** модуль объявил панель, а у пользователя нет её права
- **THEN** пункта панели в карточке стройки нет

#### Scenario: Третья панель модуля
- **WHEN** модуль объявляет третью панель карточки стройки
- **THEN** тест реестра панелей падает с названием модуля

#### Scenario: Ссылка на панель вне пространства
- **WHEN** пользователь открывает ссылку на панель модуля, не входящего в текущее пространство
- **THEN** панель открывается с плашкой и возвратом, в навигации карточки она единственная из блока —
  активной, с пометкой «вне пространства»; пространство не меняется

#### Scenario: Прежние панели
- **WHEN** карточку стройки открывает пользователь без модулей
- **THEN** «Каталог», «Наборы данных» и «Подписчики» стоят на прежних местах и тех же адресах — теперь из
  общего механизма; блока «Работы» нет, голый адрес стройки открывает «Каталог»

### Requirement: [AUTH-16.1] [PLAN-20] Блок «Работы» и панель по умолчанию в карточке стройки
Карточка стройки SHALL показывать блок «Работы» над списком разделов: сначала панели ядра, затем панели
модулей в порядке рейла, без имён модулей; блок «Эта стройка» — под разделами. По умолчанию MUST
открываться первая видимая панель; «Каталог» MUST открываться и своим адресом `/catalog` (макет П0).

#### Scenario: Блок «Работы»
- **WHEN** карточку открывает пользователь с правами «Хода работ», смет и графиков
- **THEN** над разделами стоит блок «Работы»: «Ход работ», «Сметы», «График»; имён модулей в блоке нет

#### Scenario: Панель по умолчанию
- **WHEN** пользователь открывает голый адрес стройки
- **THEN** открывается первая видимая панель: «Ход работ», если он виден, иначе «Каталог»

#### Scenario: Только «Ход работ»
- **WHEN** из панелей блока «Работы» пользователю видна только «Ход работ» («Бухгалтер»)
- **THEN** блок «Работы» состоит из одного пункта
