# Рабочее обсуждение ТЗ модульной архитектуры

Восстановлена страница Claude с навигацией по разделам, поиском, комментариями к
меткам требований, замечаниями ко всему ТЗ и разделу, фильтрами и сводкой.
В комментариях можно отвечать, выбирать вид замечания, закрывать и возвращать
обсуждение, удалять запись с подтверждением вторым нажатием.

Из корня рабочей копии установите зависимости командой `npm --prefix docs/tools ci`,
затем запустите `python docs/tz/workbench/serve.py` и откройте
[рабочую страницу](http://127.0.0.1:8766/). Порт можно задать через `--port`.
Сервер должен работать, пока открыта страница.

«Текущее ТЗ» читает Markdown непосредственно из `docs/tz/`. Правка текста делается
в этих файлах, затем страница обновляется. «Снимок Claude» показывает текст из
экспорта. Общие метки связывают оба представления с одним обсуждением.

`comments.json` хранит рабочее обсуждение. Изменения в браузере записываются в этот
файл сразу. Codex читает его, отвечает новой записью с той же меткой пункта и
вносит согласованные решения в соответствующий Markdown. Для ответа от Codex
используется поле `author: "codex"`. Путь к тексту задаётся полем `file`, метка
пункта — `item`. Авторские даты и состояния импортированных записей сохранены.
Изменения файлов передаются между рабочими копиями через Git.

Сервер слушает только этот компьютер. Браузер работает от имени локального
владельца. Авторизация и совместный доступ Claude принадлежали сервису Claude.
Здесь вкладки одной рабочей копии получают изменения обсуждения каждые две секунды.
При одновременной правке одного замечания устаревшая запись отклоняется.
